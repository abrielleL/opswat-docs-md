# User Guide

Since MetaDefender Update Downloader 2.4.0, the licensing mechanism has been changed.

- No longer need to activate license of Update Downloader itself to make it operational.
- Instead required to add license file (.yml) of offline MetaDefender products

Check out [1.2. License activation](/docs/mddownloader/installation/license-activation) to learn more.

## [About this guide](/docs/mddownloader/operating/user-guide#about-this-guide)

The Update Downloader product is designed to download updates to an internet connected computer and save it to a specified folder to make it possible to upload to a non-internet connected Metascan v3, v4 or Central Management product.
