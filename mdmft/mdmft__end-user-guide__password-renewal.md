# Password Renewal

Summarize Page    Connect to Cursor Connect to VS Code

If this is your first login to MetaDefender® MFT or if prompted, you may need to reset your password. Enter your current password, then enter your new password twice, and click "Submit." Pay attention to the [password strength](/docs/mdmft/end-user-guide/password-strength) indicator for security.
