# Release a File

Summarize Page    Connect to Cursor Connect to VS Code

When the supervisor approval function is enabled, this feature allows local administrators and other administrators (except readonly administrators) to release pending files. Once released, the files are available to users, and no further supervisor approval is needed.

Releasing a file is regardless of how many approval steps are still remaining.

To release a file, go to the "Processing History" page. In the file action menu, select the "Release" option.

Administrators can also release multiple files at once.
