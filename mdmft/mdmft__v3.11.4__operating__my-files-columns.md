# My Files Columns

Summarize Page    Connect to Cursor Connect to VS Code

| Column | Description |
| --- | --- |
| Name | Displays the name of the file or folder. |
| File Status | Represents the current stage of the file's lifecycle—from the initial upload, through scanning by *MetaDefender Core™*, to its final state such as available, deleted, or archived. |
| Uploader | (Optional) Identifies the user who originally uploaded the file, applicable in [Shared Space](/docs/mdmft/v3.11.4/operating/group-shared-space) configurations. |
| Processing Status | The upload file's lifecycle starting from uploading it, going through |
| Scan Result | Displays the file’s final verdict, determined based on the scan results from MetaDefender Core™ |
| Supervisor Approval Status | (Optional) Visible only when the [Supervisor Approval](/docs/mdmft/v3.11.4/configuration/supervisor-approval) feature is enabled. Indicates the file’s current approval state: Disabled, Pending, Rejected, or Approved. |
| Sharing | Indicates whether the file has been shared with others, providing feedback to the file owner. |
| File Classification | Shows the classification level assigned to the file by the uploader during the upload process. For more information [go to File Classification page](/docs/mdmft/v3.11.4/configuration/file-settings#enable-file-classification) |
| Upload Date | The precise date and time when the file upload began, adjusted to the user's local timezone for clarity |
| Expiration Date | Indicates the date when the file will automatically be moved to Trash. The file remains recoverable from the Trash until it is permanently deleted. |
| File Size | Displays the total size of the file, shown in a human-readable format (e.g., KB, MB, GB) for easy reference. |
