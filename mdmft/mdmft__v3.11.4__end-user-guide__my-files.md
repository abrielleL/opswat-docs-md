# My Files | File list

Summarize Page    Connect to Cursor Connect to VS Code

On the "My Files" page, you can view and manage your uploaded files. The file list allows for customization.

### [Sort Order](/docs/mdmft/v3.11.4/end-user-guide/my-files#sort-order)

Change the sort order by clicking on the column headers (e.g., "Name," "Upload Date," "File Size"). An arrow indicates ascending or descending order.

---

### [Adding or Removing Columns](/docs/mdmft/v3.11.4/end-user-guide/my-files#adding-or-removing-columns)

Click the "cogwheel" icon in the top right corner of the table to select which columns to display. The modified table layout will be stored automatically. You can return anytime to the factory default setting, by using the "Reset to Default" button.

---

### [Filtering Files by Upload Date](/docs/mdmft/v3.11.4/end-user-guide/my-files#filtering-files-by-upload-date)

You can filter the files easily by Clicking the "Advanced" button right next to the search field.

On the pop up select from a predefined date range, or set the preferred custom start and end date, then click on the "Apply" button.

The selected date filter can be removed by clicking on the filter label's "x" button.

---

### [Action Menu (Three-Dots Menu) for Single Files](/docs/mdmft/v3.11.4/end-user-guide/my-files#action-menu-three-dots-menu-for-single-files)

The "action" (three-dots) menu provides options for managing a single file.

Info

The action menu is unavailable for files that are currently uploading.

---

### [Favorites](/docs/mdmft/v3.11.4/end-user-guide/my-files#favorites)

Under My Files, you can click on the star icon of a **non-Blocked** file or folder to mark it as your favorite. When you click on the "Favorites" button, only items chosen as favorites will be visible in the list. To remove an item from favorites, simply click on the star icon again.

---

### [Top menu for Multiple Files](/docs/mdmft/v3.11.4/end-user-guide/my-files#top-menu-for-multiple-files)

When multiple files are selected, the top menu allows bulk operations.

Info

You can customize the "[Shared with me](/docs/mdmft/v3.11.4/end-user-guide/shared-with-me)**"** menu similarly to the "My Files" menu.
