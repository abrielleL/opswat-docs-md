# Force password Reset for Local and External Users

View as Markdown Summarize this page Ask ChatGPT about this page Ask Claude about this page Connect your AI tool
## [Overview](/docs/mdmft/v3.11.5/operating/force-password-reset-for-local-and-external-users#overview)

An Administrator or Helpdesk Administrator can force Local Users and External Users to reset their passwords at their next login. While in this state, the user cannot access any pages apart from the "Force Password Reset" page.

The Force Password Reset action can be enforced on newly created users or on already existing users.

## [Enforce on a Single User](/docs/mdmft/v3.11.5/operating/force-password-reset-for-local-and-external-users#enforce-on-a-single-user)

1. As an Administrator, go to the "Local Users" or "External Users" page
2. Create a new user or edit an existing one

3. Turn on the "Force Password Reset on Next Logon" switch

4. Click the "Continue" button to either create or edit the user

## [Enforce on multiple users](/docs/mdmft/v3.11.5/operating/force-password-reset-for-local-and-external-users#enforce-on-multiple-users)

1. As an Administrator, go to the "Local Users" or "External Users" page
2. Select multiple users from the table
3. Click the "Force Password Reset" button

4. A confirmation modal will appear, which the Administrator must confirm
