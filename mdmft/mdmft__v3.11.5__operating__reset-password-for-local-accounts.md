# Resetting the Password for Local Accounts

View as Markdown Summarize this page Ask ChatGPT about this page Ask Claude about this page Connect your AI tool
### [Overview](/docs/mdmft/v3.11.5/operating/reset-password-for-local-accounts#overview)

It is essential to have SMTP configured in MetaDefender Managed File Transfer for users to reset their passwords.

This feature is available only for local users; guests or third-party users like AD or SSO users cannot reset their passwords via these steps.

### [Steps to Reset Password](/docs/mdmft/v3.11.5/operating/reset-password-for-local-accounts#steps-to-reset-password)

1. Click the "Forgot Password?" button.

2. Enter your username or email and submit.

3. An email will be sent to the provided address. Follow the link in the email to set a new password. Once submitted, you can login with the new password.
