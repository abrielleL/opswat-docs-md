# File locking

View as Markdown Summarize this page Ask ChatGPT about this page Ask Claude about this page Connect your AI tool

If you see a "Locked until..." in the "State" column after uploading files, it means MetaDefender Managed File Transfer™ is configured to lock them for a set period. This feature, called "outbreak prevention," helps protect against false negative [scan results](/docs/mdmft/v3.11.5/end-user-guide/scan-results) and zero-day vulnerabilities.

The file will unlock automatically at the specified time.
