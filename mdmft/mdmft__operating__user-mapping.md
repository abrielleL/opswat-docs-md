# User Mapping

Summarize Page    Connect to Cursor Connect to VS Code

This feature allows you to map different users across multiple MFT systems to share and synchronize files between them.

## [Creating User Mappings](/docs/mdmft/operating/user-mapping#creating-user-mappings)

Info

The User Mapping must be set up on the destination MFT.

To use the User Mapping feature:

1. On the User Management page, click the three dots next to the user's row and choose "User Mapping" from the dropdown menu.

2. In the modal, select the user type you want to map and fill in the necessary fields to identify the user.

Info

User mapping can be added to any user type and it can be mapped from any user type.

Info

Different type of users need different kind of data for configuration

- Local user/External user – Username, Email address
- AD user – Domain, Username
- Guest user – Guest Identifier

User mappings can be imported to avoid manual entry. For more information refer to the [Import User Mapping Configuration](/docs/mdmft/configuration/import-export#import-user-mapping-configuration) page.

The User Mapping status (Yes or No) of the users can be displayed by selecting the User Mapping column in the Table View Settings menu on Local/External/Active Directory/Guest Users pages.
