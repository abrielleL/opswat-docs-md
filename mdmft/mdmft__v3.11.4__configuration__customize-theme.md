# Customize Themes

Go to "Settings" → "Customization" to configure brand-related options. Available for administrators only.

### [Selecting the Primary Logo](/docs/mdmft/v3.11.4/configuration/customize-theme#selecting-the-primary-logo)

Accepted file types: SVG, PNG, JPG and JPEG.

Recommended height-width ratio: 0.365.

Maximum size: 10 kB.

The primary logo will appear on:

- The login page and its related "Forgot Password" and "Recover Password" pages

- The "Application" sidebar, scaled to 70px height

- The "Download landing" page, scaled to 45px height

### [Hiding the "Powered By OPSWAT" Logo](/docs/mdmft/v3.11.4/configuration/customize-theme#hiding-the-powered-by-opswat-logo)

This option is available for administrators when customizing the primary logo. It provides flexibility in branding while maintaining a clean and minimalist interface.

### [Selecting a Secondary Logo](/docs/mdmft/v3.11.4/configuration/customize-theme#selecting-a-secondary-logo)

Accepted file types: SVG, PNG, JPG and JPEG.

Recommended height-width ratio: 1.

Maximum size: 10 kB.

The primary logo will only appear on the login page, next to 'Access your secure files.'

### [Selecting a Loading Animation](/docs/mdmft/v3.11.4/configuration/customize-theme#selecting--a-loading-animation)

Accepted file type: GIF.

Maximum size: 2 MB.

Maximum dimensions: 64x64 pixels.

The loading animation is used throughout the application when the UI is waiting for information to load.

Upload loading animation form element

### [Selecting a Favicon](/docs/mdmft/v3.11.4/configuration/customize-theme#selecting-a-favicon)

Accepted file types: PNG and ICO.

Maximum size: 100 KB.

Maximum dimensions: 128x128 pixels.

These restrictions ensure optimal compatibility and performance across browsers while offering flexibility in branding.

Upload Favicon form element

### [Selecting the Primary Color](/docs/mdmft/v3.11.4/configuration/customize-theme#selecting-the-primary-color)

Only colors with a significant deviation from white and red are accepted to avoid contrast issues and because the application displays critical information in red or orange. Apart from these, select any color for your login page and main menu.

### [Hiding About Info](/docs/mdmft/v3.11.4/configuration/customize-theme#hiding-about-info)

Enabling this switch under "Customize Theme" hides the question mark icon on the topbar and its menu, which provides access to the product's "About" page and documentation.

State where Hide About Info enabled

### [Customizing the Browser Tab Title](/docs/mdmft/v3.11.4/configuration/customize-theme#customizing-the-browser-tab-title)

This feature allows you to personalize the titles displayed on your browser tabs, enhancing navigation efficiency and user experience.

## [Reverting to OPSWAT branding](/docs/mdmft/v3.11.4/configuration/customize-theme#reverting-to-opswat-branding)

You can always revert to the initial images and primary color by clicking 'Reset' at the header of the page.
