# UpdateCredentials tool - Cannot re-enable users

View as Markdown Summarize this page Ask ChatGPT about this page Ask Claude about this page Connect your AI tool

The mentioned tool can disable users but cannot re-enable them due to an error. By copying the **lms-license-net.dll** file from *"OPSWAT\MetaDefender Managed File Transfer\Services"* folder next to the **UpdateCredentials.exe** will solve the problem
