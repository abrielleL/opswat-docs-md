# How to restore access in case of broken third-party authentication?

View as Markdown Summarize this page Ask ChatGPT about this page Ask Claude about this page Connect your AI tool

1. You can restore administrator access by enabling a local administrator using the "UpdateCredentials" tool. Refer to the [Using the UpdateCredentials tool to change the username, email, enabled status or password for local administrator users](/docs/mdmft/v3.11.5/knowledge-base/how-can-an-administrator-password-be-changed#using-the-updatecredentials-tool-to-change-the-username-email-enabled-status-or-password-for-local-administrator-users) for guidance.
2. Fix or reconfigure third-party authentication.

Warning

You must know the username and password for the local administrator you want to enable using the "UpdateCredentials" tool.

Info

The last local administrator cannot be deleted but can be disabled.
