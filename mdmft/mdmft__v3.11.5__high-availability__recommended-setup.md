# Recommended Setup

View as Markdown Summarize this page Ask ChatGPT about this page Ask Claude about this page Connect your AI tool

Every component is installed on different hosts. Only the HA controller is open to external network. Both nodes should be able to reach the database and file storage. The MetaDefender MFT HA Controller™ should reach the nodes.
