# Installing MetaDefender Managed File Transfer

Summarize Page    Connect to Cursor Connect to VS Code
## [Before Installation](/docs/mdmft/installation/installing-metadefender-managed-file-transfer#before-installation)

Before beginning the installation, ensure that the  [MetaDefender Managed File Transfer System Requirements](/docs/mdmft/installation/system-requirements) are met. If you are installing MetaDefender Managed File Transfer™ on the same server as MetaDefender Kiosk™ and/or MetaDefender Core™, the server must meet the combined system requirements of all the products.

## [Installation](/docs/mdmft/installation/installing-metadefender-managed-file-transfer#installation)

1. Download the installer from My OPSWAT™ on MetaDefender Managed File Transfer™ section.
2. Install on a computer by using the [Command Line](/docs/mdmft/installation/installing-from-command-line) or the [Install Wizard](/docs/mdmft/installation/installing-using-the-install-wizard).
3. Open a web browser—or click "Launch" when using the Install Wizard—and navigate to <http://localhost:8010>
4. Complete [Setup Wizard - Post-Installation Configuration](/docs/mdmft/installation/post-installation-configuration)

## [Deployment with MetaDefender Kiosk™ and MetaDefender NetWall®](/docs/mdmft/installation/installing-metadefender-managed-file-transfer#deployment-with-kiosk_product_name-and-netwall_product_name)

MetaDefender Managed File Transfer™ seamlessly integrates with MetaDefender Kiosk™ to protect your network by controlling the flow of data in and out of your organization. MetaDefender Kiosk™ can serve as a media scanning station on your own hardware or on OPSWAT®'s custom-made kiosks. Media such as USB devices, DVDs, card readers, SD cards, flash drives, or floppy disks, are scanned by MetaDefender Kiosk™ by inserting the media device into the appropriate drive. The installation process includes:

- [Install Metadefender Kiosk](/docs/mdmft)
- [Configuring Kiosk to integrate to MetaDefender Managed File Transfer](/docs/mdmft)
