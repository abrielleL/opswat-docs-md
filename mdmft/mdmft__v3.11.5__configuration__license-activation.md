# License Activation

View as Markdown Summarize this page Ask ChatGPT about this page Ask Claude about this page Connect your AI tool

Without a valid license, users cannot log in or upload files. Administrators can perform the product configuration.

For full functionality, ensure expected behavior and stay compliant with the OPSWAT terms and conditions. You must have a valid license activated and enough number of users associated with it.

### [Online License Activation](/docs/mdmft/v3.11.5/configuration/license-activation#online-license-activation)

1. Go to "Settings"→"Security"→"License." Click the "Activate" button or go to "User Settings"→"About the Product."
2. Go to "License information" and click the "Activate" button.
3. Check "Online activation" and enter your license key.

4. Click "Activate Online."

### [Offline License Activation](https://docs.opswat.com/mdvault/installation/activating-metadefender-vault-by-applying-the-license#offline-license-activation)

1. Go to "Settings" → "Security" → "License" and click the "Activate" button.
2. Select "Offline activation".

3. Copy the Deployment ID.

4. Go to My OPSWAT (<https://my.opswat.com>) and click "Active License" on the left hand side menu.
5. Select MetaDefender Managed File Transfer from the Product dropdown, enter the license key and Deployment ID from MetaDefender Managed File Transfer UI.

6. Click "Activate key" and download the license file.
7. Return to MetaDefender Managed File Transfer and upload the license file by clicking "Choose file".

Info

If you have troubles with your activation and your calendar is not Gregorian, please follow the guide [here](/docs/mdmft/v3.11.5/troubleshooting/licensing)

## [Multiple Activations with the Same License Key](/docs/mdmft/v3.11.5/configuration/license-activation#multiple-activations-with-the-same-license-key)

MetaDefender Managed File Transfer does not support multiple activations with the same key on multiple systems. You must obtain a separate key for each system.

## [Transferring License Key to a Different System](/docs/mdmft/v3.11.5/configuration/license-activation#transferring-license-key-to-a-different-system)

To transfer a license to a different system, deactivate the key on the original system first.

Warning

If systems are not connected to the Internet, deactivations will fail.
