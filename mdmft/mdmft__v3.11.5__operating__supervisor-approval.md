# Supervisor Approval

View as Markdown Summarize this page Ask ChatGPT about this page Ask Claude about this page Connect your AI tool

Supervisors have exclusive access to the "Pending Approvals" and "Approval History" sections. In these areas, supervisors can efficiently review files awaiting approval and track and reference previously approved files. This ensures transparency and accountability in the file management process.

As a supervisor, you have the authority to:

- Preview files
- Download files
- Revoke file access
- Approve files
- Attach messages to files
