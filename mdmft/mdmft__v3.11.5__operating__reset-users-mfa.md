# Resetting users' MFA

View as Markdown Summarize this page Ask ChatGPT about this page Ask Claude about this page Connect your AI tool

The "Reset MFA" option will appear only for users who have already set up the TOTP client application.

1. Click the three dots next to the user's name and select "Reset MFA."

2. Confirm the action when prompted.

Info

Upon completion, users will need to reconfigure their TOTP client.
