# Can an Admin Check Per-User Storage Usage in MetaDefender Managed File Transfer?

View as Markdown Summarize this page Ask ChatGPT about this page Ask Claude about this page Connect your AI tool

**Check Your Version:**

This article applies to all MetaDefender Managed File Transfer releases.

MetaDefender Managed File Transfer does not have a dedicated report listing storage usage per user. To track an individual user's usage, enable the **Upload Quota** feature under **Settings > File Settings**. Once enabled, each user's current storage status is shown in their user information dropdown.

The user information dropdown showing current storage usage (9.02 MB of 10.00 GB used).

For overall capacity, the **System Dashboard** shows used and free space across all storage types, but this is system-wide and not broken down by user.
