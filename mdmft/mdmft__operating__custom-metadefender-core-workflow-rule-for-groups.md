# Custom MetaDefender Core Workflow Rule for Groups

Summarize Page    Connect to Cursor Connect to VS Code

To apply distinct MetaDefender Core Workflow rules to specific groups, navigate to the "Groups" menu.

Info

The dropdown list only displays workflows available on every MetaDefender Core™.

## [Assigning Core Workflow Rules to Groups](/docs/mdmft/operating/custom-metadefender-core-workflow-rule-for-groups#assigning-core-workflow-rules-to-groups)

1. Navigate to the "Users/Groups" menu
2. Click the three dots next to the desired group and select "Edit Group"

3. In the modal, disable the "Use Default Workflow Settings" option and select the desired workflow rule

4. You can also set a display name for the selected group.

Info

If set, the display name will be shown to users instead of the group's original name when they select the group for file approval.
