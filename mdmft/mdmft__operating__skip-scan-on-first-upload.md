# Skipping Scan on Upload

Summarize Page    Connect to Cursor Connect to VS Code
## [Overview](/docs/mdmft/operating/skip-scan-on-first-upload#overview)

In situations where upload speed is a priority and scan results can be delayed, enabling the "Skip Scan on upload" option allows files to bypass the initial scan during upload.

Important

While this expedites file availability, it carries the risk of missing malicious files during the initial upload. Therefore, it is recommended to use this option cautiously.

Files can be scanned later, either manually or through scheduled rescans.

## [Setup](/docs/mdmft/operating/skip-scan-on-first-upload#setup)

When creating or updating a local or external user, the "Skip Scan on upload" option can be configured under the user information tab. This setting affects future uploads only.
