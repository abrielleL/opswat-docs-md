# Installing MetaDefender Managed File Transfer

View as Markdown Summarize this page Ask ChatGPT about this page Ask Claude about this page Connect your AI tool
## Before Installation

Before beginning the installation, ensure that the  [MetaDefender Managed File Transfer System Requirements](/installation/system-requirements) are met. If you are installing MetaDefender Managed File Transfer™ on the same server as MetaDefender Kiosk™ and/or MetaDefender Core™, the server must meet the combined system requirements of all the products.

## Installation

1. Download the installer from My OPSWAT™ on MetaDefender Managed File Transfer™ section.
2. Install on a computer by using the [Command Line](/installation/installing-from-command-line) or the [Install Wizard](/installation/installing-using-the-install-wizard).
3. Open a web browser—or click "Launch" when using the Install Wizard—and navigate to <http://localhost:8010>
4. Complete [Setup Wizard - Post-Installation Configuration](/installation/post-installation-configuration)

## Deployment with MetaDefender Kiosk™ and MetaDefender NetWall®

MetaDefender Managed File Transfer™ seamlessly integrates with MetaDefender Kiosk™ to protect your network by controlling the flow of data in and out of your organization. MetaDefender Kiosk™ can serve as a media scanning station on your own hardware or on OPSWAT®'s custom-made kiosks. Media such as USB devices, DVDs, card readers, SD cards, flash drives, or floppy disks, are scanned by MetaDefender Kiosk™ by inserting the media device into the appropriate drive. The installation process includes:

- [Install Metadefender Kiosk](docs/mdkiosk/installation/installing---upgrading-metadefender-kiosk)
- [Configuring Kiosk to integrate to MetaDefender Managed File Transfer](docs/mdkiosk/configuration/configuring-with-metadefender-vault)

## Deployment with My OPSWAT™

MetaDefender Managed File Transfer™ seamlessly integrates with My OPSWAT™ to support global operations for OPSWAT products.

End of Life

OPSWAT Central Management version 7 and My OPSWAT On-premises (Central Management version 8) will reach [End of Life on 01/31/2027](https://www.opswat.com/docs/ocm/knowledgebase/end-of-sale-and-end-of-life-cm7-and-cm8). MetaDefender Managed File Transfer™ will also discontinue support for these in versions released beyond that date.
