# Signing In as a Guest User

Summarize Page    Connect to Cursor Connect to VS Code

Guest users should select the "Guest" tab on the login page and enter their identifier, which they can obtain from their host or contact person, or from an email sent to their guest account.

Info

To learn how to create guest users, click [here](/docs/mdmft/end-user-guide/guest-users).
