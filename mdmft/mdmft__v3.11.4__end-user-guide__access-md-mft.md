# Accessing MetaDefender MFT

Summarize Page    Connect to Cursor Connect to VS Code

MetaDefender Managed File Transfer™ (MFT) is a web-based application optimized for modern web browsers such as Edge, Chrome, Firefox, and Safari.

To securely access your files via the MetaDefender® MFT application, open a web browser, navigate to the MetaDefender MFT platform, and log in.

Initial Access:

- **Web link**: You should have received a welcome email containing a link to the MetaDefender® MFT application and a separate email with your login credentials.
- **URL**: If you haven't received a link, request the MetaDefender® MFT URL from your administrator and enter it into your browser. Once the login page appears, bookmark it for future use.
