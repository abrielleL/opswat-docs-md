# External Users

### [Creating External Users](/docs/mdmft/end-user-guide/external-users#creating-external-users)

External user accounts are for sharing files with partners or organizations on a long-term basis. External users cannot see internal users and can only share files with their creator.

1. Go to the "Users" menu and select "External Users." $plugin[fjwoux2te1f]

2. In the "Create new user" window, enter a username, email, and password.

3. In the "Personal Information" tab, set the "Expiration date" (may be disabled depending on settings) and enter the first name and last name.

4. Click "Create" to finish creating the external user account.

Info

The user will receive a welcome message with a link to MetaDefender® MFT and the credentials for [signing in](/docs/mdmft/end-user-guide/sign-in-as-local-user).

### [Managing External Users](/docs/mdmft/end-user-guide/external-users#managing-external-users)

To manage external users, go to the "Users" menu and select "External Users."

The three-dot menu offers the following options:

- **Edit:** Allows you to edit the **expiration date** (may be disabled depending on settings), **user name**, **email**, **first name**, and **last name**
- **Change password**: Allows you to update the user's password
- **Disable/Enable:** Disables the account to prevent login, or enables it again
- **Delete:** Deletes the guest account if it is no longer needed
