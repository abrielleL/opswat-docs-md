# How long is the support lifecycle for a specific version of MetaDefender Managed File Transfer?

View as Markdown Summarize this page Ask ChatGPT about this page Ask Claude about this page Connect your AI tool Check Your Version

This article applies to all MetaDefender Managed File Transfer™ releases.

OPSWAT provides support for each release of MetaDefender Managed File Transfer™ for 18 months *after the next release* of the product is published. Once a new release is available, support continues for the previous release for 18 months.

However, bug fixes and enhancements are applied only to the next release, not to the current or older releases, even if they are still under support.

In some cases, hot-fixes may be provided for the current release and then incorporated as regular fixes in the next release.

Pro Tip:

OPSWAT highly recommends upgrading regularily to the latest version of MetaDefender Managed File Transfer and not waiting until the end of a release’s support cycle.

Current versions incorporate state-of-the-art features and necessary bug fixes and are freely available for all license holders to download.

To upgrade, follow these steps:

1. Browse [Release Notes](/docs/mdmft/v3.11.5/release-notes/release-notes) for details on the latest MetaDefender Managed File Transfer™ version.
2. Visit [**My OPSWAT**](https://my.opswat.com) to download the new version under the relevant package license.

If upgrading from an older release, visit [Upgrading MetaDefender Managed File Transfer](/docs/mdmft/v3.11.5/installation/updating-and-upgrading).
