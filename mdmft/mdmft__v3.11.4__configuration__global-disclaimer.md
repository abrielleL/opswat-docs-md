# Global Disclaimer

Summarize Page    Connect to Cursor Connect to VS Code

The Global Disclaimer allows administrators to display a custom message to all users at the top of every page. It can be configured under **Settings →** **Customization → Global Disclaimer**.

### [Configuration](/docs/mdmft/v3.11.4/configuration/global-disclaimer#configuration)

**Show Global Disclaimer** — Toggle to enable or disable the disclaimer. When enabled, the message is visible to all users on all pages of the product.

When enabled, the following options become available:

**Show disclaimer on login page** — When checked, the disclaimer is also displayed on the login page, before users authenticate.

**Disclaimer Title** — A short heading shown above the disclaimer text. Maximum 30 characters.

**Disclaimer Description** — The main body of the disclaimer message shown to users. Maximum 500 characters. A live character counter is displayed as you type.

Warning

The disclaimer will be hidden when MetaDefender Managed File Transfer™ is unlicensed, over-licensed, or nearing expiration.
