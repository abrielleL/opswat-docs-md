# Shared with me

Summarize Page    Connect to Cursor Connect to VS Code

Files and folders shared with you by other MetaDefender Managed File Transfer™ users can be found under "Overview" --> "Shared With Me."

Depending on what is the Role the file/folder is shared with you, you can have different actions available.

## [Share Role permissions](/docs/mdmft/v3.11.4/end-user-guide/shared-with-me#share-role-permissions)

Info

*Can move only to folders which belongs to the same user as the item(s) to be moved.

**Deleted files will be moved into trash bin of owner.

***The owner of the uploaded files will be the user who shared the folder.

Info

The file list in the "Shared With Me" menu can be customized similarly to the "[My Files](/docs/mdmft/v3.11.4/end-user-guide/my-files)" menu.
