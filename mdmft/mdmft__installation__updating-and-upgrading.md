# Upgrading MetaDefender Managed File Transfer

Summarize Page    Connect to Cursor Connect to VS Code
## [Before upgrading](/docs/mdmft/installation/updating-and-upgrading#before-upgrading)

It's highly encouraged that you [create a backup manually](/docs/mdmft/installation/updating-metadefender-managed-file-transfer).

## [Upgrading](/docs/mdmft/installation/updating-and-upgrading#upgrading)

1. Download the installer from My OPSWAT™ from MetaDefender Managed File Transfer™ section.
2. Launch the installer on a computer with an existing installation by using the [Command Line](/docs/mdmft/installation/installing-from-command-line) or the [Install Wizard](/docs/mdmft/installation/installing-using-the-install-wizard).
