# Can MetaDefender Managed File Transfer (MFT) be installed on Linux/Ubuntu?

Summarize Page    Connect to Cursor Connect to VS Code

**Check Your Version:**

This article applies to all MetaDefender Managed File Transfer releases.

### [**Answer**](/docs/mdmft/knowledge-base/can-metadefender-managed-file-transfer--mft--be-installed-on-lin#answer)

**No.** MetaDefender Managed File Transfer 3.11.0 is **Windows-only** and is not available for Linux, Ubuntu, or any other Unix-based operating system.

### [**Supported Operating Systems:**](/docs/mdmft/knowledge-base/can-metadefender-managed-file-transfer--mft--be-installed-on-lin#supported-operating-systems)

- Microsoft Windows Server 2019
- Microsoft Windows Server 2022
- Microsoft Windows Server 2025
- Architecture: 64-bit only

Warning:
Windows Desktop editions (Windows 10, Windows 11, etc.) are **not** supported, per Microsoft licensing terms that prohibit using Desktop editions as servers.
