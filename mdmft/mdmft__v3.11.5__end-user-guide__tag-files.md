# Tagging Files

View as Markdown Summarize this page Ask ChatGPT about this page Ask Claude about this page Connect your AI tool

Tags are keywords that make it easier to [find your files](/docs/mdmft/v3.11.5/end-user-guide/search) later.

1. Click the "action" menu (three dots) next to the file name on the right.
2. Select "Edit file tags."

3. Enter a new tag in the text box and click "Add tag." To remove a tag, click the "x" next to it.

Search

You can [search](/docs/mdmft) for files using these tags.

Info

*Tag search is case insensitive*, so tags like "MyProject" or "myproject" will return the same results.

You can assign up to *20 tags to each file*, and a tag can be up to *50 characters* long.
