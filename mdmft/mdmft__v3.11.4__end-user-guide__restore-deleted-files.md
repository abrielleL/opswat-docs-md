# Restoring Deleted Files (Recycle Bin)

Summarize Page    Connect to Cursor Connect to VS Code

You can restore files that you have deleted and sent to the Recycle Bin.

Warning

Files permanently deleted will not be moved to the Recycle Bin and therefore cannot be restored.

Retention period

Files in the Recycle Bin are automatically deleted after a specified period, which you can check on the Recycle Bin page.

### [Restoring a Single File](/docs/mdmft/v3.11.4/end-user-guide/restore-deleted-files#restoring-a-single-file)

1. Select "Recycle Bin" from the side menu.
2. Click on the "action" menu (three dots) next to the file on the right.
3. Select "Restore File" from the menu.

Info

You can also download any file from the Recycle Bin directly, just as you would from the "My Files" page, without needing to restore them first—unless the file is marked as "Blocked."

---

### [Restoring Multiple Files at Once](/docs/mdmft/v3.11.4/end-user-guide/restore-deleted-files#restoring-multiple-files-at-once)

1. Select "Recycle Bin" from the side menu.
2. Check the checkboxes next to the files you want to restore.
3. A menu will appear above the table.
4. Click "Restore" in the menu above the table.

Info

Folder structures cannot be restored; only the files within the folders are moved to the Recycle Bin.
