# How can an administrator password be changed?

Summarize Page    Connect to Cursor Connect to VS Code

To change the username, email, password, or enabled status for local administrator users, use the *UpdateCredentials* tool.

You can find the tool in the "Tools" directory of your installation. The default location is at: *C:\Program Files\OPSWAT\MetaDefender Managed File Transfer\Tools*.

Info

This tool must be run on the same machine where MetaDefender Managed File Transfer is installed.

Only local administrator accounts can be changed.

To change the local administrator account:

1. Run the tool and login using the credentials of the administrator account you want to modify.
2. If the password is correct you can enter a new username, email, or password, and change the enabled status.
3. Click "Update credentials."
4. Close the tool. You will now be able to log in using the updated username or password.
