# Searching Files

View as Markdown Summarize this page Ask ChatGPT about this page Ask Claude about this page Connect your AI tool

Search for files and folders using file names, folder names, or [tags](/docs/mdmft/v3.11.5/end-user-guide/tag-files) as keywords.

Enter the keywords into the search field, and the file list will update accordingly.

Info

The search function is case insensitive and can find partial word matches.
