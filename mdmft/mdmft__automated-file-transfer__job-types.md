# Available Job Types

Summarize Page    Connect to Cursor Connect to VS Code

MetaDefender Managed File Transfer offers a growing set of predefined job types to automate recurring tasks, replacing manual processes with well-configured, automatically executed jobs.

---

[SFTP - Pull Files](/docs/mdmft/automated-file-transfer/sftp---pull-files)

Automatically pull files from remote source using SFTP into MetaDefender MFT.

[SFTP - Push Files](/docs/mdmft/automated-file-transfer/sftp---push-files)

Automatically push files to a remote host using SFTP from MetaDefender MFT.

---

[MFT - Pull Files](/docs/mdmft/automated-file-transfer/mft---pull-files)

Automatically pull files from a remote MetaDefender Managed File Transfer™ instance.

[MFT - Push Files](/docs/mdmft/automated-file-transfer/mft---pull-filesw8h)

Automatically push files to a remote MetaDefender Managed File Transfer™ instance.

Difference from MFT to MFT

Unlike the system-level MFT-to-MFT mirroring functionality, using Automated Jobs transfers files only from the specified sources set up by the users who have defined these jobs.

---

[SMB - Pull Files](/docs/mdmft/automated-file-transfer/smb-pull-files)

Automatically pull files from a remote file share using SMB protocol into MetaDefender® MFT.

[SMB - Push Files](/docs/mdmft/automated-file-transfer/smb-push-files)

Automatically push files to a remote MetaDefender Managed File Transfer™ instance.
