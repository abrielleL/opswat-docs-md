# Global Jobs Configuration

View as Markdown Summarize this page Ask ChatGPT about this page Ask Claude about this page Connect your AI tool

Clicking the "Configure" button on the [Jobs Overview](/docs/mdmft/v3.11.5/automated-file-transfer/jobs-overview) page opens the global jobs configuration modal, allowing users to set system-level parameters for automated job execution.

**Execution History Retention**

Users can configure how long to retain historical information for automated jobs. Job execution details older than the specified number of days will be automatically removed.
