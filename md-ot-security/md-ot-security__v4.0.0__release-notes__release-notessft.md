# Version 3.5.0

| **Version** | 3.5.0 |
| --- | --- |
| **Release date** | 30 October 2025 |
| **Scope** | Enhance current features and add new features. |

## [New Features, Improvements and Enhancements](/docs/md-ot-security/v4.0.0/release-notes/release-notessft#new-features-improvements-and-enhancements)

|  | Details |
| --- | --- |
| **Alert Workflow Management** | Introduced an end-to-end alert handling process — *Policy/ Rule → Alert → Incident → Response* with incorporation of MITRE ATT&CK techniques. Supports contextualized alert filtering to help analysts focus on the most relevant threats. |
| **Japanese Language Support** | Added full user interface localization for Japanese, improving accessibility for local teams and regional deployments. |
| **AI-Enhanced Data Query with Natural Languages** | Allowed users to interact with the system through natural languages questions for device/ asset info. The AI helps interpret queries and return relevant data insights or statistics, making information retrieval faster, more flexible and intuitive. |
| **Detection of Critical Commands sent to ICS devices** | Added the function to detect abnormal or unexpected critical command sent to industrial control systems (ICS) devices, helping prevent unauthorized operations or potential process disruptions. |
| **Integration with OPSWAT Cloud NAC** | Added integration with OPSWAT Cloud NAC for enhanced network access control and visibility across connected devices. |
| **Detection of duplication of device’s identifiable property via network connections** | Added the function to detect duplicated device properties (e.g., MAC, IP, hostname) in network connections to identify spoofed or cloned devices, and network attacks |
| **Smart Asset Profiling for Yokogawa PLCs** | Extended Smart Asset Profiling capabilities to Yokogawa PLCs, enabling detailed identification and classification of industrial assets. |
| **Exclude Network Traffic from Passive Discovery** | Allowed administrators to define network segments or traffic types to be excluded from passive discovery, reducing noise and improving discovery accuracy. |
| **Customizable PCAP Capture Duration** | Added the ability to set custom time intervals for PCAP file captures during network testing, providing greater flexibility for troubleshooting and diagnostics. |
| **General Improvements** | Included various UI improvements, performance optimizations and bug fixes to enhance performance, reliability and user experience. |
