# Enterprise - Custom Fields

The **Custom Fields** setting is accessible under **Settings > Custom Fields.**

In this section, you can add more new Custom Fields to the Asset

Users can choose Enable All or Disable All to display Custom Fields in Asset or not

Users can create New Custom Fields, and delete or edit them. When editing custom fields, users only can edit Label and Placeholder.
