# OT Security - How to create support package?

Steps to Generate a Support Package

1. Navigate to **Settings**

   1. Log in to your OT Security console.
   2. Click the **User Menu** in the top-right corner.
   3. Select **Settings** from the dropdown list.
2. Go to **Support Package**

   1. On the **Settings** page, look for the **Support Package** tab or button.
   2. Click on **Support Package**.
3. Follow On-Screen Instructions

   1. **Prepare a USB drive** (if required) and ensure it is plugged into the machine.
   2. Click **Create Support Package** to start generating the logs.
   3. **Wait** for the creation process to complete.
   4. Once finished, if you are using a USB drive, **unplug** it after the process completes.
4. (Optional) Copy the Support Package

   - If you need to transfer the logs to another location or share them, you can click **Copy Support Package** to move it from the OT Security system to a USB drive or other storage medium.
