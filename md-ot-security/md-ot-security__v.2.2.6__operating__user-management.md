# User Management

The user management is accessible under **Investigate → User Management**

In the MetaDefender OT Security application, user can take one of the three following roles : **Super admin**, **Admin** and **Operator.**

To create a new account, click on the plus (+) button on the top right, then enter username, role, password, display name and email address. The username will be used to enter the system.
