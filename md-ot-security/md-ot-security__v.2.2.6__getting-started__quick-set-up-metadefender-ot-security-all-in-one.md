# Quick set up MetaDefender OT Security All-in-One

## [1. Set up the stand](/docs/md-ot-security/v.2.2.6/getting-started/quick-set-up-metadefender-ot-security-all-in-one#1-set-up-the-stand)

## [2. Route the power cable through the stand then connect the power cable](/docs/md-ot-security/v.2.2.6/getting-started/quick-set-up-metadefender-ot-security-all-in-one#2-route-the-power-cable-through-the-stand-then-connect-the-power-cable)

## [3. Connect ethernet port (built-in) for passive scanning.](/docs/md-ot-security/v.2.2.6/getting-started/quick-set-up-metadefender-ot-security-all-in-one#3-connect-ethernet-port-built-in-for-passive-scanning)

We recommend using the ethernet port for passive scanning to have better performance.

## [4. Connect 2 usb-to-ethernet adapters (NIC01 for active and NIC02 for internet).](/docs/md-ot-security/v.2.2.6/getting-started/quick-set-up-metadefender-ot-security-all-in-one#4-connect-2-usb-to-ethernet-adapters-nic01-for-active-and-nic02-for-internet)

Please note that NIC for active scanning will connect to the normal port (not mirror port) on Switch.

Press the power button to start MetaDefender OT Security application and continue with Quickstart Guide](/docs/md-ot-security/v.2.2.6/getting-started/quick-set-up-metadefender-ot-security-all-in-one#5-press-the-power-button-to-start-metadefender-ot-security-application-and-continue-with-quickstart-guide)
