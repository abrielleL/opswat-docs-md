# Generate CIP Report

## [How to generate a CIP Report](/docs/md-ot-security/reports/generate-cip-report#how-to-generate-a-cip-report)

This guide provides step-by-step instructions on generating a CIP (Critical Infrastructure Protection) report using the system.

### [1. Navigating to the Reports Page](/docs/md-ot-security/reports/generate-cip-report#1-navigating-to-the-reports-page)

1. Locate the **Reports** page from the main menu or navigation bar.
2. Click on the **Saved** **Report** page to proceed

### [2. Initialing CIP Report Generation](/docs/md-ot-security/reports/generate-cip-report#2-initialing-cip-report-generation)

1. On the **Saved** **Report** page, locate the **Generate CIP Report** button in the top-right corner of the screen.
2. Click the **Generate CIP Report** button to start the process.

### [3. Capturing the Network Map](/docs/md-ot-security/reports/generate-cip-report#3-capturing-the-network-map)

Before generating the CIP report, you must capture the **Network Map** as prompted:

1. After clicking the **Generate CIP Report** button, a popup will appear with instructions.
2. Navigate to the **Network Map** page from the main menu or navigation bar.
3. On the **Network Map** page, clicking on the icon to capture.

4. Once the **Network Map** is successfully captured, you can proceed to the next step.

### [4. Completing the CIP Report Generation](/docs/md-ot-security/reports/generate-cip-report#4-completing-the-cip-report-generation)

1. Return to the **Saved** **Report** page.
2. Click the **Generate CIP Report** button again to finalize the report.
3. The system will process the request and generate the CIP report.

### [5. Downloading the CIP Report](/docs/md-ot-security/reports/generate-cip-report#5-downloading-the-cip-report)

This is the same with Downloading Report of Report Export and Management Guide.
