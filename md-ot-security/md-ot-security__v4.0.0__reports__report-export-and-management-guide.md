# Report Export and Management Guide

### [1. Overview](/docs/md-ot-security/v4.0.0/reports/report-export-and-management-guide#1-overview)

The system provides functionality to export system settings, device data, scanned/learned information, and policies. This guide outlines the steps to generate, manage, and download these reports effectively.

## [2. Exporting Reports](/docs/md-ot-security/v4.0.0/reports/report-export-and-management-guide#2-exporting-reports)

### [2.1. Saving Reports](/docs/md-ot-security/v4.0.0/reports/report-export-and-management-guide#21--saving-reports)

1. Navigate to any page where exporting is supported.
2. Click the **Save Report** button located at the top-right corner.

1. Select the desired file format for the report.

- Supported Formats

  - **CSV**: Suitable for data analysis in spreadsheet applications.
  - **PDF**: Ideal for sharing and presentation purposes.

### [2.2. Storing Reports](/docs/md-ot-security/v4.0.0/reports/report-export-and-management-guide#22-storing-reports)

- Once saved, all generated reports are automatically stored on the **Reports** page

## [3. Downloading Reports](/docs/md-ot-security/v4.0.0/reports/report-export-and-management-guide#3-downloading-reports)

### [3.1. Step to Download](/docs/md-ot-security/v4.0.0/reports/report-export-and-management-guide#31-step-to-download)

1. Navigate to the **Reports** page.
2. Locate the desired report file. You can use filters or the search bar for convenience:

   - **Filters:** Filter by file type or download date.
   - **Search:** Search reports by their name.

1. Check the box next to the file(s) you want to export.

4. Click the **Download** button to save the file(s)
