# Workaround for setting the time in UTC on the BIOS

Steps:

1. Power off the system.
2. Power the system on and quickly press the "F2" button until you see the BIOS setting menu
3. Navigate to Integrated Device.
4. Adjust the time to UTC+0.
5. Click Apply Changes then wait for the system to start.

**Note**: from version ***2.2.0*** we have support for setup time.
