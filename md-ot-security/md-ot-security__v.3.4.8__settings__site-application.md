# Site - Application

The application setting is accessible under **Settings > Application.**

## [Operations](/docs/md-ot-security/v.3.4.8/settings/site-application#operations)

### [Display options for historical connections and alerts associated with removed assets](/docs/md-ot-security/v.3.4.8/settings/site-application#display-options-for-historical-connections-and-alerts-associated-with-removed-assets)

Choose whether to hide or show connections and alerts associated with removed assets.

### [Chart](/docs/md-ot-security/v.3.4.8/settings/site-application#chart)

Configure chart display.

Number of protocols displayed on charts (prioritize ICS protocols)

### [Asset Learning Duration](/docs/md-ot-security/v.3.4.8/settings/site-application#asset-learning-duration)

Every device in the network scanned into MetaDefender OT Security will be assigned a default compulsory learning period. After completing the learning hours, if Anomaly Detection mode is not enabled, MetaDefender OT Security will either continue to learn the device's behavior or not.

## [System Setting](/docs/md-ot-security/v.3.4.8/settings/site-application#system-setting)

### [Sound volume](/docs/md-ot-security/v.3.4.8/settings/site-application#sound-volume)

Adjust the volume of on-screen alerts.

### [Disk space check](/docs/md-ot-security/v.3.4.8/settings/site-application#disk-space-check)

Show the amount of data currently stored. Claim more disk space to delete unimportant and temporary data when free disk space is low.

### [Operation time info](/docs/md-ot-security/v.3.4.8/settings/site-application#operation-time-info)

Information on the time operation of MetaDefender OT Security: Timezone, First run, Last restarted
