# Version 3.6.2

| **Version** | 3.6.2 |
| --- | --- |
| **Release date** | 30 January 2026 |
| **Scope** | Enhance current features and add new features. |

## [New Features, Improvements, and Enhancements](/docs/md-ot-security/release-notes/release-notes#new-features-improvements-and-enhancements)

|  | Details |
| --- | --- |
| **Enhance Anomaly Detection** | Allow users to turn on anomaly detection with specific conditions:   1. For all assets in one sensor 2. For a subnet (CIDR) 3. For a specific IP address 4. For a specific device type |
| **System Health Monitoring** | Added system health monitoring to track the status and performance of core components, helping administrators proactively identify issues and maintain system stability. |
| **CVE DB versioning** | Implemented versioning for the CVE database, allowing better tracking of updates, easier troubleshooting, and improved consistency in vulnerability management. |
| **General Improvements** | Included various UI improvements, performance optimizations, and bug fixes to enhance performance, reliability and user experience. |
