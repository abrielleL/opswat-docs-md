# User Activity Logging

The **User Activity Logging** feature in **MetaDefender OT Security** provides a detailed audit trail of user actions, helping administrators track system activity.

To manage User Activity Logging in **MetaDefender OT Security**, navigate to: **User Management → User Activity Logging** in the Web Management interface.

## [Key Information Displayed](/docs/md-ot-security/v4.0.0/user-management/user-activity-logging#key-information-displayed)

### [**Compact View**](/docs/md-ot-security/v4.0.0/user-management/user-activity-logging#compact-view)

The **Compact View** provides a summarized version of user activities, displaying:

| Field | Description |
| --- | --- |
| **Action Time** | Timestamp of the logged action. |
| **User/Actor** | The username of the individual acting. |
| **Action** | The specific action performed (e.g., login, logout, enable/disable features, etc.). |
| **Action Status** | Status of the action (**SUCCESS**, **FAILED**, etc.) |

### [**Extended View**](/docs/md-ot-security/v4.0.0/user-management/user-activity-logging#extended-view)

For a **detailed log analysis**, switch to **Extended View** by clicking the **Extended View** button. This mode provides more fields.

## [**Features & Actions**](/docs/md-ot-security/v4.0.0/user-management/user-activity-logging#features--actions)

**Login/Logout Tracking** – Logs all authentication events.

**Configuration Changes** – Tracks modifications to settings or assets.

**Extended View** – Click the **Extended View** button to see detailed logs.

**Filtering & Sorting** – Use filters to refine logs by **date, user, or action type**.
