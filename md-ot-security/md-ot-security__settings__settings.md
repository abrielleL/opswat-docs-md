# Settings

Available when clicking on “…” → Settings at the top right corner.

This page allows user to adjust settings for the MetaDefender OT Security system, including:

- Discovery: configure your Network Interface Cards and scanning settings.
- Network topology: configure for network devices and simulation of their physical linkage.
- Alert: choose the way alert is displayed and where the reports are sent.
- Device type: configure smart active scanning and alert rules for devices.
- Protocol: set color for protocols.
- Site: create site of device.
- Update: choose the way to update application.
- License: manage license activation.
- Application: set archive settings for connection, reboot AIO machine or reset all data.
- Support package: create and store the support package file to usb drive.
