# MetaDefender Industrial Firewall & IPS Overview

The list of MetaDefender Industrial Firewall & IPS is accessible under MetaDefender Industrial Firewall & IPS menu

The list of MetaDefender Industrial Firewall & IPS contains all the information about MetaDefender Industrial Firewall & IPS in the system.

### [The part **Summary** displays statistics about:](/docs/md-ot-security/v.2.2.6/operating/mdfirewall-overview#the-part-summary-displays-statistics-about)

- Total connected MetaDefender Industrial Firewall & IPS: Total number of connected MetaDefender Industrial Firewall & IPS.
- Updates available: Total number of MetaDefender Industrial Firewall & IPS having new versions need to be updated.
- Protected PLCs: Total number of PLCs that are protected in the system.
- Unacknowledged events: Total number of unacknowledged events.
- Low disk alerts: Total number of alerts related to the free space of the disk.
- Full memory alerts: Total number of alerts related to full memory.

### [Modes](/docs/md-ot-security/v.2.2.6/operating/mdfirewall-overview#modes)

This field displays a summary of the connected MetaDefender Industrial Firewall & IPS mode.

### [Versions](/docs/md-ot-security/v.2.2.6/operating/mdfirewall-overview#versions)

This field displays a summary of the connected MetaDefender Industrial Firewall & IPS version.

For versions of connected MetaDefender Industrial Firewall & IPS bar, there are 5 colors can be displayed:

- *Green*: display the number of MetaDefender Industrial Firewall & IPS having **Latest** version.
- *Blue*: display the number of MetaDefender Industrial Firewall & IPS having **Up To Date** version.
- *Yellow*: display the number of MetaDefender Industrial Firewall & IPS having **Slight Behind** version.
- *Orange*: display the number of MetaDefender Industrial Firewall & IPS having **Behind** version.
- *Red*: display the number of MetaDefender Industrial Firewall & IPS having **Major Behind** version.
- *Grown*: display the number of MetaDefender Industrial Firewall & IPS having **Unknown** version.

### [MetaDefender Industrial Firewall & IPS List](/docs/md-ot-security/v.2.2.6/operating/mdfirewall-overview#metadefender-industrial-firewall--ips-list)

Each row contains the following fields:

- Device Name
- No. of protected PLC
- Unacknowledged Events
- Firmware Version
- Mode
- License Status: **No License/Licensed**
- Connectivity Status: **Disconnected/Connected** (whether MetaDefender OT Security can connect the MetaDefender Industrial Firewall & IPS device or not)
- Managed Status: **Managed/Unmanaged** (whether MetaDefender OT Security can manage the MetaDefender Industrial Firewall & IPS device or not)
- Disk Space Status
- Memory Status

## [Filter](/docs/md-ot-security/v.2.2.6/operating/mdfirewall-overview#filter)

We support filtering on the list of MetaDefender Industrial Firewall & IPS:

- User can ***enter a value for one or more fields***, and the result list and the number of total records will be updated according to the value(s) you entered.
