# Version 3.7.0

View as Markdown Ask ChatGPT about this page Ask Claude about this page

| **Version** | 3.7.0 |
| --- | --- |
| **Release date** | 23 March 2026 |
| **Scope** | Enhance current features and add new features. |

## [New Features, Improvements, and Enhancements](/docs/md-ot-security/v4.0.0/release-notes/release-notesxvplcg#new-features-improvements-and-enhancements)

|  | Details |
| --- | --- |
| **Introduced Links among devices** | Summarize and abstract communication among devices. Add connection links to Report Builder |
| **Display Misconfiguration, Update History in Enterprise Manager** | Supported viewing all Misconfigurations and Update History of all Sensors in Enterprise Manager. |
| **Support Moxa vendor** | Added scanning of Moxa devices in Smart Asset Profiling and optimized detection of CVEs for it. |
| **Allow to add routes** | Flexible routing of networks/subnets. |
| **Allow to configure proxy** | Allow the user to configure a proxy server from Enterprise Manager to access the internet via proxy. |
| **Support CIFS protocol** | Supported viewing and extracting Server Name, OS Name, OS Version, Server Type from CIFS protocol. |
| **Extract outer VLAN, inner VLAN for connections** | Extract and display outer VLAN and inner VLAN for connections. |
| **Extract user_agent from HTTP protocol** | Supported to get OS Name and OS version from HTTP protocol. |
| **Extract data from S7COMM protocol** | Supported to get hostname, Hardware CPU, Serial Number from S7COMM protocol. |
| **Identify Device Type, OS Type from TTL** | Supported to get Device Type, OS Type from TTL. |
| **Remove port 3003/3006/1443 requirements from web access** | Now users do not need to open ports 3003, 3006, 1443 in Firewall for web access. |
| **General Improvements** | Included various UI improvements, performance optimizations, and bug fixes to enhance performance, reliability and user experience. |
