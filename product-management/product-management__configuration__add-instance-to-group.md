# Add Existing Instances to a Group

This page describes how you can add an existing instance to a product group.

Navigate to the **Products** page on the left navigation menu and select your product. Select the **Groups** tab.

Click a group you would like to add instances to navigate to the group details view. On the Instances tab, click **Add Instance.**

Here you can select instances to add to the group and choose if you would like to apply the group's configuration to those instances by checking on "**Apply Group Configuration to selected instances**" option. Then click **Add.**

The console then shows if all selected instances are moved and if the group's configuration is applied to the instances. Click **Close** to finish.
