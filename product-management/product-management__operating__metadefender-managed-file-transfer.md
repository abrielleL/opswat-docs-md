# MetaDefender Managed File Transfer Dashboard

The MetaDefender Kiosk Dashboard helps visualize, track and analyze data collected from the managed MetaDefender Managed File Transfer (MFT) instances. The dashboard can be accessed from the left navigation menu, in **Products > MetaDefender Managed File Transfer > Overview** **tab.**

By default, the dashboard shows data collected for all managed instances over 24 hours. The period of time can be customized in the top left corner of the page. You can also apply filters to the dashboard to show only certain instances or instance groups.

#### [Product Overview](/docs/product-management/operating/metadefender-managed-file-transfer#product-overview)

The Product Overview section displays a summary of managed MetaDefender Managed File Transfer instances/groups, which includes:

- The total number of instances and their current status.
- The instances' licensing status based on the remaining duration.

#### [Processing Overview](/docs/product-management/operating/metadefender-managed-file-transfer#processing-overview)

The Processing Overview section displays a summary of the processing results collected from selected MetaDefender Managed File Transfer instances/groups over a specific time period, which includes:

- Number and volume (total file size) of files uploaded/downloaded over time
- The storage data usage
- The user types of the users who trigger the file processing sessions.

#### [Dashboard Customization](/docs/product-management/operating/metadefender-managed-file-transfer#dashboard-customization)

To customize the dashboard's appearance, please refer to [Dashboard Customization](/docs/product-management/operating/dashboard-customization).
