# Dashboard Customization

Users can now customize a dashboard based on their need. This feature is available on

- [MetaDefender Kiosk Dashboard](/docs/product-management/operating/kiosk-dashboard)
- [MetaDefender Media Firewall Dashboard](/docs/product-management/operating/metadefender-media-firewall-dashboard)

To customize a dashboard, click the four-square icon at the top right corner of a dashboard, select **Update Modules.** An **Add Modules** dialog should be popped up.

In the **Add Modules** dialog, all available modules (dashboard widgets) of the dashboard are displayed and group by sections. It also tells users how many modules are selected.

- If a module is selected, it has a checked icon in front of the module name.
- If a module has not been selected, it should have grey background and no checked icon.

Click an module to add or remove it. Click on **Save** to save your changes.

For MetaDefender Media Firewall only, an **Edit Modules** function is available to rearrange the module layout in the dashboard. Click the four-square icon at the top right corner of a dashboard and select **Edit Modules** to enter Edit mode.

In Edit mode, drag-and-drop each module to change the dashboard layout.Click **Save** to confirm your new layout or click **Cancel** to discard any changes and exit Edit mode.

Warning

Please note that the Edit Modules function is only available for MetaDefender Media Firewall.

The dashboard's appearance should be updated immediately.
