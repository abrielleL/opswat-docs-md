# Registration Code

## [Registration Code](/docs/product-management/configuration/registration-code#registration-code)

The registration code is used to enroll OPSWAT products to your account. This code is randomly generated upon account creation.

If your registration code was inadvertently exposed, you can revoke it to prevent unwanted usage. A new registration code will then be generated. This action won't impact enrolled instances on your account. To do so:

1. Select **Revoke Code.**
2. Select **Revoke** in the popup dialog to confirm the revocation.
