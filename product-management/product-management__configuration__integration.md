# Integrations

The **Integration** settings page contain settings related to 3rd party integration with My OPSWAT.

### [APIs](/docs/product-management/configuration/integration#apis)

The **APIs** tab manages the secret keys used to authenticate with My OPSWAT's public APIs. For a list of available public APIs, please refer to [Developer Guide](/docs/product-management/developer-guide).

Click the drop-down menu next to a specify secret key entry to either **View Details**, **Disable** or **Delete** that secret key.

To generate a new secret key:

1. Click **Generate Secret Key**.
2. Enter a description in the pop-up dialog and click **Generate**.

3. A new secret key is created. Click **Done** to close this dialog. If it's sucessfull, a secret key will be created and shown.
