# Group Details

This page describes information on an individual group

**Product Version**: The version of the instance that was used to set as the group configuration.

**Configuration Version**: The version of the configuration you applied to the group.

**Current**: Refers to the number of instances that have the group version/configuration.

**Custom**: Refers to the number of instances that are not the group version/configuration.

**Out-of-date**: Refers to the number of instances that are not up to date with the group version/configuration version.

**Not Compatible:** This tab appears when a product has features that are not yet compatible with the group configuration.
