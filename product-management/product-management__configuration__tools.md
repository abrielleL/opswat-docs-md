# Tools

The **Tools** settings tab contains features that are used to integrate with OPSWAT Products.

### [MetaDefender Endpoint - Response Code Generator](/docs/product-management/configuration/tools#metadefender-endpoint---response-code-generator)

The Response Code Generator is used to generate a Time-based One-time Password (TOTP) for use with the MetaDefender Endpoint product.

There are certain use cases where a MetaDefender Endpoint instance may need an administrator's authorization before proceeding with a command. This authorization can be granted via a challenge-response code mechanism that is integrated with the My OPSWAT. An administrator can use the My OPSWAT console to verify a challenge code generated by the MetaDefender Endpoint instance and generate a response code. This response code is then entered in the MetaDefender Endpoint interface to authorize the command.

To generate the response code,

1. Acquire the challenge code from the MetaDefender Endpoint instance.
2. Enter the challenge code into the **Challenge Code** field and click **Verify**.

3. If the challenge code is valid, additional UI elements will appear.

The **Device** field displays the device ID associated with the MetaDefender Endpoint instance.

The **Command** field displays the command that associated with the request from the MetaDefender Endpoint instance.

4. Fill in all the required input fields

   - **Vendor Name**: The vendor name of the media device from the MetaDefender Endpoint instance's request.
   - **User**: The user associated with the MetaDefender Endpoint instance's request.
   - **Expiration Time** **(minutes)**: The expiration time of the response code.
   - **Password:** The password used to setup the MetaDefender Endpoint instance.
5. Click **Generate Response Code** to generate the TOTP in the **Response Code** field.
