# What's New

| Version: 2025.4.1  Release date: Nov 26, 2025, UTC | My OPSWAT - Central Management is a component of My OPSWAT that allows customers to manage multiple OPSWAT products remotely, improve data flows visibility, and provide better reports for each product and entire account. It also provides critical information like product instance health, license, and connection status, report history, license, and audit trails. |
| --- | --- |
| **Enhancement** |  |
| CPU usage optimization | Reduce CPU utilization, optimize the communication flow between instances by caching frequently accessed data in memory, and minimize redundant serialization |
| **Known Limitations** |  |
| When configuring a MetaDefender Kiosk K-Series instance through My OPSWAT, searching for users only returns results from 1 local Active Directory even if multiple are available. | User search currently only returns results from the first reachable local Active Directory. |
