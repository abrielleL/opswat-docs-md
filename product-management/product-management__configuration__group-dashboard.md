# Group Dashboard

The **Group** dashboard of a product gives you an overview of the instance connection status, version, configuration and license information about your group.

You can also filter, search, or sort groups within this view. Rename multiple groups option is also available.

**To access the Group dashboard**, navigate to **Products** on the left navigation menu and select your product. Select the **Groups** tab to view all groups within your account.

**To delete groups**, select groups then **Actions** and choose Delete Group(s) option. On the confirmation dialog, click Delete to confirm your action.

By deleting groups, instances assigned to those groups will be moved to the default group of that product and the instances' configuration will be remained the same. If you would like to move instances to different groups instead of the default group, you need to do so before deleting groups.
