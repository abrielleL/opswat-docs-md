# MetaDefender Media Firewall Dashboard

MetaDefender Media Firewall provides another option for safely and securely leveraging the productivity advantages, flexibility, and convenience of portable media in IT or OT SCADA environments.

The MetaDefender Media Firewall Dashboard visualizes, tracks and analyzes data collected from the managed MetaDefender Media Firewall instances. The dashboard can be accessed from the left navigation menu, in **Products > MetaDefender Media Firewall > Overview** **tab.**

By default, the dashboard shows data collected for all managed instances in last 24 hours. The period of time can be customized in the top left corner of the page. You can also apply filters to the dashboard to show only certain instances or instance groups.

#### [Processing Overview](/docs/product-management/operating/metadefender-media-firewall-dashboard#processing-overview)

The Processing Overview section displays a summary of the file processing results collected from the selected instances/groups within the selected time period, which includes:

- The **Verdict chart** shows the breakdown of file processing verdicts
- The **Blocked chart** shows the breakdown of files blocked reasons.
- The **Scan Results** **chart** shows distribution of blocked, concealed and allowed files. You can use the checkboxes in the top left corner to show/hide data.
- The **Total Sessions** **chart** shows distribution of successful and failed sessions. You can use the checkboxes in the top left corner to show/hide data.
- The **Sessions Per Media Type** **chart** shows the breakdown of sessions for each removable media types.
