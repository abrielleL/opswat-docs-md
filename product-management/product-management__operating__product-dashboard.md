# Products Dashboard

The **My** **Products** page provides a dashboard for managed instances also gives information about other products your organization has not purchased yet. To navigate to this page, select **Products** in the left navigation menu.

#### [Assets Operation:](/docs/product-management/operating/product-dashboard#assets-operation)

#### [Security](/docs/product-management/operating/product-dashboard#security)

The Security tab display all security issues detected by the managed OPSWAT Product instances.

In the top-right corner, you can change the time period and the **Security Alert Preferences.**

The **Security Alert Preferences** dialog display the alert severity and notification behavior for each type of security issues.

Warning

Please note that these preferences currently cannot be changed.
