# Instance Dashboard

The Instances dashboard (at the account level or the group level) gives you an overview of the health, version, configuration and license information about your instances within an account or a group.

You can also filter, search, or sort instances within this view. Rename multiple instances is also available in case you would like to update instances' name.

## [**Instance level**](/docs/product-management/configuration/instance-dashboard#instance-level)

Navigate to the **Products** on the left navigation menu and select your product. Select the **Instances** tab to view all instances managed by your account.

Selecting instances and **Actions** provides several options: deleting instances, moving to a group, and exporting to a CSV file.

## [**Group level**](/docs/product-management/configuration/instance-dashboard#group-level)

Navigate to **Products** on the left navigation menu and select your product. Select the **Groups** tab to view all existing groups on your account. By selecting a specific group, you can view details about that group. From there, select the **Instances** tab to view all instances assigned to that group.

Selecting instances and **Actions** provides several options: deleting instances, moving to a different group, applying group configuration and exporting to a CSV file.

The menu on each instance allows you to set that instance's configuration as a group's configuration.

Warning

By deleting instances, you will permanently remove them and all of their history/reports from your account.
