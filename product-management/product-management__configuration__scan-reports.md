# Scan Reports

For certain OPSWAT Products, you can view scan reports that have been uploaded to My OPSWAT. To view an instance's scan reports, select a specific instance in the [instance dashboard](/docs/product-management) to open the instance detail page view then select the **Scan Reports** tab.

The Scan Report page displays information like Total Files scanned, number of Blocked, Threat Detected, Vulnerability, Zero-day Protection and Proactive DLP results. You can **export** these reports to a .json, .pdf or .txt file by selecting one or more reports via their checkboxes, opening the **Action** drop down menu in the top-right corner and then selecting the download option with the desired format.

You can use the [Reports & Notifications](/docs/product-management/configuration/reports---notifications) settings to schedule email notifications containing a summary scan report of specific product instances.

This feature is currently supported for:

- MetaDefender Kiosk K-Series
- MetaDefender Kiosk L-Series
- MetaDefender Media Firewall
- MetaDefender ICAP
- MetaDefender Core

Info

For My OPSWAT On-premises, the Scan Reports feature for MetaDefender Core and MetaDefender ICAP has an optional integration with OpenSearch for optimized storage and query performance. Please refer to [this article](https://www.opswat.com/docs/myop/configuration/opensearch-integration) for more details.
