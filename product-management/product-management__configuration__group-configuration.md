# Group Configuration

The **Configuration** tab on a Group details view allows you to configure settings for instances that you manage in this group. This tab displays which configuration version is being used and how many instances applied that configuration. It also provides statistic on instances are up-to-date or out of date with these configuration changes.

## [Add Instance to Group](/docs/product-management/configuration/group-configuration#add-instance-to-group)

You can add an instance to a group by selecting the instance and using the **Action** drop down menu on the right. Select **Move to Group**, select a group to add to, enter the PIN and Move to implement the change

## [Set Group Configuration](/docs/product-management/configuration/group-configuration#set-group-configuration)

To set group configuration the first time or promote an instance's configuration to be the group's configuration, navigate to the **Instances** tab of the group and pick an instance you would like to promote its configuration to the group configuration then select **Set as Group Configuration** from its menu. After confirming the action, the group will take that instance's configuration

## [Apply group configuration to instances](/docs/product-management/configuration/group-configuration#apply-group-configuration-to-instances)

On the **Configuration** tab of a group, click **Apply Group Configuration** and select instances you would like to apply the group's configuration to, then click **Apply Configuration**.

The console will let you know if the configuration can be applied to instances and it will be sent to instances when the instances check in.
