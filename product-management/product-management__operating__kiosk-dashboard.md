# MetaDefender Kiosk Dashboard

The MetaDefender Kiosk Dashboard helps visualize, track and analyze data collected from the managed MetaDefender Kiosk instances. The dashboard can be accessed from the left navigation menu, in **Products > MetaDefender Kiosk > Overview** **tab.**

By default, the dashboard shows data collected for all managed instances over 24 hours. The period of time can be customized in the top left corner of the page. You can also apply filters to the dashboard to show only certain instances or instance groups.

#### [Product Overview](/docs/product-management/operating/kiosk-dashboard#product-overview)

The Product Overview section displays a summary of the managed MetaDefender Kiosk instances/groups, which includes:

- The total number of instances and their current status.
- The instances' licensing status based on the remaining duration.

#### [Processing Overview](/docs/product-management/operating/kiosk-dashboard#processing-overview)

The Processing Overview section displays a summary of the scan results collected from the selected MetaDefender Kiosk instances/groups over a specific time period, which includes:

- Number of threats detected, sanitized, sessions, average session time or moved to MFT (MetaDefender File Transfer).
- The product groups that have the most number of threats detected.
- The number of file processing sessions and average processing time per session.
- The top 5 ranking by processed file types.
- The files processed/threat/sanitized graph.
- The media/media with threat sessions graph which shows any active media scanning sessions during the selected time period.
- The average number of files and processing time per session graph.

#### [Resource Overview](/docs/product-management/operating/kiosk-dashboard#resource-overview)

The Resource Overview section displays the breakdown of the selected MetaDefender Kiosk instances/groups excluding instances that are not licensed or disconnected, by the following criteria:

- Health status.
- Last seen time.
- Version
- Free storage space.

#### [Dashboard Customization](/docs/product-management/operating/kiosk-dashboard#dashboard-customization)
