# User Settings

User settings include settings related to the user.

The **User timeout** setting determines the length of login session. Near the end of the specified timeout limit, you will be prompted to either end or extend your session. If the timeout limit is reached without any actions from the user, the login session will automatically end and the user will be logged out. The default timeout length is 30 minutes and can be extended up to 480 minutes.

Enabling the **Require PIN for change activities** setting requires users to enter their personal PIN when the users make any changes in your account. Users can set up their PIN by accessing User Profile page under the user menu.
