# Configuration

If your organization already uses Single Sign On (SSO) services for user authentication before accessing your applications/services, you can integrate with OPSWAT MetaDefender IT-OT Access solution to prevent non-compliant devices from accessing your applications/resources. We support most Identity Providers (IdPs) who support the Security Assertion Markup Language ( SAML) protocol (such as Okta, PingIdentity, Centrify, and OneLogin) as well as applications/services that support SAML SSO.

With MetaDefender IT-OT Access, you no longer need to invest in expensive infrastructure or resources for upgrading, configuring, and maintaining your existing solution.

**To integrate your existing SSO system with OPSWAT solution, here is a check list :**

- [Enable Access Control on your MetaDefender IT-OT Access account](/docs/macloud-sdp/secure-access/enable-access-control-on-your-metaaccess-account)
- [Add protected applications with IdP Method](/docs/macloud-sdp/secure-access/add-protected-applications-with-idp-method)
- [Configure Access Rules](/docs/macloud-sdp/secure-access/configure-access-rules)
- [Update Applications settings on Identity Provider](/docs/macloud-sdp/secure-access/update-applications-settings-on-identity-provider)
- [Configure SSO settings on applications](/docs/macloud-sdp/secure-access/configure-sso-settings-on-applications)

All the above steps need to be carried to get the solution to work. Skipping any of these may cause some login issues. We strongly recommend testing your integration by following steps [in this guideline](/docs/macloud-sdp/secure-access/test-your-integration).

We also provide detailed guidelines on how integrate specific IdP and applications [here](/docs/macloud-sdp/secure-access/sample-guidelines).
