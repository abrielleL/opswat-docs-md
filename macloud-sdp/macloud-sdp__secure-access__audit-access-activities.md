# Audit Access Activities

MetaDefender IT-OT Access understands the complex BYOD ownership problem in managing BYOD devices. Now, MetaDefender IT-OT Access uniquely addresses this problem by recording a user identity such like application username with each device they use when accessing protected applications, increasing unmanaged device control without requiring any IT infrastructure changes, network traffic manipulation, or mobile device management (MDM).

With protected apps via IdP method, you need to enable "***Allow*** ***MetaDefender IT-OT Access*** ***to*** ***record a user who is using a device to access an application***" option to allow MetaDefender IT-OT Access record users who are using devices to access protected applications when IdP forwards user authentication to MetaDefender IT-OT Access.

From MetaDefender IT-OT Access console or through [Get Access Activities](/docs/macloud-sdp/developer-guide/get-access-activities) API, administrators can now see who is using a device to access what application and which action MetaDefender IT-OT Access took for that access activities. This brings more visibility to administrators to address who is trying to access protected applications from unknown devices. By this way, administrators is easy to identify risk from unknown devices.

From MetaDefender IT-OT Access console, you can audit access activities by navigating to Secure Access > Activities
