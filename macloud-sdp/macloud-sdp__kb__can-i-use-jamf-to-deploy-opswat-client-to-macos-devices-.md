# Can I use Jamf to deploy MetaDefender Endpoint to macOS devices?

This article applies to all MetaDefender Endpoint releases including and subsequent to version 10.4.214.0 deployed on macOS devices.

Beginning with version 10.4.214.0, MetaDefender Endpoint supports deployment to macOS devices via Jamf Now.

To make use of this option, users should request a *pkg* package from the OPSWAT Support team.

Once the package is received, follow [These Instructions](https://docs.jamf.com/jamf-now/documentation/Deploying_Mac_Packages.html) on Jamf Now to upload the MetaDefender Endpoint package to your Jamf Now account or, for detailed instructions on how to deploy MetaDefender Endpoint via Jamf Pro, [Read This](/docs/macloud-sdp/kb/how-can-i-deploy-the-opswat-client-with-jamf-pro-).

Support:

To **Request Your** ***pkg*** **Package**, open a [Support Case](https://my.opswat.com/portal/support) with the OPSWAT team via phone, online chat or form.
