# User Settings

This documentation is for console users only. It does not apply to end-users within Secure IT Access.

## [Update Name](/docs/macloud-sdp/configuration---management/user-settings#update-name)

Users are able to update their name and other profile information. To do so, select your name in the top right-hand corner of MetaDefender IT Access, then looking under **Name**, you'll find a button **Update Profile**. Here you can update your name, your phone, and other profile fields.

## [PIN Security](/docs/macloud-sdp/configuration---management/user-settings#pin-security)

Users are able to enable or disable PIN requirements on their account. In addition, they are able to set their PIN for their personal account.

### [Set up PIN](/docs/macloud-sdp/configuration---management/user-settings#set-up-pin)

To set up the PIN code you wish to use:

- Select your name in the top right-hand corner of MetaDefender IT Access
- Navigate to **Security** and you will be able to set your PIN.

Note: You will not be prompted for a PIN code until you enable PIN security. For more information, review the section below.

### [Enable/Disable PIN](/docs/macloud-sdp/configuration---management/user-settings#enabledisable-pin)

For more information on enabling/disabling your PIN, please review this [document](https://docs.opswat.com/macloud-sdp/configuration---management/global-settings).
