# How do I use the MetaDefender IT Access Testing Harness?

This article applies to the current MetaDefender IT Access oAuth Portal and MetaAccess API.

The **MetaDefender IT Access** **API Testing Harness** is accessible via the MetaDefender IT Access oAuth Portal, [Here](https://gears.opswat.com/developers/docs).

1. Log into the **MetaDefender IT Access** **oAuth Portal** using your standard MetaDefender IT Access Console login details.
2. Navigate to the **Testing Harness** page where you will find your applications listed, or where you can click the option to **Register New Application**, as illustrated below.

Pro Tip:

For more on registering new applications via the oAuth Portal, please [Read This](/docs/macloud-sdp/kb/how-could-i-retrieve-client-id-and-client-secret-on-metaaccess-t).
