# Is the MetaDefender IT Access download link static or expire?

This article applies to all MetaDefender IT Access products download links, to be deployed on Windows, macOS, Linux, Android and iOS systems.

The MetaDefender IT Access download link is static and will not expire. The URL is static and is formatted as follows:

- [https://gears.opswat.com/console/download/{your-metaaccess-api-key}](https://gears.opswat.com/console/download/%7Byour-metaaccess-api-key%7D)
