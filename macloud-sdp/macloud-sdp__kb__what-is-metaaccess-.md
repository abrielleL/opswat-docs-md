# What is MetaDefender IT Access?

This article applies to the current MetaDefender IT Access solution and all MetaDefender Endpoint releases deployed on Windows, macOS, Linux, Android and iOS systems.

OPSWAT MetaDefender IT Access is a cloud based access control solution that helps organizations enforce endpoint compliance and prevent contamination of cloud applications.

To do this, MetaDefender IT Access blocks potentially compromised or non-compliant devices from accessing SaaS applications. The conditions for compliance are fully configurable, so administrators determine whether an application or state is passable, represents an issue or should be treated as critical.

MetaDefender IT Access provides visibility and advanced management tools for a range of endpoint application types, from hard-disk encryption to public file sharing, and includes the functionality to remove non-compliant applications remotely.

To learn more about OPSWAT’s MetaDefender IT Access solution and product range, please [Read This](https://www.opswat.com/products/metaaccess).

Please Note:

- Prior to 24 August 2017, MetaDefender IT Access was known as MetaDefender Endpoint Management.
- Prior to 24 February 2015, MetaDefender IT Access was known as Gears or Gears Cloud.
