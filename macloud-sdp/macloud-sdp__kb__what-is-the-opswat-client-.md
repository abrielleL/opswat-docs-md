# What is the MetaDefender Endpoint?

This article applies to all MetaDefender Endpoint releases deployed on Windows, macOS, Linux, iOS and Android systems.

## [Functionality](/docs/macloud-sdp/kb/what-is-the-opswat-client-#functionality)

The MetaDefender Endpoint is a lightweight, unobtrusive application, designed to run on every device that is being managed by your account on either MetaDefender IT Access or My OPSWAT.

MetaDefender Endpoint delivers the device’s security status to the OPSWAT servers and, in turn, channels commands from the servers back to the device to resolve any issues.

## [Installation](/docs/macloud-sdp/kb/what-is-the-opswat-client-#installation)

The MetaDefender Endpoint gets installed on each of a user’s managed devices via an installer package available in the following file types:

- **.msi** for Windows
- **.dmg** for macOS
- **.rpm** or .deb for Linux
- **.apk** for Android
- **.ipa** for iOS

The installer package has the same features and behavior as a typical installer package of the same file type.

Please Note:

You will need administrator level privileges to install the MetaDefender Endpoint on a local device, or you can install it remotely using any of the domain controller group policy features that support dissemination and remote installation of applications.

To learn more, [Read This](https://docs.opswat.com/ocm/operating/opswat-client).

## [Management](/docs/macloud-sdp/kb/what-is-the-opswat-client-#management)

Once installed and running, information collected by the MetaDefender Endpoint will start to appear in your MetaDefender IT Access Console, which is accessible via [This Link](https://metaaccess.opswat.com/), or via your My OPSWAT Console, accessible via [This Link](https://docs.opswat.com/ocm).
