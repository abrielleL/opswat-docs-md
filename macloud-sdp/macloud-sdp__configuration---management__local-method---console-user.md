# Local Method - Console User

Within MetaDefender IT Access, administrators have the ability to create users (both end-users and console users). This document covers how to set up local console users who will access the MetaDefender IT Access console.

## [Add a console user](/docs/macloud-sdp/configuration---management/local-method---console-user#add-a-console-user)

In order to invite an additional user to manage your account:

1. Log into MetaDefender IT Access console
2. Go to **User Management > Users > Console Users**.
3. Click on the “**Invite Console User**” button to invite users to manage your account.
4. Select a user role you wish them to have on the Invitation popup. For more information on user roles, please click [here](https://docs.opswat.com/macloud-sdp/configuration---management/roles).
5. Enter an email address of the person you would like to invite to your account. Note that this user doesn't need to have an OPSWAT account at this moment, but (s)he is required to sign up an account with OPSWAT MetaDefender IT Access if (s)he has not done so before accepting the invitation
6. Enter your PIN to confirm the action
7. Click on the **Invite** button to send out the invitation.
8. If the action is successful, the user will then receive an email with an invitation. The user can follow this [guideline](/docs/macloud-sdp/kb/how-could-i-manage-another-account-) to accept your invitation and start managing your account.

## [Update a console user](/docs/macloud-sdp/configuration---management/local-method---console-user#update-a-console-user)

Local users can have their roles updated after being added. To update a local console user:

1. Log into MetaDefender IT Access console
2. Go to **User Management > Users > Console Users**.
3. Select the user you wish to update by checking the box next to their name.
4. Select **Update**.
5. Select the new role permission for the user.
6. Enter your PIN to confirm the action.
7. Click **Update**.

## [Delete a console user](/docs/macloud-sdp/configuration---management/local-method---console-user#delete-a-console-user)

To remove a local user and their access to MetaDefender IT Access:

1. Log into MetaDefender IT Access console
2. Go to **User Management > Users > Console Users**.
3. Select the user you wish to remove by checking the box next to their name.
4. Select **Delete**.
5. Enter your PIN to confirm the action.
6. Select **Delete.**
