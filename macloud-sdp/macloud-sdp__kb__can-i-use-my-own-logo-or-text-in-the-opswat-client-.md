# Can I use my own logo or text in the MetaDefender Endpoint?

This article applies to all paid license holders using Persistent MetaDefender Endpoint releases deployed on Windows or macOS devices.

The Persistent MetaDefender Endpoint for both Windows and macOS is fully customizable for paid license holders.

While MetaDefender IT Access does not support the uploading of logo and text customized packages by default, administrators can enable this feature by contacting OPSWAT Support.

To utilize this option:

1. Contact OPSWAT Support to receive a customizable default package by following the instructions in the box at the bottom of this article.
2. Update the text and logo/icon in the package.
3. Send your customized package back to OPSWAT Support.
4. OPSWAT will update your account.
5. Finally, MetaDefender Endpoint will apply the customization as soon as it connects to MetaDefender IT Access.

Support:

To **Request Your Customizable Default Package**, open a [Support Case](https://my.opswat.com/portal/support) with the OPSWAT team via phone, online chat or form.
