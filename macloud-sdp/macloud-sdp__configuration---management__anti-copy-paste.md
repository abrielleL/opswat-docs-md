# Anti Copy/Paste

This is a paid feature. For inquiries on upgrading your MetaDefender IT Access account, please contact OPSWAT Sales.

**Anti Copy/Paste** feature allows administrators to prevent users from copying/pasting on their endpoints with the MetaDefender Endpoint installed.

Found under **Policies > Laptops/Desktops > Anti Copy/Paste** , Administrators can pick from two options: **Always enable** or **Only enable while one of the specific applications is running**.

Always enable will permanently disable copying/pasting on the MetaDefender IT Access managed devices that use the policy with this feature enabled. This can be updated at any time if a user requests the ability to copy/paste.

**Only enable while one of the specific applications is running** allows administrators to customize the copy/paste limitations for users. By selecting **Add Application**, administrators can name any product any list it's process name for the MetaDefender Endpoint to detect. *Note: you must have at least one application added to use this option.*
