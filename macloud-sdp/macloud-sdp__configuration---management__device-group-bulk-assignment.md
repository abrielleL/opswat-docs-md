# Device Group Bulk Group Assignment

This document covers the options that MetaDefender IT Access provides for bulk group assignment for endpoints. This feature can be found by navigating to **Inventory > Device Groups >** and selecting the device group you would like to update.

Administrators are able to move devices in bulk to groups in MetaDefender IT Access by utilizing the **Bulk Group Assignment**. To proceed with bulk group assignments, please follow the following instructions:

- Navigate to **Inventory > Device Groups >** and selecting the device group you would like to perform the bulk assignment.
- Select the (⋮) in the right hand corner of the device group page, and select **Bulk Group Assignment**.
- A pop-up window will appear. Select the type of sample list you want to download (based on device ID or hostname) and select the **here** button to download the sample device list.
- This will prompt a CSV download.
- Open the CSV file and input the relevant data and save the changes.
- Navigate back to the pop-up window and upload the CSV file with your changes.
- Select **Add Devices to Group**.
- All devices should appear in the device group immediately.

For other methods of group assignment, both manual and automatic, please review [Device Group Auto-Assignment](https://docs.opswat.com/macloud-sdp/configuration---management/device-group-auto-assignment)
