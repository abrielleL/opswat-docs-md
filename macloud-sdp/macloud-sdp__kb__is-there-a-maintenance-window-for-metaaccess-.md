# Is there a maintenance window for MetaDefender IT Access?

This article applies to MetaDefender IT Access and all MetaDefender IT Access products deployed on Windows, macOS, Linux, Android and iOS systems.

In order to deliver new, state-of-art features and functionality to our MetaDefender IT Access customers regularly, the OPSWAT team will conduct updates during the following scheduled maintenance windows.

|  |  |
| --- | --- |
| Americas | Tuesdays 6pm-9pm PST/PDT (UTC-8/-7) |
|  | Sundays 6pm-9pm PST/PDT (UTC-8/-7) |
| Europe, the Middle East, and Africa | Tuesdays 2am-5am CET (UTC+1) |
|  | Mondays 2am-5am CET (UTC+1) |
| Asia-Pacific | Tuesdays 9am-12pm CST (UTC+8) |
|  | Mondays 9am-12pm CST (UTC+8) |

Please Note:

OPSWAT may, occasionally, conduct maintenance in other windows. However, this will only occur when necessary and, in these exceptional cases, we will communicate with customers ahead of time.

Support:

For further queries or concerns regarding **MetaDefender IT Access** **Maintenance and Updates**, please open a [Support Case](https://my.opswat.com/portal/support) with the OPSWAT team via phone, online chat or form, or feel free to ask the community on our [OPSWAT Expert Forum](https://go2.opswat.com/s).
