# How do I increase the Phishing Protection score on Security Score Windows devices?

## [How to get max score](/docs/macloud-sdp/kb/how-do-i-increase-the-phishing-protection-score-on-security-scor#how-to-get-max-score)

To get the max score for this category, we need to enable the antiphishing for all the browsers on your computer.

## [How to set default browser:](/docs/macloud-sdp/kb/how-do-i-increase-the-phishing-protection-score-on-security-scor#how-to-set-default-browser)

Go to Windows Settings and select Apps tab → choose “Default apps”

Start select default browser

Click "Set Default"

## [How to enable Antiphishing in Chrome:](/docs/macloud-sdp/kb/how-do-i-increase-the-phishing-protection-score-on-security-scor#how-to-enable-antiphishing-in-chrome)

Google Chrome

Open settings of Chrome → select tab “Privacy and Security” → Click on “Security” field

Select protect option for Chrome browser

Note: we must enable antiphishing on all profile users of Chrome to make it right
