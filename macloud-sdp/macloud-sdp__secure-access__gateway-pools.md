# Gateway Pools

MetaDefender IT-OT Access organizes SDP gateways by using Gateway Pools. Pools are a way for administrators to group gateways together however they so choose.

### [Create A Gateway Pool](/docs/macloud-sdp/secure-access/gateway-pools#create-a-gateway-pool)

To create a gateway pool, administrators must do the following:

1. Navigate to **Secure Access > Access Methods > Gateways**.
2. Select **Add Gateway Pool**.
3. Fill out gateway pool name and select **Next**.
4. Optional: Assign applications to the gateway pool. This is not required at the time of the pool creation, but will be required to gain access to an application while using that pool for SDP sessions.
5. Select **Submit**.

### [Update A Gateway Pool](/docs/macloud-sdp/secure-access/gateway-pools#update-a-gateway-pool)

Administrators are able to update both the pool name and the application assignments. To update a gateway pool, administrators must do the following:

1. Navigate to **Secure Access > Access Methods > Gateways**.
2. Select the gateway pool you wish to update.
3. Update the gateway pool name if needed and select **Next**.
4. Update the assigned applications to the gateway pool if needed.
5. Select **Submit**.

### [Delete A Gateway Pool](/docs/macloud-sdp/secure-access/gateway-pools#delete-a-gateway-pool)

Administrators are able to remove gateway pools if no longer needed. To delete a gateway pool, administrators must do the following:

1. Navigate to **Secure Access > Access Methods > Gateways**.
2. Select the gateway pool you wish to remove.
3. Delete all gateways that are assigned to this pool. You cannot delete a pool until all gateways are removed.
4. Once completed, select the delete icon next to the gateway pool you wish to remove.
5. Select **Delete Gateway Pool**.
