# How do I solve Windows Defender issues on MetaDefender Endpoint/MetaDefender IT Access devices?

This article applies to Windows Defender, the current MetaDefender IT Access Console and API, and all MetaDefender Endpoint releases deployed on Windows 10 or 11 systems.

The following article covers three common MetaDefender IT Access device compliance warnings that users may encounter when running Windows Defender in conjunction with MetaDefender IT Access/MetaDefender Endpoint

These warnings/flags are triggered by device issues and will appear under **MetaDefender IT Access** **Console>Inventory>Devices>Relevant Device>Detailed Device Information>Deep Compliance>Anti-Malware**, as illustrated below.

## MetaDefender IT Access Compliance Warning: Windows Defender - No Successful Scan Recently

### Windows 11

1. Open the Windows Start menu, search for Windows Security, then launch it.

2. In the **Windows Security** console, click on **Virus & threat protection** in the left-hand navigation panel.

3. On the **Virus & threat protection** page, click **Scan options**.

4. On the **Scan options** page, select the **Full scan** option, then click **Scan now**.

5. Open the Windows **Start** menu, then search for **MetaDefender Endpoint** (or **MetaDefender IT Access**) and select **Run as administrator**.

6. Once the app is running, right-click on the Client tray icon and, from the pop-up menu, click **Recheck**.

Please Note:

This will trigger the MetaDefender Endpoint to scan all device compliance data and report to the MetaDefender IT Access servers again.

### Windows 10

1. Open the Windows **Start** menu, search for **Windows Defender**, then launch it.

2. In the **Windows Defender** console, click on **Virus & threat protection** in the main panel, or in the left-hand navigation panel.

3. On the **Virus & threat protection** page, click **Advanced scan**

4. On the **Advanced scans** page, select the **Full scan** option, then click **Scan now**.

5. Open the Windows **Start** menu, then search for **MetaDefender Endpoint** (or **MetaDefender IT Access**) and select **Run as administrator**.

6. Once the app is running, right-click on the MetaDefender Endpoint tray icon and, from the pop-up menu, click **Recheck**.

Please Note:

This will trigger the MetaDefender Endpoint to scan all device compliance data and report to the MetaDefender IT Access servers again.

## MetaDefender IT Access Compliance Warning: Windows Defender - Real Time Protection Disabled

### Windows 11

1. Open the Windows **Start** menu, search for **Windows Security**, then launch it.

2. In the **Windows Security** console, click on **Virus & threat protection** in the left-hand navigation panel.

3. On the **Virus & threat protection** page, click **Manage settings**.

4. On the **Virus & threat protection settings** page, enable **Real-time protection**.

5. Open the Windows **Start** menu, then search for **MetaDefender Endpoint** (or **MetaDefender IT Access**) and select **Run as administrator**.

6. Once the app is running, right-click on the MetaDefender Endpoint tray icon and, from the pop-up menu, click **Recheck**.

Please Note:

This will trigger the MetaDefender Endpoint to scan all device compliance data and report to the MetaDefender IT Access servers again.

### Windows 10

1. Open the Windows **Start** menu, search for **Windows Defender**, then launch it.

2. In the **Windows Defender** console, click on **Virus & threat protection** in the main panel, or in the left-hand navigation panel.

3. On the **Virus & threat protection** page, click on **Virus & threat protection settings**.

4. On the **Virus & threat protection settings** page, enable **Real-time protection**.

5. Open the Windows **Start** menu, then search for **MetaDefender Endpoint** (or **MetaDefender IT Access**) and select **Run as administrator**.

6. Once the app is running, right-click on the MetaDefender Endpoint tray icon and, from the pop-up menu, click **Recheck**.

Please Note:

This will trigger the MetaDefender Endpoint to scan all device compliance data and report to the MetaDefender IT Access servers again.

## MetaDefender IT Access Compliance Warning: Windows Defender - Virus Definition Out Of Date

### Windows 11

1. Open the Windows **Start** menu, search for **Windows Security**, then launch it.

2. In the **Windows Security** console, click on **Virus & threat protection** in the left-hand navigation panel.

3. On the **Virus & threat protection** page, click **Protection updates**.

4. On the **Virus & threat protection updates** page, click **Check for updates**.

5. Open the Windows **Start** menu, then search for **MetaDefender Endpoint** (or **MetaDefender IT Access**) and select **Run as administrator**.

6. Once the app is running, right-click on the MetaDefender Endpoint tray icon and, from the pop-up menu, click **Recheck**.

Please Note:

This will trigger the MetaDefender Endpoint to scan all device compliance data and report to the MetaDefender IT Access servers again.

### Windows 10

1. Open the Windows **Start** menu, search for **Windows Defender**, then launch it.

2. In the **Windows Defender** console, click on **Virus & threat protection** in the main panel, or in the left-hand navigation panel.

3. On the **Virus & threat protection** page, click on **Protection updates**.

4. Open the Windows **Start** menu, then search for **MetaDefender Endpoint** (or **MetaDefender IT Access**) and select **Run as administrator**.

5. Once the app is running, right-click on the MetaDefender Endpoint tray icon and, from the pop-up menu, click **Recheck**.

Please Note:

This will trigger the MetaDefender Endpoint to scan all device compliance data and report to the MetaDefender IT Access servers again.
