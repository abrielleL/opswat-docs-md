# How does OPSWAT Mobile App perform jailbreak detection on Apple devices?

This article applies to all OPSWAT Mobile App releases deployed on iOS devices.

The OPSWAT Mobile App uses four different techniques to detect jailbroken iOS devices.

When any of the four detection mechanisms pull a positive result, the device is reported as **Jailbroken**.

These detection methods include a combination of behavioral and signature based techniques to increase the likelihood and sensitivity of jailbreak detection.

This includes behavioral and signature based queries into:

- **known jailbreaking apps**
- **known jailbreaking data files**
- **restricted areas in the file system**
- **restricted OS APIs.**
