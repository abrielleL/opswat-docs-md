# Do I need to keep OPSWAT Mobile App running in the background?

This article applies to all OPSWAT Mobile App releases deployed on Android and iOS devices.

In order to keep a mobile device’s compliance data current, end users should allow the **OPSWAT Mobile Application** to run continuously as a background process (in background-mode).

Guidelines for running background processes vary per device and OS and user’s should consult device-specific documentation to learn more.

For third-party information on the topic, read [This](https://www.androidauthority.com/stop-android-background-apps-664842/) (**Android**) and [This](https://developer.apple.com/forums/thread/681789) (**Apple**).

Please keep in mind, however, that our iOS Mobile App is currently unable to report data in background mode. This is due to strict limitations enforced by Apple’s policy, which prevent background processes from executing actions or running code.
