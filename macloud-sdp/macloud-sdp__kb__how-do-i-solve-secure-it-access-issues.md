# How do I solve Secure IT Access Issues?

This document will be updated periodically when environmental issues arise that can affect Secure IT Access from being used on your local device.

When enabling Secure IT Access for end-point devices, the OPSWAT MetaDefender Endpoint will receive a command from MetaDefender IT Access to install Secure IT Access packages. Sometimes, due to unforeseen environmental variables, you may experience some issues connecting via Secure IT Access.

Please visit the known environmental issues below for detailed remediation instructions:

1. [How do I solve Background App issues on Secure IT Access Windows devices?](/docs/macloud-sdp/kb/how-do-i-solve-background-app-issues)
2. [How do I solve WAN Miniport Driver issues on Secure IT Access Windows device?](/docs/macloud-sdp/kb/how-do-i-solve-wan-miniport-driver-issues)

Support:

If you believe to have an environmental issue that is not listed in this document, please open a [Support Case](https://my.opswat.com/portal/support) with the OPSWAT team via phone, online chat or form, or feel free to ask the community on our [OPSWAT Expert Forum](https://go2.opswat.com/s).
