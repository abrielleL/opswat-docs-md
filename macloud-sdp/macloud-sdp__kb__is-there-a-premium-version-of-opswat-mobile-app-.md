# Is there a premium version of OPSWAT Mobile App?

This article applies to all OPSWAT Mobile App releases deployed on Android and iOS devices.

No, there is no premium version of the OPSWAT Mobile App. Only one current version is available, and it is free of charge for both personal and commercial use - but not for resale.

To learn more, please [Read This](/docs/macloud-sdp/kb/is-opswat-mobile-app-free-for-personal-and-commercial-use-).
