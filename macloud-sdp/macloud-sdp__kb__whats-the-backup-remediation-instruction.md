# What's the Backup Remediation Instruction?

## [Issue 1: No backup application is installed](/docs/macloud-sdp/kb/whats-the-backup-remediation-instruction#issue-1-no-backup-application-is-installed)

To remediate this issue, install least one backup product or enable pre-installed backup products (Time Machine for MacOS, or Windows Backup for Windows). Once completed, run another compliance check to clear up the issue.

## [Issue 2: No backup activity in the last X day(s)](/docs/macloud-sdp/kb/whats-the-backup-remediation-instruction#issue-2-no-backup-activity-in-the-last-x-days)

To remediate this issue, run an ad-hoc backup cycle. Once completed, run another compliance check to clear up the issue.

To avoid a future compliance issue, we suggest scheduling backups to run while a device is online and running.
