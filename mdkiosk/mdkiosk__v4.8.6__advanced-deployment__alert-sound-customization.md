# Alert Sound Customization

View as Markdown Ask ChatGPT about this page Ask Claude about this page

To change the alert sound when blocked files are detected, replace <Kiosk install directory>\Client\en\resources\sounds\alarm.wav with your own .wav file.

The file name must be maintained or MetaDefender Kiosk will not recognize the sound to play.
