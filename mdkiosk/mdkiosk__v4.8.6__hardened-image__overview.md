# Overview

View as Markdown Ask ChatGPT about this page Ask Claude about this page

The Kiosk Hardened Image is a customized Windows operating system for the Kiosk series. Those hardened OS images are built to strengthen the Kiosks against cyberattacks by configuring the operating system and removing unnecessary applications. This method is also widely used in OT/ICS cybersecurity with following security-related task such as:

- Limiting access.
- Disabling unnecessary default features.

Windows 10 IoT Enterprise LTSC 2021

Kiosk Hardened Image is built on Windows 10 IoT Enterprise LTSC 2021, which remains under Microsoft's mainstream support until January 12, 2027, and extended support until **January 13, 2032.**

## [**Benefits of Hardened Image**](/docs/mdkiosk/v4.8.6/hardened-image/overview#benefits-of-hardened-image)

**Security Enhancements**

Improve security and reduce data breaches of MetaDefender Kiosk, prevent unauthorized access and malware by creating a secured system and reducing its attack surface, especially from unknown removable media devices brought to the critical facilities on a day-to-day operation.

**Performance Breakthrough**

Strengthen overall performance of the MetaDefender Kiosk by deleting unnecessary programs and services, and removing unneeded features that support to lower storage requirements and power consumption.

**Deployment flexibility**

Kiosk Hardened Image is expansive and adaptive to various OT/ICS organizations, and critical infrastructure worldwide, easy to deploy and install with MetaDefender Kiosk & MetaDefender Core altogether.

**Compliance Need**

Supports compliance with industry-specific regulations and standards.
