# Why does Kiosk pause on the final screen after scan session "settings"?

View as Markdown Ask ChatGPT about this page Ask Claude about this page

An important note related to the enhancement request described in the release notes listed below would be the necessary steps to address the timeout value and how to set it up.

<https://www.opswat.com/docs/mdkiosk/v4.7.3/release-notes/release-notes>

Increasing or decreasing the timeout value from the Kiosk UI User timeout tab will result in adjusting the pause after a session is completed.

Max value for this tab can be set to 20160 min (2 weeks).
