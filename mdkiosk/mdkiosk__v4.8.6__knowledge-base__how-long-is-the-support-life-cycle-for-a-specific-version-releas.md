# How long is the support life cycle for a specific version/release of MetaDefender Kiosk?

View as Markdown Ask ChatGPT about this page Ask Claude about this page Check Your Version:

This article applies to all MetaDefender Kiosk V4 releases.

OPSWAT provides support on each release of MetaDefender Kiosk for 18 months after the publication of the **following** release of the product. So, once a new release is published, you have 18 more months of support on the previous release.

Keep in mind, however, that bug fixes and enhancements are applied only to the next release of a product, not to the current release or historical releases - even when those releases are still under support.

In some cases, hot-fixes can be provided for the current release of the product, and then incorporated as regular fixes in the next release.

Pro Tip:

OPSWAT highly recommends that users regularly upgrade to the latest version of MetaDefender Kiosk and not wait until the end of a release’s support cycle.

Current versions incorporate state-of-the-art features and necessary bug fixes, and are freely available for all license holders to download.

To upgrade, follow these steps:

1. Browse [Release Notes](https://docs.opswat.com/mdkiosk/release-notes) for details on the latest MetaDefender Kiosk version release.
2. Visit [My OPSWAT](https://my.opswat.com/home/metadefender-kiosk) to download a new version under the relevant package license.

Visit [Installation Documentation](https://docs.opswat.com/mdkiosk/installation) for step-by-step instructions on how to install the MetaDefender Kiosk solution.
