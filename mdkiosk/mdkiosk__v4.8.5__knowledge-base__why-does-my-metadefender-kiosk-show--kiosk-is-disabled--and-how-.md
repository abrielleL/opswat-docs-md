# Why does my MetaDefender Kiosk show "Kiosk is Disabled" and How to resolve it.

This article applies to the MetaDefender Kiosk Windows

The Kiosk includes a self-locking mechanism designed to block usage if a threat is detected or if local files are compromised. This ensures system integrity and prevents potential risks.

This article will explain why the lock occurs and provide guidance on how to resolve the situation.

## [1. If you are using Kiosk Secure Image](/docs/mdkiosk/v4.8.5/knowledge-base/why-does-my-metadefender-kiosk-show--kiosk-is-disabled--and-how-#1-if-you-are-using-kiosk-secure-image)

<https://www.opswat.com/docs/mdkiosk/knowledge-base/why-is-my-md-kiosk-disabled-on-secure-image-and-how-to-resolve-i>

## [2. If you are using the Kiosk Hardened Image or Kiosk Software](/docs/mdkiosk/v4.8.5/knowledge-base/why-does-my-metadefender-kiosk-show--kiosk-is-disabled--and-how-#2-if-you-are-using-the-kiosk-hardened-image-or-kiosk-software)

After running the [MetaDefender Kiosk Self-Scan](https://www.opswat.com/docs/mdkiosk/advanced-deployment/self-scan), you may encounter the message “Kiosk is disabled” if the scan detects threats or returns a blocked result.
