# Resources

The Resources section in the Management Console interface contains different links to other OPSWAT solutions that can be used to compliment the usage of the Kiosk.

[**OPSWAT Media Validation Agent**](/docs/mdkiosk/v4.8.5/operating/opswat-media-validation-agent) - Download the .msi to install the agent on any endpoint.

[**OMVA Tool**](/docs/mdkiosk/v4.8.5/operating/opswat-media-validation-agent) - Downloads the companion .exe to configure the admin password and various other settings for the OPSWAT Media Validation Agent.

[**Central Management**](https://docs.opswat.com/ocm) - Link to `My OPSWAT` to download the latest Central Management releases.

[**MetaDefender Core**](https://docs.opswat.com/mdcore) - Link to `My OPSWAT` to download the latest Core releases.
