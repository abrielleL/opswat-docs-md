# How do I set up and use the Media Manifest feature in MetaDefender Kiosk with MD Core certificate?

This article applies to all MetaDefender Kiosk V4 releases deployed on Windows systems

Pro Tip:

A Media Manifest is a digitally signed file that lists the hashes of all the files that were cleaned and approved by MetaDefender Kiosk during its session.

This article covers the entire course of Media Manifest setup and usage in MetaDefender Kiosk, including:

1. Setting up the certificate for digital signing (via MetaDefender Core)
2. Enabling the Media Manifest feature (via MetaDefender Kiosk)
3. Utilizing Media Manifest (via the OPSWAT Media Validation Agent)
4. Media validation flow.

## [Setting up the certificate for digital signing (via MetaDefender Core)](/docs/mdkiosk/v4.8.5/knowledge-base/how-do-i-set-up-a-media-manifest#setting-up-the-certificate-for-digital-signing-via-metadefender-core)

1. Go to your **MetaDefender Core Management Console>Inventory>Certificates** to add a certificate that will be used for digital signing.

Note:

**Note:** OPSWAT does **not** issue certificates directly to customers for use with OMVA or Media Manifest signing.

Customers have two primary options for setting up the **Media Validation Public Certificate**:

1. **Self-Signed Certificate (Recommended for testing or small-scale deployments)** You can generate your own certificate and manually install the **public key** on each endpoint running the OMVA agent.
2. **CA-Signed Certificate (Recommended for production environments)** Use a certificate issued by your internal PKI or a trusted Certificate Authority. This enables better trust management and adheres to enterprise security standards.

⚠️ **Important:** The same certificate used to sign manifests on the Kiosk/Core must be trusted by the OMVA agent to successfully validate scanned media.

2. For more information on adding certificates, please [Read This](https://docs.opswat.com/mdcore/configuration/enabling-https) and [This](https://docs.opswat.com/mdcore/operating/inventory-management#certificates).
3. Now, go to **Core Management Console>Workflow Management>Workflows** to open the appropriate workflow.

4. Assign the certificate you created to the **Workflows** > **Generate batch signature with certificate**, as illustrated in the screenshot below.

Warning

- SHA256 must be enabled to generate the manifest files. Make sure the 'Skip hash calculation' checkbox is not selected
## [Enabling the Media Manifest feature (via MetaDefender Kiosk)](/docs/mdkiosk/v4.8.5/knowledge-base/how-do-i-set-up-a-media-manifest#enabling-the-media-manifest-feature-via-metadefender-kiosk)

1. Enable Media Manifest in Kiosk by going to the **MetaDefender Kiosk Management Console>Workflows**, then clicking the edit icon on the appropriate workflow, as highlighted in the screenshot below.

2. Now, go to the **Processing** section to assign the appropriate workflow rule (i.e. the workflow configured in the Core Management Console) and select the **Include Media Manifest** option, as illustrated below.

3. You can choose to use a manifest file generated by either MD Core or Kiosk. The manifest from Kiosk will be signed using the certificate configured under **Settings** > **Security** > **Certificates**
4. Starting with Kiosk 4.8.0, administrators enable "Exclude scan result of original file when its remediated file is available" to restrict access to original files when a remediated (sanitized or redacted) version is available. It ensures that end-users on secure networks only interact with safe, processed content while the original files can remain stored but inaccessible via the manifest
5. Finally, click **Apply** to activate your selections.

Agent)

1. Go to **MetaDefender Kiosk Management Console>Resources** to download the OMVA, as illustrated in the screenshot below.

3. Follow the **Setup Wizard** to install the agent on the appropriate endpoint. Please [Read This](https://docs.opswat.com/mdkiosk/operating/opswat-media-validation-agent) for more information.

## [Media validation flow](/docs/mdkiosk/v4.8.5/knowledge-base/how-do-i-set-up-a-media-manifest#media-validation-flow)

1. In order to process files from external media, Kiosk sends them to the associated MetaDefender Core instance.
2. MetaDefender Core then generates a manifest listing all the files that it processed during the Kiosk session, signed with a digital certificate.
3. The Kiosk then downloads this manifest to the processed media, along with the processed files.
4. This media can now be inserted into any endpoint that has the OPSWAT Media Validation Agent installed.
5. The OMVA will then check the hashes of the files in the media manifest against the files physically located on the media.
6. All Media devices will be blocked if any discrepancies are noticed.
