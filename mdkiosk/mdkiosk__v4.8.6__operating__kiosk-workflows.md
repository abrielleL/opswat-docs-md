# Kiosk Workflows

View as Markdown Ask ChatGPT about this page Ask Claude about this page

MetaDefender Kiosk lets you assign different Kiosk options to different groups of users, called workflows. You can create new workflows and edit any default ones. The [Workflows Page](/docs/mdkiosk/v4.8.6/operating/workflows-page) page contains all workflows in MetaDefender Kiosk.

For each workflow, you can do the following:

- [Properties & Membership](/docs/mdkiosk/v4.8.6/operating/properties---membership)
- [Managing User Questions](/docs/mdkiosk/v4.8.6/operating/managing-user-questions)
- [Allowed Media Types](/docs/mdkiosk/v4.8.6/operating/allowed-media-types)
- [Selecting a Server to Process Files](/docs/mdkiosk/v4.8.6/operating/selecting-a-server-to-process-files)
- [Selecting How to Handle Processed Files](/docs/mdkiosk/v4.8.6/operating/selecting-how-to-handle-processed-files)
- [Custom Command Line Script](/docs/mdkiosk/v4.8.6/operating/custom-command-line-script)
- [Managing Printing Options](/docs/mdkiosk/v4.8.6/operating/managing-printing-options)
- [Managing Logging Options](/docs/mdkiosk/v4.8.6/operating/managing-logging-options)
- [Email Session Report](/docs/mdkiosk/v4.8.6/operating/email-session-report)
- [Retrieve Files](/docs/mdkiosk/v4.8.6/operating/retrieve-files)
