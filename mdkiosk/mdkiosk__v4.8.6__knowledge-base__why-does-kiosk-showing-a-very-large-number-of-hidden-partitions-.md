# Why does Kiosk showing a very large number of hidden partitions when scanning DVD/CD?

View as Markdown Ask ChatGPT about this page Ask Claude about this page

This issue is caused by an unsupported partition count on DVD/CD, results in the partition count being 0, while there is 1 DVD/CD is mounted.

To resolve this issue, upgrade to **Kiosk version 4.7.3** or later. This update includes the necessary fixes to support the correct partition count on DVD/CD devices.
