# Can I extend MetaDefender Kiosk by adding Custom Engines or Signatures?

This article applies to all MetaDefender Kiosk V4 releases deployed on Windows or Linux systems.

Yes.

Whether you require additional malware scanning, sensitive data scanning, or other forms of file scanning, it is possible to significantly extend the scanning capabilities of MetaDefender Kiosk.

This can be done by adding custom scan engines to the MetaDefender Core instance that the Kiosk is configured to scan files with.

Adding scan engines and external scanners to your MetaDefender Core instance (and updating these engines with the maximum available signatures/definitions) is one way to ensure optimal scanning performance from any associated MetaDefender Kiosk.

MetaDefender Core’s engine options include 30+ Metascan AV engines, External Scanners, Deep CDR, Proactive DLP and more.
