# Visitor Logs

View as Markdown Ask ChatGPT about this page Ask Claude about this page

History of visitors\guests can be viewed in the Logs → Visitor Log section of the Kiosk's Management Console.

The history table contains pertinent information of the specific guest check-in.

| Column | Description |
| --- | --- |
| **Guest** | Full name of the guest |
| **Company** | The company from which the guest is visiting from |
| **Visiting** | The contact person in your organization the guest is visiting |
| **Time** | The time in which the guest checked-in |
| **Documents** | Download link to retrieve the PDF document of the agreements the guest signedIf blank, the guest was not prompted to sign any agreements |
