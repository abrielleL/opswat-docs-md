# Secure Image Deployment Wizard

View as Markdown Ask ChatGPT about this page Ask Claude about this page
## [Overview](/docs/mdkiosk/v4.8.6/secure-image/secure-image-deployment-wizard#overview)

This version of the Kiosk Secure Image Deployment Tool is now called Secure Image Deployment Wizard and has been enhanced with a user-friendly UI/UX design. It incorporates a built-in touch screen for seamless interaction with the deployment tool, providing clear and concise information. Additionally, it displays the processing status for each step of the deployment process.

It also offers a logging feature to keep a record of activities and provides the option to force a reboot in the event of an "Error" occurrence.
