# About page

The About page will display the following device information:

- **Operating system**: Details the specific version of Windows installed on the KIOSK device.
- **System Name**: The computer name designated for the KIOSK device.
- **Network configuration**: Exhibits all active network adapters on the device, including the Adapter name, MAC Address, and IPv4 Address.
