# Why are some of the keys on the physical keyboard not responsive in MetaDefender Kiosk?

This article applies to all MetaDefender Kiosk V4 releases deployed on Windows systems.

Please Note:

In the case of certain keys and key combinations (that would allow access to the underlying OS interface) being unresponsive, this is not an error.

As a fundamental MetaDefender Kiosk security requirement, OPSWAT has ensured that the Kiosk application is the only accessible interface on the system for non-administrative users.

To ensure this security feature, the Kiosk system ignores certain keys on the keyboard that can be used individually and in combination with other keys to close an application and access the underlying interface and other programs.

We have had requests from users to enable these keys for certain use cases, and our development team is actively researching ways to meet security requirements while still providing the convenience of certain critical keys on the keyboard.

Support:

If you have any difficulty **Accessing and Using Kiosk Administrative Controls Or the Kiosk Itself Due To Unresponsive Keys**, please follow these instructions on [How To Create a Support Package](https://docs.opswat.com/mdkiosk/troubleshooting#creating-the-package), before [creating a support case or chatting with our support engineer](https://my.opswat.com/portal/support).
