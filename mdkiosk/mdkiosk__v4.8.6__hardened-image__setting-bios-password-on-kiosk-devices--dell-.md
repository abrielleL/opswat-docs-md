# Setting BIOS Password on KIOSK Devices (DELL)

View as Markdown Ask ChatGPT about this page Ask Claude about this page

Administrators can enhance security on KIOSK DELL devices by setting a BIOS password to prevent unauthorized access to the BIOS.

To achieve this, administrators need to follow these steps:

**Step 1:** Start the system.

**Step 2:** At the Dell logo screen, press the **F2** key several times until you enter the BIOS or System Setup.

**Step 3:** In the BIOS Setup screen, select "Passwords" and press Enter, bringing up the Passwords screen.

**Step 4:** On the Admin Password screen, create a password in the "Enter the new password" field and press Enter.

**Step 5:** Re-enter the new password and press Enter again to confirm.

**Step 6:** Click "APPLY CHANGES" to save the changes as prompted by the message.

**Step 7:** Select Exit, the computer will restart, and the BIOS system will now have a password set in place.
