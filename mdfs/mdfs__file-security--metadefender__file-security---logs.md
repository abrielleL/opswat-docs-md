# File Security - Logs

As a Salesforce administrator, you will have access to the OPSWAT - MetaDefender Logs as shown below.

The OPSWAT - MetaDefender Logs report will provide you with high level information of the files that have been uploaded to your Salesforce environment. Such information includes:

- **Log ID**: An ID created to track each document uploaded to your Salesforce environment
- **Document Name**: the name of the document that was uploaded
- **Action**: the action column will tell you what action was performed on the file such as upload or download
- **Status**: the information in this column will indicate whether there is "No Threat Detected" with a given file or if the file has been flagged as "Infected" by our multiscanning technology
- **Download Link**: this will provide the link to download a given file
- **Created By**: the individual who preformed the action on the file
- **Created Date**: the date of the action on the given file
- **Last Update**: the date the file was last updated (by clicking on the arrow at the very right of each record in the table, you can edit the given file)
