# File Security

OPSWAT | Cloud Security for Salesforce helps protect your Salesforce environment from malicious content embedded in files. Cloud Security for Salesforce helps identify and stop these threats before they enter your Salesforce environment by leveraging the power of multiscanning with up to 15 of the best anti-virus engines as well as Deep Content Disarm and Reconstruct (CDR) to sanitize files.

For more information on the technology that powers the Cloud Security for Salesforce application, visit [OPSWAT - MetaDefender Cloud](https://www.opswat.com/products/metadefender/cloud)
