# File Security - Pause Scheduled Jobs

If you need to pause scheduled jobs running within your Salesforce Organization that are managed by Cloud Security for Salesforce, here’s what you need to know.

### [Assign User Permissions](/docs/mdfs/file-security--metadefender/file-security---pause-scheduled-jobs#assign-user-permissions)

The **Assign User Permissions** job enables the Cloud Security for Salesforce application to grant users permission to submit files for scanning.

To pause this job, follow a few simple steps.

1. Go to your wheel on the right hand side and choose Setup

2. Search for *Scheduled jobs* within search bar and select *Scheduled Jobs*

3. All you have to do is to locate the **CSFS Scheduled Job** and to pause the job.
