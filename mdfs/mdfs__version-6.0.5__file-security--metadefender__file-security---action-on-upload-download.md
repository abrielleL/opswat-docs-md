# File Security - Options on Upload/Download

On the OPSWAT - Settings, you can configure various options for handling your files, including multiple settings for Multiscanning and Sandbox. You have control over how files behave during both the uploading and downloading stages.

Below is a screenshot from the OPSWAT - Settings page showing the available pick lists. These lists appear when you choose to block or to delete files based on specific actions.

### [[Sanitization Disabled]](/docs/mdfs/version-6.0.5/file-security--metadefender/file-security---action-on-upload-download#sanitization-disabled)

| Use Cases | Explained Behavior |
| --- | --- |
| Case 1: **Multiscan - enabled MetaDefender** **Sandbox - disabled File Sanitization -** **disabled**  **Multiscan Statuses:**   - Delete files when uploading:    1. 'Infected‘   2. ‘File too large to scan’   3. ‘Scanning skipped' (e.g. using ‘*Do not send files to scan with these file extensions*’ setting)   4. 'Exceeded Limits' - Block files when downloading:    1. 'Infected'   2. ‘File too large to scan’   3. ‘Scanning skipped' (e.g. using ‘*Do not send files to scan with these file extensions*’ setting)   4. 'Exceeded Limits' | - Delete files when uploading:    - Status:      - **Infected**     - **File too large to scan**     - **Scanning skipped**     - **Exceeded Limits**   - Uploaded file is deleted.   - Status: **Deleted due to current configurations**   - Download button is redirecting to Home page along with a '**Page doesn't exist**' pop-up. - Block files when downloading:    - File download blocked.   - Download button is redirecting to **File Blocked** page. |
| Case 2: **Multiscan - enabled MetaDefender** **Sandbox - enabled File Sanitization -** **disabled**  **Sandbox Statuses:**   - Delete files when uploading: 'Malicious', 'Likely Malicious' - Block files when downloading: 'Malicious', 'Likely Malicious' | - Delete files when uploading:    - Status: **Infected** → **Deleted due to current configurations**   - Uploaded file is deleted.   - Sandbox Verdict: '**MALICIOUS**'   - Download button is redirecting to Home page along with a '**Page doesn't exist**' pop-up. - Block files when downloading:    - Status: **Infected**   - File download blocked.   - Sandbox Verdict: '**MALICIOUS**'   - Download button is redirecting to **File Blocked** page. |

### [[New Version with _Sanitized suffix / New Version with Original Filename]](/docs/mdfs/version-6.0.5/file-security--metadefender/file-security---action-on-upload-download#new-version-with-_sanitized-suffix--new-version-with-original-filename)

| --- | --- |
| Case 1: **Multiscan - enabled** **MetaDefender** **Sandbox - disabled** **File Sanitization -** **enabled** **Block sanitized version if original file infected - [checked]**  **Multiscan Status:**  Delete files when uploading:   - 'Infected‘ - ‘File too large to scan’ - ‘Scanning skipped' (e.g. using ‘*Do not send files to scan with these file extensions*’ setting) - 'Exceeded Limits' | Delete files when uploading:   - Status:    - ‘**Infected**', ‘**File too large to scan**’, ‘**Scanning skipped**’, ‘**Exceeded Limits**’ → **Deleted due to current configurations**      - Sanitized version (with / without **_Sanitized** suffix) is created and original version is deleted.   - empty      - Original version is not deleted. - Sanitized version (with / without **_Sanitized** suffix) cannot be downloaded. |
