# MetaDefender ICAP Server Integration Testing with October 2025 F5 BIG-IP Security Updates

F5 has released [security updates](https://my.f5.com/manage/s/article/K000154696) for multiple BIG-IP software applications related to a security incident F5 reported in October 2025.

Based on internal testing, OPSWAT MetaDefender ICAP Server integrations with F5 BIG-IP LTM, WAF(ASM) and SSLO continue to function normally with the latest F5 software updates.

If F5 BIG-IP software is part of your deployment, we recommend that you follow F5's official guidance and apply any advised updates. See [F5 Security Advisory K000154696](https://my.f5.com/manage/s/article/K000154696).
