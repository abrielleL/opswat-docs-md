# PostgreSQL as service in CSPs

###

MetaDefender ICAP Server uses PostgreSQL as database and it can be deployed either **Standalone** (On database for each instance) or **Shared** (Multiple instances connect to a shared database server). Also it can be **Local** (Running the database server in the same instance) or **Remote** (Running the database server externally, using the CSP PostgreSQL service for example)

In this page we are listing what is the service to run the PostgreSQL server in the different Cloud Service Providers like AWS, Azure or GCP.

- AWS - [AWS RDS for PostgreSQL](https://aws.amazon.com/rds/?p=ft&c=db&z=3&refid=b24d12c4-3599-4b6a-ba1f-316b0a0d2be7)
- Azure - [Azure PostgreSQL](https://azure.microsoft.com/en-us/products/postgresql)
- GCP - [Google Cloud SQL](https://cloud.google.com/sql/postgresql?hl=en)
