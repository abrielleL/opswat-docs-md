# Using OPSWAT´s image from CSPs Marketplace

View as Markdown Ask ChatGPT about this page Ask Claude about this page

Usage of image published in CSPs Marketplaces

OPSWAT has published images of MetaDefender ICAP Server in **AWS,** **Azure and GCP**. OPSWAT provides a sample AMI (updated on a regular cadence).

Info

It is recommended for the customer to **run only POCs** as it is configured with the default options.

For production cases it is recommended to generate an image, after following the installation steps as in [On-Premise Installation Overview](/docs/mdicap/v5.15.0/installation/on-premise-deployments-overview). This process is always good to get familiar with the product and configure it to be adapted to the customer use case.

Info

In case the image published to the marketplace with the default configuration works for the customer, the overall and ongoing responsibility of the OS security patch status for that AMI is with the customer.
