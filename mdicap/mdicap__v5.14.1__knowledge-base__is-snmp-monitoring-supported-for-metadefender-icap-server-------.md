# Is SNMP monitoring supported for MetaDefender ICAP Server?

No, SNMP monitoring is not available for MetaDefender ICAP Server.  This applies to all supported [versions](/docs/mdicap/v5.14.1/release-notes/release-notes) of the product.

In addition to modern 3rd-party monitoring solutions such as Prometheus or OpenTelemetry, MetaDefender ICAP Server offers a native [Health Check API](https://www.opswat.com/docs/mdicap/configuration/health-check-api-configuration).
