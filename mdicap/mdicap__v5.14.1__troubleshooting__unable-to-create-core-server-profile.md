# Unable to Create Core Server Profile

This article describes an issue which may occur when using Microsoft Internet Explorer (IE) to access the MetaDefender ICAP server UI. Similar issues may also occur, e.g. inactive drop-down boxes or input validation errors. It is recommended that you use any of the following browsers to avoid these issues.

- Chrome
- Firefox
- Safari
- Microsoft Edge

## [Symptom](/docs/mdicap/v5.14.1/troubleshooting/unable-to-create-core-server-profile#symptom)

When creating a profile to connect MetaDefender ICAP Server to MetaDefender Core, an error is displayed when inputting the Core URI address:

Error

**Wrong URL format! Expected format: http[s]://host:port[?apikey=<apikey>]**

## [Cause](/docs/mdicap/v5.14.1/troubleshooting/unable-to-create-core-server-profile#cause)

This error is one of several issues you may experience when using Microsoft Internet Explorer to access the MetaDefender ICAP Server UI.

## [Solution](/docs/mdicap/v5.14.1/troubleshooting/unable-to-create-core-server-profile#solution)

Use one of the following recommended browsers to access the MetaDefender ICAP Server UI:

- Chrome
- Firefox
- Safari
- Microsoft Edge
