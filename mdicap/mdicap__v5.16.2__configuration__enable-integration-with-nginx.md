# NGINX Integration Configurations

View as Markdown Ask ChatGPT about this page Ask Claude about this page Connect your AI tool Info

Learn more the NGINX integration at [NGINX Integration Module](/docs/mdicap/v5.16.2/integrations/nginx-integration-module)

By default, this feature is turned OFF. To enable it, go to **Setting > System > NGINX Secured Configuration**

The unsecure port default is 8043 and secure port is 8443
