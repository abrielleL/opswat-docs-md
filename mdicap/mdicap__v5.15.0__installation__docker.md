# Docker

View as Markdown Ask ChatGPT about this page Ask Claude about this page

Starting with MetaDefender ICAP Server 4.13.0, we will support you to deploy and run the product on the docker containerization environment, comes with various options:

1. OPSWAT docker images hosted on our docker hub repository. The docker images are bundled with MetaDefender ICAP Server latest official release builds [Docker image published on OPSWAT Docker Hub](/docs/mdicap/v5.15.0/installation/docker-image-published-on-opswat-docker-hubd93)
2. Provide a build toolkit (with docker file and licensing auto deactivation scripts), use them as a deployment support with your own docker image [Using build tool kit with your own docker image](/docs/mdicap/v5.15.0/installation/using-build-tool-kit-with-your-own-docker-imaged4m)

Supported platforms

- CentOS / RedHat
- Debian / Ubuntu
