# Web Management Console

The Web Management Console is available at (<server name or IP>:port). This is the DNS name or IP address of your test server):

http://<server name or IP>:8048

After installing the product the default password for the **admin** user is **admin**.

Warning

As long as TLS is not configured for the Web Management Console, passwords are sent clear-text over the network. To set up TLS see [3.2 Configuring TLS](/docs/mdicap/configuration/configuring-tls).

Every change made in MetaDefender ICAP Server configuration via the Web Management Console is applied when you select **Save settings** or **OK**, except if the change cannot be applied.
