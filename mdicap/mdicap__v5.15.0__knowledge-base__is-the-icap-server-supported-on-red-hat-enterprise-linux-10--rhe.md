# Is the ICAP Server Supported on Red Hat Enterprise Linux 10 (RHEL 10)?

View as Markdown Ask ChatGPT about this page Ask Claude about this page Check your version:

This article applies to MetaDefender ICAP Server instances deployed on Red Hat Enterprise Linux 10 (RHEL 10).

Yes. OPSWAT MetaDefender ICAP Server is compatible with Red Hat Enterprise Linux 10.

Please note that on RHEL 10, the third-party dependency **libnsl** is required. This package is available from the official Red Hat repositories and can be installed as part of the standard system setup.
