# What is the latest MetaDefender ICAP Server version?

View as Markdown Ask ChatGPT about this page Ask Claude about this page Check Your Version:

This article applies to all MetaDefender ICAP Server V5 releases deployed on Windows or Linux systems.

Browse MetaDefender ICAP Server [Release Notes](https://www.opswat.com/docs/mdicap/release-notes) for details on the latest version, version history, version comparisons and release notes.

Alternatively, go directly through the [My OPSWAT](https://my.opswat.com/portal) for a list of available downloads.:

1. Login to My OPSWAT portal
2. Click on “MetaDefender ICAP Server”

3. Click on “Download” button

4. In the new window opened, always the version from the top is the latest version

Pro Tip: 

OPSWAT highly recommends that users upgrade to the latest version of MetaDefender ICAP Server. Current versions incorporate state-of-the-art features and necessary bug fixes, and are freely available for all license holders to download.

Support:

Feel free to contact OPSWAT support for further guidance through your Upgrade process. Please follow these instructions on [How To Create a Support Package](https://docs.opswat.com/mdcore/troubleshooting/how-to-create-support-package-), before logging a [Support Ticket](https://www.opswat.com/support) with the OPSWAT team.
