# OPSWAT Licensing on AWS

To activate the instances where the MetaDefender products are running, it is needed to activate these products providing the LICENSE_KEY.

> **Info**
>
> LICENSE_KEY needs to be requested to Sales before starting to install the product.

MetaDefender Storage Security ask for the LICENSE_KEY when doing the on-boarding process. It is needed to assure the persistence of the database, not to have to reactivate the product on every restart.

> **Info**
>
> MetaDefender Storage Security works together with MetaDefender Core, to see how works the licensing for MetaDefender Core [check this page ](https://www.opswat.com/docs/mdcore/cloud-deployment/licensing-automation-on-aws)
