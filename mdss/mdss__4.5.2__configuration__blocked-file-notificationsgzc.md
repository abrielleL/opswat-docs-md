# User registration request notifications

New users can attempt to register accounts from the login page:

![](https://uploads.developerhub.io/prod/k8zL/h9bfnh3np82col1161t0bgfd3b4r2ezxi7jniiop3esjh7xv0uxkgmgv2qojtgqh.png)

These registration requests need to be verified and approve by MDSS System Administrators.

![](https://uploads.developerhub.io/prod/k8zL/ltdj1oher19wnp1l2bro1has72ucdv2yttpl4yk41dyavi31n37ij7xppxiy7lao.png)

To enable notifications for user registration requests, please select the **User Registration Requests** option from the **Email Notifications** section:

![](https://uploads.developerhub.io/prod/k8zL/b9jxn1jknk11uif4vjmdkna9m5lcq3jhy57gh6k3y914p0q3e160bxwonvbfb1yl.png)

> Always triple check the sender of the email before trusting ANY links.

![](https://uploads.developerhub.io/prod/k8zL/8k5gm1dkm60wbinm5g4s760nwalo2um4w2q4aw40ohvszlrj1tceap7cj532neqh.png)

The email contains the following information:

- Full Name of of registered user
- Email address of registered user
- Date of registration
- Link to the MDSS instance's Users tab

![](https://uploads.developerhub.io/prod/k8zL/o7f3uva3gh9z9gwnuq8woyyd0u2wm5qg69dsazi3ym0tdqt3tpc21sjfkgyjkj5q.png)
