# Add an SMB-Compatible Storage

| Product Specification Requirements | Version |
| ---- | ---- |
| Service Message Block (SMB) protocol | Windows deployments: SMB 2.0.2 to SMB 3.1.1. Linux deployments: SMB 3.1.1, 3.0 or 2.1. |

> **Info**
>
> Integration with SMB Compatible Storage is accomplished via the Service Message Block (SMB) protocol over TCP. Before you begin, make sure SMB is enabled on the file server and that the MDSS machine can reach it on TCP port 445. Linux deployments also accept a custom port; Windows deployments use port 445 only.

Please choose your deployment type:

- [Add an SMB-Compatible unit in Windows deployments](https://www.opswat.com/docs/mdss/integrations/add-an-smb-compatible-unit-in-windows-deployments)
- [Add an SMB-Compatible unit in Linux deployments](https://www.opswat.com/docs/mdss/integrations/how-to-add-a-smb-share-as-a-nfs-storage)
