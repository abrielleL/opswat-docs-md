# Licensing Model

Licensing for MetaDefender Storage Security is directly integrated with MetaDefender Core, as both solutions are delivered together. The licensing framework includes several key elements:

Licenses are provided through a subscription model, with agreements structured for annual or multi-year terms.

Pricing details, entitlements, and usage terms are outlined in a formal agreement with OPSWAT. For enterprise-level implementations, tailored quotes are provided to align with organisational requirements.

Activation is managed via a license key linked to a unique deployment ID generated by the associated MetaDefender Core instance. Both online and offline activation options are available.

A valid and appropriately tiered MetaDefender Core license is required to support MetaDefender Storage Security. This includes coverage for necessary engine packages such as anti-malware engines, Deep CDR, and Proactive DLP to meet the intended security standards.

A Bring Your Own License (BYOL) model is supported for deployments using cloud marketplaces like AWS Marketplace. In this scenario, customers acquire the license directly from OPSWAT and apply it within the cloud platform.

Organizations planning to implement MetaDefender Storage Security must consult OPSWAT or their sales representatives to receive personalized pricing and licensing guidance based on deployment size, security objectives, and selected engine packages.
