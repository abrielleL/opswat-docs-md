# Database procedures

> **Warning**
>
> Whether you use the internal PostgreSQL or an external one, the installed version should be 17.

MetaDefender Storage Security includes an internal PostgreSQL instance by default, currently running on version 17.

For environments with high loads or where high availability is required, the internal PostgreSQL instance can be replaced with a cloud-managed alternative. Instructions for making this switch are provided here: [AWS RDS with PostgreSQL](https://www.opswat.com/docs/mdss/configuration/documentdb-support)
