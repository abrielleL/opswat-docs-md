# What are the Maximum and Minimum Data Retention Periods for MetaDefender Storage Security?

> **Check Your Version:**
>
> This article applies to all MetaDefender Storage Security releases deployed on Windows and Linux systems.

MetaDefender Storage Security allows you to define how many days scan reports are retained.

## Data Retention Days Range

- **Maximum value:** 50,000 days
- **Minimum value:** 1 day

These values define the range you can enter when configuring the Data Retention Days setting in the MetaDefender Storage Security UI.

## Steps to Configure

You can set the retention period by navigating to: Settings > Data Retention
