# Why my files are not moving on SharePoint On-Prem with MDSS, despite UI confirmation?

### **Issue**

When moving files within SharePoint On-Prem, the UI indicates that the file has been successfully moved. However, upon verification, the file is not transferred to the target destination.

### **Root Cause**

The issue occurs due to missing handling for maintaining folder structures during the file movement process.

### **Solution**

Upgrade MetaDefender Storage Security to version **3.5.3 or later**, where proper handling for folder structure preservation in SharePoint On-Prem has been implemented.
