# Settings

The "Settings" section of MetaDefender Storage Security provides a centralized location for configuring various aspects of the system to meet your specific security and operational needs.

Each tab provides a clear interface for configuring the corresponding settings. Make sure to review the specific documentation for each tab to fully understand the available options and their impact on your system.

The Settings page is organized into the following sections:

- Scan Pools

  - This tab allows you to manage and configure scan pools, which define the resources used for scanning files. You can add, edit, and delete scan pools, as well as specify the number of integrated scan instances for each pool. *[Referencing the image: this tab is currently selected in the screenshot.]*

- Export

  - This tab allows you to configure how scan results and other data are exported from MetaDefender Storage Security. You can specify export formats, destinations, and other export-related settings. You can find more information on [this page](/docs/mdss/operations/importing-exporting-a-configuration).
- SMTP

  - This tab is used to configure SMTP settings for email notifications. You can specify the SMTP server, authentication details, and other email-related parameters to ensure seamless delivery of notifications.
- Notifications

  - This tab allows you to configure various types of notifications, such as alerts for detected threats, scan completion notifications, and other system events. You can customize the content and delivery method for each notification type.
- License

  - This tab provides information about your MetaDefender Storage Security license, including expiration dates and feature availability. You can also use this tab to manage and update your license.
- Users

  - This tab allows you to manage user accounts and permissions within MetaDefender Storage Security. You can add, edit, and delete users, as well as assign roles and permissions to control access to different features.
- Data Retention

  - This tab allows you to configure data retention policies, specifying how long scan results and other data are stored in the system. You can define retention periods based on your organization's compliance requirements.
- External Loggers

  - This tab allows you to configure external loggers, such as syslog servers, to forward system logs for centralized logging and analysis.
- Single Sign On (SSO)

  - This tab allows you to configure Single Sign-On (SSO) integration with your organization's identity provider. You can enable SSO and specify the necessary settings to allow users to authenticate using their existing credentials.
- Security

  - This tab allows you to generate a new master encryption key that will re-encrypt all sensitive data. You can find more information on [this page](/docs/mdss/metadefender-storage-security/4.0.0/configuration/security---encryption-keys).
- Access Control

  - This tab allows you to view the roles defined in your system and the permissions associated with each. You can browse all roles, inspect their Read, Write, and Delete permissions per resource, and use the search bar to locate a specific role by name quickly
