# Types of deployment

Whether you require the rapid scalability of the cloud, the control of on-premises infrastructure, or the simplicity of SaaS, MetaDefender Storage Security ensures seamless integration and robust protection across all platforms.

## Pre-Deployment Checklist

Before continue with the deployment of MetaDefender Storage Security

1. Verify prerequisites met (System, Network, Database).
2. Gather necessary credentials and OPSWAT license (Service accounts, API keys).
3. Confirm chosen deployment architecture.

## Deployment Options

Aiming to facilitate the deployments of the OPSWAT´s products to different environments, there are documented examples of architectures and how to deploy them for the following options.

- Deploy using [Cloud Service Providers services](https://www.opswat.com/docs/mdss/installation/csp-deployment-overview)
- Deploy to your [On-Premise Deployment Overview](https://www.opswat.com/docs/mdss/installation/on-premise-deployment-overview)
- Deploy using [containerized technologies in all environments](https://www.opswat.com/docs/mdss/installation/containerized-deployment-overview)
