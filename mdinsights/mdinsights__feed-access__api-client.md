# API Client

No software is required to access our threat intelligence feeds, which are accessible via our [web API](/docs/mdinsights/feed-access/accessing-insights-feeds). In this way, you can directly integrate and access feeds in your security systems and applications.

Users who wish to access MetaDefender InSights feed snapshots or query the InSights threat intelligence API for preview, evaluation or local review may do so using our Python API client. This lightweight client serves as a reference and uses an authorized API key and can download our latest threat intelligence feed snapshots in [JSON Feed Format](/docs/mdinsights/data-formats/json-feed). It can also query the various API endpoints to perform lookups.

For any questions about accessing MetaDefender InSights or any other OPSWAT products or services, please refer to resources and contact information in your [My OPSWAT](https://my.opswat.com/home/metadefender-insights) account.
