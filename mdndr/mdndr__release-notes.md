## MetaDefender NDR v5.4.0 — Release Notes

**Release Date:** October 21, 2026

### Overview

MetaDefender NDR v5.4.0 is now FIPS 140-3 certified, marking an important milestone for deployments in regulated environments.

**Key Highlights:**

- **Meet Cryptographic Security Requirements with FIPS 140-3 Certified OPSWAT MetaDefender NDR:** Support deployments in government, finance, healthcare, and other regulated environments that require validated cryptographic security.
- **Streamline Security Monitoring and Response with SIEM and SOAR Integrations:** Connect to Splunk, Datadog, Elasticsearch, and syslog directly from the NDR management console. Integrate with D3 Security and third-party automation platforms through scoped service accounts and long-lived API credentials.
- **Simplify User Access with Single Sign-On (SSO):** Support centralized authentication through SAML and OIDC, including Okta and Microsoft Entra ID, with group and role mapping for controlled user access.
- **Track Threats Across Locations with Multi-Site Threat Attribution:** Identify which NDR sensor detected each threat, enabling security teams to correlate activity across multiple sites, generate site-specific threat reports, and respond to incidents with accurate location context.
