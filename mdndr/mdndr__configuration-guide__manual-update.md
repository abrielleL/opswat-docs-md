# Manual update

System setting (global). This setting applies to the whole system and to every sensor. For conventions, abbreviations, and the other sections, see the [Administration configuration reference](/docs/mdndr/configuration-guide/administration-configuration-reference).

**Where:** Administration → Configuration → System settings → Manual Update

Upload a signed update bundle by hand. Use this section for an air-gapped system, or when you do not use automatic updates.

This section has no settings. It is a file upload control. Select the update bundle file, then start the upload. The system verifies and applies the bundle.

**Related:** [Updates management](/docs/mdndr/operating-guide/updates-management)
