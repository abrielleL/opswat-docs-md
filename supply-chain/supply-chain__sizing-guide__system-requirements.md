# System Requirements

**MetaDefender Software Supply Chain** supports a wide range of deployment options, providing the flexibility to choose the environment that best suits customers' requirements and infrastructure.

- Physical server.
- Virtualization platforms like VMware, Hyper-V and XenServer.
- IaaS deployments (AWS, Azure, GCP, etc.)
- Kubernetes

Before installing MetaDefender Software Supply Chain, please refer to the **recommended system requirements.**
