# Licensing

## License Packaging Options

Organizations and development teams have the flexibility to integrate MetaDefender Software Supply Chain into CI/CD workflows or gateway environments.

MetaDefender Software Supply Chain offers two types of subscription packaging options: **Per User** and **Standalone**, that fits with your specific deployment, usage requirements, and budget efficiency.

- [Per User license](https://www.opswat.com/docs/supply-chain/licensing/per-user-license)
- [Standalone license](https://www.opswat.com/docs/supply-chain/licensing/standalone-license)

## Compare License Packaging Options

|  | Per User | Standalone |
| ---- | ---- | ---- |
| Pricing | Based on the number of users. Billed annually. | Custom pricing based on selected technologies and configurations. |
| Suitable for | Large development teams (e.g., 10,000 engineers) | Flexible for teams of all sizes, especially smaller security teams |
| Included Technologies | - 5 AV engines (Linux) - Proactive DLP - SBOM | No technology included. Customer can choose any AVs package and/or PDLP and/or SBOM Also, the customer can use the existing MetaDefender Core or buy a separated MetaDefender Core |
| Customization | Fixed package, minimal customization | Customizable security and configurations |
| Infrastructure Focus | CI/CD pipeline | Third-party, open-source vendors |
| Deployment Environment | On-premises | On-premises |
