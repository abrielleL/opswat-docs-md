# Add service units

A **service unit** represents an integration between MetaDefender Software Supply Chain and your development platforms. The following table lists currently supported service integrations:

| Service Category | Service Vendor |
| ---- | ---- |
| Source Code Services | Bitbucket |
|  | GitHub |
|  | GitLab |
|  | Gitea |
|  | SVN |
|  | Azure DevOps |
| Container Services | Amazon ECR |
|  | Azure Container Registry |
|  | DockerHub |
|  | JFrog Container |
|  | Quay |
| -  | Harbor |
| Binary Services | JFrog Binary |
| -  | Sonatype Nexus Repository |

You can integrate each service mentioned above by navigating to **Inventory** and selecting your desired service unit.
