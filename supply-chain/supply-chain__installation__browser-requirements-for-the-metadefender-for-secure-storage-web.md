# Browser Requirements for Web Console

One of the following browsers is suggested to view the MetaDefender Software Supply Chain Web Console:

- Microsoft Edge
- Chrome
- Firefox
- Safari

Chrome, Firefox, Safari, and Edge browsers are tested with the latest available version at the time of release.
