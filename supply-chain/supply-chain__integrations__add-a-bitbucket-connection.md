# Add A Bitbucket service

In order to integrate Bitbucket with MetaDefender Software Supply Chain, please follow these steps:

1. From the left side menu, navigate to **Inventory** and choose Bitbucket:
2. There are two ways to connect:

![](https://uploads.developerhub.io/prod/jdK6/6yrv1zbbq665dtdjk0ywi4xkr8kb24ws15j3eknz4ieib32lwey7a212r750djbj.png)

- **Using Bitbucket Cloud**:

![](https://uploads.developerhub.io/prod/jdK6/axhw1ig3a6fs4z91n64fzjw0h8fnkyw6tohe7w3twdcv3aru8dv4afy6t5vo08as.png)

- **Using Bitbucket Data Center**

![](https://uploads.developerhub.io/prod/jdK6/2m094dr8im8j68tmjkri1ggotlxswv7zp0ij0p6npba6efpqjky1pcanjjpio3rr.png)

3. Give your connection a name so you can easily identify it later.
4. Enter your **Email Address**. Scroll to the end of this page for more details.
5. Enter your **API Token**. Scroll to the end of this page for more details.
6. Enter your **Domain**. Scroll down to the end of this page for more details.
7. Enter your **Access Token**. Scroll down to the end of this page for more details.

### To generate an Access Token please follow these steps:

1. Log in to your Bitbucket Data Center.
2. Click on your profile picture.
3. Go to Manage Account and then HTTP access tokens.
4. Click on **Create token .**
5. Your **Domain** is the link used for connecting to Bitbucket Data Center.

### Where can I find the Email and API Token for Bitbucket Cloud?

1. Log in to [Bitbucket](https://bitbucket.org/).
2. Click on your profile picture. Under 'Account', you will find your **email address**.
3. Click on Settings.
4. Go to Atlassian account settings and then Security.
5. Click on Create and manage API tokens.
6. Select **Create an API token with scopes**.
