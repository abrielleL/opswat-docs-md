# Installation and upgrading

### Before installation

Before you begin the installation, please ensure that the [System requirements](https://www.opswat.com/docs/supply-chain/installation/system-requirements) are met and that [docker engine](https://docs.docker.com/engine/install/ubuntu/)  is already installed on the system.

If you are installing MetaDefender Software Supply Chain on the same server as MetaDefender Core, the server must meet the cumulative system requirements of all the products.

### Installation

1. Download the package of your choice from the [My OPSWAT](my.opswat.com)
2. Install the package on your computer via the [command line](https://www.opswat.com/docs/supply-chain/installation/installing-using-the-command-line)
3. Open a web browser and point to http://<server name or IP> (by default, port 80 is used)
4. Complete the installation

### Installation notes

- The installation requires internet connectivity in order to acquire packages from the container registry
