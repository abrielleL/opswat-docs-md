# Per User License

This package supports large development teams that requires integration of security solutions into your CI/CD pipelines. The Per User license option simplifies budgeting by aligning costs directly with the number of active users.

**This Packaging Option is Ideal for:**

- Teams with at least 100 developers with active code commits
- Organizations using MetaDefender Software Supply Chain as an integral part of their development workflow

**Included Technologies:**

- MetaScan Multiscanning: 5-engine package (AhnLab, Bitdefender, ClamAV, Eset and K7)
- Proactive DLP: Full capabilities
- SBOM: Full capabilities
