# Anti-phishing for specific users

View as Markdown Ask ChatGPT about this page Ask Claude about this page

To enable anti-phishing for specific users only, perform the following steps:

1. Create an inbound rule

2. For the rule, set the specific users as filter conditions

3. Enable anti-phishing for the rule

4. Save the rule
5. As this rule is specific to some recipients, keep in mind setting it to the appropriate order among other rules
