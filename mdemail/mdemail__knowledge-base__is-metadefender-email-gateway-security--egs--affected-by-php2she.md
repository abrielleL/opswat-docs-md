# Is MetaDefender Email Gateway Security (EGS) Affected by PHP2Shell (CVE-2026-109618 and CVE-2026-109619)?

View as Markdown Ask ChatGPT about this page Ask Claude about this page
## [**Check Your Version**](/docs/mdemail/knowledge-base/is-metadefender-email-gateway-security--egs--affected-by-php2she#check-your-version)

Based on the product-level security assessment, MetaDefender Email Gateway Security does not contain or use PHP.

## [**Security Assessment: Not Affected**](/docs/mdemail/knowledge-base/is-metadefender-email-gateway-security--egs--affected-by-php2she#security-assessment-not-affected)

MetaDefender Email Gateway Security is not affected by CVE-2026-109618 or CVE-2026-109619 within the assessed product scope.

## [**Overview**](/docs/mdemail/knowledge-base/is-metadefender-email-gateway-security--egs--affected-by-php2she#overview)

PHP2Shell refers to two security vulnerabilities in the PHP interpreter: **CVE-2026-109618** and **CVE-2026-109619**. Under certain conditions, an affected PHP runtime may allow remote code execution.

## [**Product Assessment**](/docs/mdemail/knowledge-base/is-metadefender-email-gateway-security--egs--affected-by-php2she#product-assessment)

MetaDefender Email Gateway Security does not contain the PHP runtime targeted by these vulnerabilities.

## [**Is Any Action Required?**](/docs/mdemail/knowledge-base/is-metadefender-email-gateway-security--egs--affected-by-php2she#is-any-action-required)

No EGS-specific patch, hotfix or configuration change is required to address these two PHP vulnerabilities in the assessed product. PHP installed separately as part of another application or service must be assessed independently.

**Note:** This article addresses only the two CVEs above. It does not assess other vulnerabilities or independently installed third-party software.
