# How to Perform a Clean Uninstallation of MetaDefender Email Gateway Security (EGS)?

View as Markdown Ask ChatGPT about this page Ask Claude about this page
## [**Step 1: Run the Uninstallation**](/docs/mdemail/6.4.2/knowledge-base/how-to-perform-a-clean-uninstallation-of-metadefender-email-gate#step-1-run-the-uninstallation)

### [**Option 1: Using the Start Menu**](/docs/mdemail/6.4.2/knowledge-base/how-to-perform-a-clean-uninstallation-of-metadefender-email-gate#option-1-using-the-start-menu)

1. Click on the **Start Menu** and type **Uninstall MetaDefender Email Gateway Security**.
2. Select **Uninstall MetaDefender Email Gateway Security** from the search results.

3. Right-click and choose **Run as administrator** (if required).
4. Follow the on-screen prompts to complete the uninstallation process.

### [**Option 2: Using Control Panel**](/docs/mdemail/6.4.2/knowledge-base/how-to-perform-a-clean-uninstallation-of-metadefender-email-gate#option-2-using-control-panel)

1. Open **Control Panel** and navigate to: **Programs** > **Uninstall a program**.
2. In **Programs and Features**, locate **MetaDefender Email Gateway Security**.
3. Right-click and select **Uninstall**.

4. Follow the steps in the installer to complete the process.

## [**Step 2: Remove Remaining Files**](/docs/mdemail/6.4.2/knowledge-base/how-to-perform-a-clean-uninstallation-of-metadefender-email-gate#step-2-remove-remaining-files)

Navigate to the installation folder (default location):

1. `C:\Program Files\OPSWAT\MetaDefender Email Security`
2. Delete any remaining files and folders.

## [**Step 3: Clean-up Windows registry**](/docs/mdemail/6.4.2/knowledge-base/how-to-perform-a-clean-uninstallation-of-metadefender-email-gate#step-3-clean-up-windows-registry)

Open **Registry Editor** (`regedit`):

1. Press **Win + R**, type `regedit`, and press **Enter**.
2. Navigate to the following path: `HKEY_LOCAL_MACHINE\SOFTWARE\OPSWAT\MetaDefender Email Security`
3. Delete the **MetaDefender Email Security** key along with all its subkeys.

4. Confirm the deletion when prompted.
