# User Guide

## [About This Guide](/docs/mdcloud/operation/user-guide#about-this-guide)

Welcome to the [MetaDefender Cloud](https://metadefender.opswat.com/) guide. This guide is intended to provide the information you need to:

- Start analyzing files with 20+ anti-malware engines
- Use [MetaDefender Cloud Public APIs](/docs/mdcloud/integrations/public-apis)
- Learn about new features, updated features, and bug fixes
- Learn about frequently asked questions and additional concepts through our library of knowledge base articles

## [Key Features of MetaDefender Cloud](/docs/mdcloud/operation/user-guide#key-features-of-metadefender-cloud)

- File Analysis - Analyzing binaries with 20+ anti-malware engines
- [Deep CDR](https://www.opswat.com/technologies/data-sanitization) (aka Content Disarm and Reconstruction) with support for 150+ file types
- Sandbox dynamic analysis to detect more unknown and targeted attacks
- Binary vulnerability data assessment
- IP-Domain reputation
- Threat Intelligence Feeds
