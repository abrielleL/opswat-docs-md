# Licenses and Usage Limits

Active license details (both paid and trial versions) are available from user profile under “Licenses” on the [OPSWAT Portal](https://id.opswat.com/login) (this is also available on the Account Information page after logging into [MetaDefender Cloud](https://metadefender.opswat.com/?lang=en)). Upon successful procurement, new limits will refresh in this location (there will be up to 24 hours delay if you have purchased/upgraded the license recently)

Each user is registered with unique API Keys, with contractual limits configured per:

- [Accounts' Organization](/docs/mdcloud/account-management/accounts--organization)

  - If part of an organization, the limits will be determined at the organization level
  - All usage of the users within an organization will be aggregated to count towards the limits of the organization
- Individual User

  - If not part of an organization, each individual will have their own usage limits

## [How To Use a Coupon for MetaDefender Cloud](/docs/mdcloud/account-management/licenses-and-usage-limits#how-to-use-a-coupon-for-metadefender-cloud)

Coupons are OPSWAT’s time-bound promotions for MetaDefender Cloud, offering various limit increases like file scans or hash lookups.

Navigate to Dashboard/Account Information from Account Profile to apply the coupon

Note

If you already have an active coupon, you cannot apply another one until the first one expires.

Info

Contractual APi limits are shared between multiple registered users of the same organization
