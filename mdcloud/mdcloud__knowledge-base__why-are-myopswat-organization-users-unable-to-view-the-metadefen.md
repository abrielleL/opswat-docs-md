# Why are MyOPSWAT Organization Users Unable to View the MetaDefender Cloud Organization License and Scan History?

**Issue**

MyOPSWAT organization users may find that they cannot view the MetaDefender Cloud Organization license or scan history.

**Explanation**

The MetaDefender Cloud license (API Key) is tied to an individual user account (email address), rather than the organization itself. As a result, each user within a MyOPSWAT organization will only see their own API Keys in under License Management > Cloud Services, for MetaDefender Cloud and IT Access.

**Access Requirements**

For enrolled users to gain access to the MetaDefender Cloud Organization Account Console, the organization must have a **Professional** or **Enterprise** tier license.

More details on the differences between **Standard, Professional**, and **Enterprise** tiers can be found here: [MetaDefender Licensing](https://metadefender.opswat.com/licensing).
