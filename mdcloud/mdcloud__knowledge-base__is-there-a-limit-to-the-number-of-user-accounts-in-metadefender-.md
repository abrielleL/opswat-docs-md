# Is There a Limit to the Number of User Accounts in MetaDefender Cloud?

This article applies to all active MetaDefender Cloud license holders - whether your product is paid for or issued for evaluation purposes.

MetaDefender Cloud supports Organization feature where multiple users can be assigned to use the resources. However, there are important considerations regarding licensing and usage limits.

#### [**User Account Limits**](/docs/mdcloud/knowledge-base/is-there-a-limit-to-the-number-of-user-accounts-in-metadefender-#user-account-limits)

There is **no hard limit** on the number of user accounts you can assign to an MD Cloud organization. However, **total usage across all users is aggregated and subject to your organization’s overall license limits**, including:

- File scanning limits
- Rate limits defined by your licensing plan

#### [**License Requirements**](/docs/mdcloud/knowledge-base/is-there-a-limit-to-the-number-of-user-accounts-in-metadefender-#license-requirements)

Organization feature is available only for **Professional and Enterprise licensing plans.** Access to this feature is managed at the organizational level.

#### [**Creating User Accounts**](/docs/mdcloud/knowledge-base/is-there-a-limit-to-the-number-of-user-accounts-in-metadefender-#creating-user-accounts)

To add a new user to your MD Cloud organization:

1. Ensure the user is registered at <https://my.opswat.com/>.
2. Add the registered user to your organization from the MetaDefender Cloud portal.

#### [**Understanding Organizations in MD Cloud**](/docs/mdcloud/knowledge-base/is-there-a-limit-to-the-number-of-user-accounts-in-metadefender-#understanding-organizations-in-md-cloud)

An “Organization” in MD Cloud is a **logical grouping of multiple user accounts** with shared configurations and usage metrics. Features include:

- Adding multiple users under one organization
- IP allowlisting for MD Cloud APIs across all organization users
- Role-based access control (RBAC) support

#### [**Account Types Supported by OPSWAT**](/docs/mdcloud/knowledge-base/is-there-a-limit-to-the-number-of-user-accounts-in-metadefender-#account-types-supported-by-opswat)

OPSWAT currently supports two user types:

- **Individual Users (no organization affiliation)**
- **Organization Users** (can have multiple roles with RBAC- role-based access control)
