# Who can I contact to have a file scanned on Metadefender Cloud removed?

To request the removal of a file that has been scanned in the MetaDefender Cloud, please submit a request using our Data Subject Request Form.

### [**Steps to Submit the Request**](/docs/mdcloud/knowledge-base/who-can-i-contact-to-have-a-file-scanned-on-metadefender-cloud-r#steps-to-submit-the-request)

- To request the removal of a file, please use the official [OPSWAT Data Subject Request Form](https://www.opswat.com/legal/data-subject-request-form) provided by OPSWAT.
- Fill in the required fields on the form. Ensure you provide accurate information regarding the file in question.
- In the form’s description section, specify your request to have the file scanned on MetaDefender Cloud removed.
- Submit the form for review. OPSWAT's support team will assess your request and proceed accordingly.

### [**What Happens Next?**](/docs/mdcloud/knowledge-base/who-can-i-contact-to-have-a-file-scanned-on-metadefender-cloud-r#what-happens-next)

Once your request has been submitted, OPSWAT will process it and follow up with you regarding the next steps. This may include confirming your identity and providing further instructions if necessary.

Support:

If **Further Assistance** is required, please proceed to log a [**support case or chatting with our support engineer**](https://my.opswat.com/portal/support).
