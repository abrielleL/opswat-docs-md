# Why should I use MetaDefender Cloud instead of a product from another vendor?

This article applies to all active MetaDefender Cloud license holders - whether your product is paid for or issued for evaluation purposes. For more information on our range of licensing and evaluation options, please [Read This](https://metadefender.opswat.com/licensing).

While there are numerous free and paid, cloud-based multi-scan security solutions on the market, OPSWAT prides itself on the unique additional features and value-adding functionality of its MetaDefender Cloud solution.

These features include:

**Privacy Features**

- Private Scanning

  - We have the ability to scan files without storing them on our servers or sharing them with anti-malware engine vendors.
- Private Processing

  - We take privacy one step further by ensuring that the scan results of a particular file will only be accessible to the person who scanned it.
- Optional RSA Key Encryption

  - As well as encrypting sanitized files after Deep CDR processing, we give users the option to use RSA keys to make secure webhook calls.
  - For more information regarding RSA key encryption and how to use it in conjunction with MetaDefender Cloud, please [Read This](https://docs.opswat.com/mdcloud/account-management/rsa-key-encryption).

**Data Sanitization (Deep Content Disarm & Reconstruction)**

- Our industry leading Deep CDR technology leaves no stone unturned, by assuming that all files are malicious.
- Deep CDR takes files, breaks them down into their most basic components, removes any elements that might be malicious, then reconstructs them safely, preserving at least 99% of their original quality.
- For more information on MetaDefender Cloud’s Deep CDR feature, [Read This](https://www.opswat.com/technologies/data-sanitization).

**Advanced Threat Intelligence**

- Having actively collected file reputation data since 2012, we have amassed a database of over 40 billion hashes, against which our users check their files.
- We provide live feeds for both the blocklisting and allowlisting of hashes, which can also be used in offline environments.
- These feeds are updated instantly with the latest file hashes analyzed by our platform from various sources, including malware sharing programs, customer files and more.
- We gather data from multiple real-time online sources that specialize in IP address, domain and URL reputation, providing an aggregated-results based lookup service to our users.

**On-Premises Deployment Options**

- If a cloud cyber security solution like MetaDefender Cloud is ill-suited to your organization, OPSWAT’s MetaDefender Core might be the right option for you.
- Read more about this state-of-the-art on-premises cyber security option [Here](https://www.opswat.com/products/metadefender/core).

**Faster File Scans**

- Depending on a solution that hinges on engine statuses, the file type and your own security hardware can be challenging, but MetaDefender Cloud frees you from these limitations.
- 10 To +/- 20 engine multi-scans via MetaDefender Cloud can take as little as <500ms.
- OPSWAT stands by its commitment to ensure that all MetaDefender Cloud clients enjoy an exceptional user experience, and has implemented both Scan Time and Availability SLAs that you can read about [Here](https://docs.opswat.com/mdcloud/operation/api-security-faq#response-time-sla).

**Advanced Multi-Scan**

- MetaDefender Cloud utilizes a range of 20+ (depending on licensing option) leading anti-malware scan engines, with a 99.4% detection rate, to scan user files.
- The anti-malware engines selected and used by MetaDefender Cloud are SDK and CLI packages that employ state-of-the-art signature, heuristic, and machine learning detection methods.
- The result, a combination of both quality and quantity that places MetaDefender Cloud multi-scanning tiers above the rest.
