# Incident Reporting on MetaDefender Cloud

MetaDefender Cloud leverages OPSWAT's status page for cloud services, where we regularly post service performance and incident information.

## [How Do I Subscribe to Notifications About Incidents on Metadefender Cloud?](/docs/mdcloud/legal/incident-reporting-on-metadefender-cloud#how-do-i-subscribe-to-notifications-about-incidents-on-metadefender-cloud)

Go to [trust.opswat.com](http://trust.opswat.com) and click on the button "SUBSCRIBE TO UPDATES".

The page provides several options for receiving notifications about outages and scheduled maintenance. Options include email, SMS, embed code, RSS feed, and others.

## [What Kinds of Incidents Are Posted to trust.opswat.com?](/docs/mdcloud/legal/incident-reporting-on-metadefender-cloud#what-kinds-of-incidents-are-posted-to-trustopswatcom)

Currently, you can find several types of information posted to this page:

- Incidents such as outages and unexpected changes
- Performance degradation
- Scheduled maintenance

## [I Am Having an Issue with MetaDefender Cloud. Where Can I Report It?](/docs/mdcloud/legal/incident-reporting-on-metadefender-cloud#i-am-having-an-issue-with-metadefender-cloud-where-can-i-report-it)

If you're experiencing an issue with MetaDefender Cloud, you can always visit the [OPSWAT Portal](https://go.opswat.com/) and submit a ticket to our support team from there.
