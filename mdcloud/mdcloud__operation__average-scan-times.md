# Average Scan Times

Below are some statistics related to the average scan times for different file types:

Excluding archives, most of the file scans finish in **under 8 seconds**!

| **File Type Category** | **Average Scan Time (sec/file)** |
| --- | --- |
| Executables (E) | 7.739 |
| Documents (D) | 2.152 |
| Archives (A) | 2.900 |
| Media video format (M) | 2.921 |
| PDF (P) | 2.171 |
| Grafic files (G) | 3.328 |
| Text files (T) | 2.569 |
| Mail messages (Z) | 2.615 |
| Other (O) | 2.672 |

Please take into consideration that:

- The numbers show the average total time for multiscanning.
- These are just average values, your actual scan times might differ. One big factor that influences scan times is file size.
- The results should be viewed as a guideline and not a performance guarantee.
- These numbers do not take into consideration the queue time: every file uploaded will be placed in a queue where it waits to be picked up and sent to scanning. Usually, this happens instantly, but in some cases, it could be that the file needs to wait up to several minutes to be picked up.
- Archive scan times are the highest and are influenced by how many files are inside the archive.
