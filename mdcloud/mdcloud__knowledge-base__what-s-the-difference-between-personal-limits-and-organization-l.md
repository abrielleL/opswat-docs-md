# What's the difference between Personal limits and Organization limits? If the Organization limits expire or are used up, does it automatically switch to using Personal limits?

Applied to latest version of MD Cloud

**Personal limit**:

- For every registered account with MD Cloud, there will be a default set of limits assigned for the account
- Customer can purchase MD Cloud limit and use it personally

**Organization limit** (Professional and Enterprise tier):

- Is a set of purchased limits assigned to an Organization
- This limit is shareable to the Organization’s users and suborganization (SubOrg)

**How it works**:

- Once a user account is added to an Organization or SubOrg, whenever the user submit a file/object for scanning to MD Cloud, the system will deduct Org limit or SubOrg limit.
- Once the Org and SubOrg limit is depleted, the next scan submission will be failed.
- For Professional and Enterprise tiers, a buffer limit (the ability to temporarily exceed usage limits) is available, ranging from 20% to 50%. For more details, please refer to the following link. [MetaDefender Cloud | Licensing](https://metadefender.opswat.com/licensing)

**Note**:

- Once added to Organization, the user cannot utilize its personal limit until the user removed himself out of the Org/SubOrg
