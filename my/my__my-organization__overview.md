# My Organization

> **Who can see this feature?**
>
> **User type:** [Organization user](https://www.opswat.com/docs/my/get-started/user-types-in-my-opswat-portal#organization-user)

The **My Organization** module enables administrators to manage users, roles, and configure security settings, organizational information, and more.

![](https://uploads.developerhub.io/prod/JYvy/jvdidhxw7ecxdc37t1ohgwb407suvq2y8rmafrdnvoa9q1o3khuqohzraetpge7d.png)

## Key Components

### 1. General Information

Access and update your organization's details, including name, contact information, and other essential settings.​

👉 [Learn more about General Information](https://www.opswat.com/docs/my/my-organization/general-information)

### 2. Users and Roles

Manage user access and permissions using Role-Based Access Control (RBAC). Invite new users, assign roles, and oversee user activities within your organization.​

👉 [Explore Users and Roles Management](https://www.opswat.com/docs/my/my-organization/users-and-roles)

### 3. Security

Configure security settings to protect your organization's data.

👉 [Configure Security Settings](https://www.opswat.com/docs/my/my-organization/security)

### 4. Critical Alert Users

Designate users to receive important email alerts, including license expirations and urgent announcements from OPSWAT.

👉 [Manage Critical Alert Users](https://www.opswat.com/docs/my/my-organization/critical-alert-users)

### 5. Event History

Track and review a log of significant events within your organization, such as user invitations, role changes, and security updates.​

👉 [View Event History](https://www.opswat.com/docs/my/my-organization/event-history)

### 6. Organization List

Easily view and switch between all organizations you're joining.

👉 [View Organization List](https://www.opswat.com/docs/my/my-organization/organization-list)
