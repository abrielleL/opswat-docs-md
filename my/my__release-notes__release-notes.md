# My OPSWAT Portal v2026.4.3.0

| **Version** | v2026.4.3.0 |
| ---- | ---- |
| **Release date** | November 16th, 2026 |
| **Release Summary** | This release introduces the **OPSWAT CVE Hub** with opt-in email advisories to help teams proactively monitor product vulnerabilities. It also launches **OESIS Submission**, a self-service workflow enabling software providers to submit application and OESIS OK Certification with end-to-end progress tracking |

### **New Features**

#### **New OPSWAT CVE Hub and Security Advisories**

![](https://uploads.developerhub.io/prod/JYvy/g62l6qyly91r7plip47qz6r17mckghudwy2g96n44n5i9tdy66eybpv2qt3lgawj.png)

- **Centralized Disclosures:** Search and filter OPSWAT-specific CVEs by product, severity, and affected version.
- **Actionable Guidance:** Review clear affected versions, and direct links to threat intelligence insights.
- **Proactive Security Advisories:**  Opt in to receive instant notifications when new CVEs are published or existing CVEs are updated.

**Access path:** Trust Center > Vulnerability Disclosure > OPSWAT CVEs

---

#### **Self-Service Application and OESIS OK Submission**

![](https://uploads.developerhub.io/prod/JYvy/za0dr6wtkkkp02yko03pews3nsvitw8x80ese7szn4t03t7nobuq7su3pc9uxsv9.png)

Software vendors and developers can now **request application** integration into the OESIS Framework or submit for **OESIS OK Certification**, monitor progress in real time, and download verified certification reports, all in My OPSWAT Portal. This replaces opaque email or support-ticket follow-up with visible progress and feedback.

**Access Path:** OEM Portal > [OESIS Submission](https://www.opswat.com/docs/my/oem-portal/oesis-submission)
