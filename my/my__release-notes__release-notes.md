# My OPSWAT Portal v2026.4.1.0

| **Version** | v2026.4.1.0 |
| ---- | ---- |
| **Release date** | October 19th, 2026 |
| **Release Summary** | OEM customers now see a live **OESIS Vulnerability** snapshot in the OEM Portal and can reach the full MetaDefender Tri CVEs dashboard in one click. Downloading support-case file attachments now requires My OPSWAT Portal sign-in, so only authorized users on the case can retrieve them. **Trust Center** now combines OPSWAT’s security, compliance, and vulnerability programs in one place |

### **New Features**

#### **OESIS Vulnerability**

![](https://uploads.developerhub.io/prod/JYvy/gx3zz8dstivq3ii7fcy0pu7g4an0v03zq8docxyf8e0omlkmj6i57luw7qdfnwsi.png)

OEM customers now see a live OESIS Vulnerability summary of CVE data inside the OEM Portal. Clicking the Live Vulnerability Data button routes you to the **full OESIS-supported vulnerability landscape** in MetaDefender Tri, already authenticated through single sign-on.

**Access path:** Left menu > OEM Portal > OESIS Vulnerabilities

**Further reading:** [OEM Portal](https://www.opswat.com/docs/my/others/oem-portal)

---

### **Enhancements**

#### **Trust Center**

![](https://uploads.developerhub.io/prod/JYvy/5uabp83151jefjk9jg6aoizvqa247ma34meu28o3iwt5jqap4glugmj6vwuq8j81.png)

**Trust Center** now brings OPSWAT’s security, compliance, and vulnerability programs together in one place, including:

- **Security Assurance** carries forward today's Trust Center functionality under a new name, including SOC 2 and ISO 27001 certification access after NDA acceptance, compliance documentation, and security-questionnaire submission and management.
- **Vulnerability Disclosure** moves here from the top level of the left menu, and existing functionality is unchanged.

**Further reading:** [Trust Center](https://www.opswat.com/docs/my/trust-center/trust-center)

---

#### **Secure Support-Case File Downloads**

Downloading a file attached to a support case now requires My OPSWAT Portal sign-in, so only users authorized on that case can retrieve its attachments. The earlier download link, which worked for anyone who had it, no longer grants access on its own.

---

#### **[For Partners] Expand All and Collapse All in Customer Hardware**

![](https://uploads.developerhub.io/prod/JYvy/sdd1u7ruh8k7m2ds6hporb039r4g6zr6ejxesqcgsxcay7uavrdr8ytu5xwf9sy3.png)

A new **Expand all** / **Collapse all** button in the **Customer Hardware** list lets you open or close the whole list in one action.

---

#### **Local Time Zone by Default in Personal Information**

The personal information popup now defaults to your local machine's time zone.

---
