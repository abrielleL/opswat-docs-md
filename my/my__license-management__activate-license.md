# Activate License

> **Who can use this feature?**
>
> - **User type:** [Organization user](https://www.opswat.com/docs/my/get-started/user-types-in-my-opswat-portal#organization-user)
> - **Role:** View only or Full access on [License Management](https://www.opswat.com/docs/my/my-organization/single-organization#role-objects-and-permissions)

In My OPSWAT Portal, users can activate a license keys of OPSWAT Products for offline deployments where an OPSWAT Product instance can not connect to OPSWAT License server, such as in an air-gapped environment.

Here are steps to activate a license key:

1. From the left sidebar, select License Management, click **Activate License**

![](https://uploads.developerhub.io/prod/JYvy/me0cd8ilei8l3gro93fx3eqzstraqr18zvf37ggoc28d41ihmh5w1jjzamjwdypm.png)

2. The activation dialog will pop up. Select what product you would like to activate and fill in all the required fields. Then select **Activate**

![](https://uploads.developerhub.io/prod/JYvy/4tq8ovjyldzcdtpznrlr6sol23qylofz7yvwwfmrwvmaa9xn16k7xmcyqsrs5oji.png)

- **Product:** The OPSWAT Product that you wish to perform license activation.
- **License Key:** The license keys associated with the OPSWAT Product.
- **Deployment ID:** The deployment ID of the product instance
- **Description:** The description you want to add for this license.

3. If the activation is successful, an offline license file will be made available. Click Download to download the license file.

![](https://uploads.developerhub.io/prod/JYvy/305sm8hcfdjtc7yehy984wi51n37bunzw1q603ul6m5th6r6s44fgiftb467d5vw.png)
