# Can I Assign Multiple Super Admins to My OPSWAT Organization?

## **Overview**

My OPSWAT currently supports **one Super Admin per organization**. The Super Admin is the single designated owner for organization-level controls and administrative authority.

Because of this, **multiple users cannot be assigned as Super Admins simultaneously**.

## **Managing Administrative Coverage**

To ensure adequate administrative coverage, organizations can use the following options:

### **Assign Multiple Administrators**

Organizations can assign multiple users to the standard **Admin** role or create/use custom administrative roles.

Admins can perform most day-to-day administrative activities, including:

- Managing users
- Accessing and managing licenses
- Submitting support requests
- Performing other organization management tasks based on their assigned permissions

This allows multiple team members to share administrative responsibilities while maintaining a single Super Admin.

### **Transfer Super Admin Access**

If Super Admin responsibility needs to be transferred, the current Super Admin can assign the role to an existing Admin.

To transfer Super Admin access:

1. Sign in to **My OPSWAT**.
2. Navigate to **My Organization > Users**.
3. Locate the user who should become the Super Admin.
4. Select the **⋮ (three-dot) action menu** next to the user.
5. Select **Set as Super Admin**.

The selected user becomes the organization's Super Admin.

> **Note:** Transferring the role does not add a second Super Admin. It transfers the existing Super Admin responsibility from the current Super Admin to the selected user.

### **Super Admin Departure or Emergency**

If the current Super Admin leaves the organization or is otherwise unavailable, OPSWAT Support can assist with transferring Super Admin access to another designated administrator.

Appropriate verification will be required before the transfer can be completed.
