# Preferences

> **Who can use this feature?**
>
> **User type:** Both [Personal](https://www.opswat.com/docs/my/get-started/user-types-in-my-opswat-portal#personal-user) and [Organization](https://www.opswat.com/docs/my/get-started/user-types-in-my-opswat-portal#organization-user) users

The **Preferences** tab in the My OPSWAT Portal allows you to customize your communication settings, manage product notifications, and control access to certain features.​

![](https://uploads.developerhub.io/prod/JYvy/1289p28tjwgw7v9e99bmi0gk4l2a19g6sh3rgnnf8hp0bimfqfl0h8elyznvudg4.png)

### Email Subscriptions

This section is available for OPSWAT customers (who have OPSWAT product licenses) **OR** users who use working email (not Gmail). You can opt in to receive:

- **OPSWAT Updates**
- **Cybersecurity Blog**
- **Company Activity Newsletter**
- **OPSWAT Academy Newsletter**
- **Webinars**
- **OPSWAT Trust Center**
- **Product Releases**: Notifications about new product versions.
  - *Your licensed products*: Receive updates only for products you have licenses for.​
  - *Custom selection*: Manually select the products you want to receive updates about.​

Note The "Your licensed products" option is available only if you have active licenses.

> **Info**
>
> The default value for Product Releases is Customize option and all products are added for:
>
> - New users who opted in "Yes, I would like to receive email communications from OPSWAT." option on the registered page.
> - Old users who opted in Product Releases option but don't have license before My OPSWAT Portal enhanced this function in version 2024.2.10
