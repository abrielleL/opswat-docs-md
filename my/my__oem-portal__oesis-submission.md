# OESIS Submission

> **Who can use this feature?**
> Any registered My OPSWAT Portal user can use **My Submissions** without a paid OEM license. Viewing **Organization Submissions** requires the **OESIS Submission - Organization Submissions** permission. Only the person who submitted a request can edit and resubmit it.

Use **OESIS Submission** to send an application to the OESIS Framework or request OESIS OK Certification, then check the request's status and respond when OPSWAT asks for more information.

## **Open OESIS Submission**

Sign in to My OPSWAT Portal and open **OEM Portal**.

- OEM customers see an **OESIS Submission** tab alongside the OEM overview
- Customers without OEM permission go directly to **OESIS Submission**.

## **Create a submission**

![](https://uploads.developerhub.io/prod/JYvy/za0dr6wtkkkp02yko03pews3nsvitw8x80ese7szn4t03t7nobuq7su3pc9uxsv9.png)

1. In **OESIS Submission**, select **Submit**.
2. Choose **Submission type**: **Add Application to OESIS Framework** or **OESIS OK Certification**.
3. Upload an **Application Package**, then review or enter **Application name**, **Version** and **Operating system**.
4. Choose the category for your submission type. For **OESIS OK Certification**, also choose **Certification level** and upload the required **Test configuration file**.
5. Add at least one **Technical contact**. You can also add a license key or file and additional information.
6. Wait for required files to finish uploading, then select **Create Submission**.

Your request appears in **My Submissions** with a submission ID. **OESIS OK Certification** requests can seek Gold or Platinum, but the awarded level depends on the test result.

## **Track a submission**

![](https://uploads.developerhub.io/prod/JYvy/qzf2ub8bwse1n4currccsphu586o1nd3yqu7v990smjtcbsqulacjzdrr51q8usn.png)

Open **My Submissions** to see requests you sent, including personal requests and requests sent while you belonged to an organization. Select a **Submission ID** to open its details and progress. The list and details fetch the current status when you open or refresh them; status changes are not pushed into an open page.

![](https://uploads.developerhub.io/prod/JYvy/6bxbnczixxyi0fpffuzcvs8rb7zvyb8qdzr7ocozojswrc463se1o005zm1wd2gu.png)

If you have **OESIS Submission - Organization Submissions** permission, use **Organization Submissions** to view requests sent by other members of your currently selected organization. That permission does not let you edit their requests.

## **Respond to a request for information**

When a submission shows **Info requested**, open its details and select **Edit & resubmit**. The submitter has 30 days to provide the requested information or replacement file. If the request is not resubmitted within 30 days, OESIS marks it **Rejected**.

## **Download submission report**

Select **Download report** from the submission details or the row action menu, reports are available for the following submission statuses.

- **OESIS OK Certification:** `Passed`, `Failed`
- **Add Application to OESIS Framework: **`Passed`, `Rejected`
