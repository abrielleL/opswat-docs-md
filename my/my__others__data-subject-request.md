# Data Subject Request

The Data Subject Request form allows users to easily submit data management requests, including:

- Request data deletion
- Restrict how data is used
- Access and review data
- Correct data (e.g., update email address)

![](https://uploads.developerhub.io/prod/JYvy/op4f2brv8uo0u70mb11bsifjc95xrles32vi7aefetifof8ko79ftjnk6c420qy5.png)

**Path:** Account menu > Data Subject Request

1. Access [Data Subject Request](http://my.opswat.com/portal/data-subject-request)
2. Fill out all required information and click Submit
3. Follow the verification instructions in the email sent to your account
