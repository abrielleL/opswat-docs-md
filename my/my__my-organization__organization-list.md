# Organization list

> **Who can use this feature?**
>
> - **User Type:** [Organization user](https://www.opswat.com/docs/my/get-started/user-types-in-my-opswat-portal#organization-user)

If you are a member of multiple organizations, by navigating to Your name in the upper right corner

- View the organization list you're belong to.
- See the current Organization that the you're locating in.

![](https://uploads.developerhub.io/prod/JYvy/9hpk1tfmhq0lh0g406djxsw007flzj0pu3m2bg7j59r7rui9exjqbtth4hdxggec.png)

If a user registers an account and does not belong to any organization but wishes to use the Central Management component's functions, My OPSWAT will display a warning message to inform the user about certain limitations in this situation.

![](https://uploads.developerhub.io/prod/JYvy/hqphmbx4nzyzuinw7wdld0u1y5unjdfa86tmv87efv0mfere4bvn80p6libo2feq.png)

My OPSWAT will create a personal Organization for them to use the Central Management component functions. This organization serves the following purposes:

**Testing Product Management Functions:** It allows users to explore and utilize features in a controlled environment.

**User Limitations:** Users cannot invite others to this organization, ensuring it remains private.

**Visibility:** This organization will not be displayed on the My OPSWAT Portal, allowing users to focus on Central Management.

**License Restrictions:** There will be no linked licenses to this organization, reinforcing its exclusive use for testing.

![](https://uploads.developerhub.io/prod/JYvy/lnxmbxsvinb275o3vvn8dee8bge36zdb225yy2ta98mw63e84wyakqsfagbohaoy.png)

> **Warning**
>
> Should not use a personal organization to manage products. Instead, please contact the OPSWAT Support team to create an organization that will enable you to manage licenses and products more effectively.
