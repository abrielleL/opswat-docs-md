# Changing MetaDefender Drive Configuration

View as Markdown Ask ChatGPT about this page Ask Claude about this page

The following guideline describes how to change the configuration of a MetaDefender Drive instance remotely.

1. Go to the **MetaDefender Drive** management page under **Inventory** in the sidebar.

2. Click the **Settings** button in the gear icon's drop-down menu.
3. OPSWAT Central Management will load the settings of the instance. Change the settings as required.
