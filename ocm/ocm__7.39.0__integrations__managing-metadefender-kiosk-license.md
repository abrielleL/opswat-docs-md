# Managing MetaDefender Kiosk Windows License

The following guideline describes how to activate or deactivate the license of a MetaDefender Kiosk Windows instance remotely.

1. Go to the **MetaDefender** **Kiosk** **Windows** management page under **Inventory** in the sidebar.

2. Select **License Information** for the MetaDefender Kiosk Windows instance you wish to configure .

3. You can choose to remove or update the current license via the corresponding button. If **Remove License** is chosen, you are returned to the MetaDefender Kiosk Windows management, which should update accordingly.

4. If **Update License** is chosen, the dialog **Metadefender Kiosk Windows Activation** will be opened. Please refer to the corresponding section for additional details.

## [Online product activation](/docs/ocm/7.39.0/integrations/managing-metadefender-kiosk-license#online-product-activation)

The following guideline describes how to activate the MetaDefender Kiosk Windows license online.

1. Select the **Online Activation** option.

2. Enter the key.

3. The dialog will be closed and the MetaDefender Kiosk Windows page will be reloaded automatically if the result is successful.

## [Offline product activation](/docs/ocm/7.39.0/integrations/managing-metadefender-kiosk-license#offline-product-activation)

The following guideline describes how to activate the MetaDefender Kiosk Windows license offline.

1. Select the **Offline Activation** option.

2. The **Offline Activation** menu will be opened.

## [Offline Activation details](/docs/ocm/7.39.0/integrations/managing-metadefender-kiosk-license#offline-activation-details)

1. Log into <https://my.opswat.com>
2. Select Activate New License on the sidebar
3. Select MetaDefender Kiosk Windows V4.X as **MetaDefender Package.**
4. Fill in the requested information about your deployment.

- **Activation Key:** The activation key of MetaDefender Kiosk Windows that you have received.

- **Deployment ID:** The deployment ID shown in the previous section.

- **Optional description:** The description for this deployment.

4. Click the **Request Unlock Key** button. The **Download Unlock Key** link appears.

5. Click the **Download Unlock Key** link and save the activation file.

6. Go back to OPSWAT Central Management's Web Management Console. Browse for the activation file and click the **ACTIVATE** button.

7. The dialog will be closed and the MetaDefender Kiosk Windows page will be reloaded automatically if the result is successful.
