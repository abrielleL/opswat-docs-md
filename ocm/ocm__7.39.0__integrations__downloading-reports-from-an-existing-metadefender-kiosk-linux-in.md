# Downloading reports from an existing MetaDefender Kiosk Linux instance

The following guideline describes how to download reports from an existing MetaDefender Kiosk Linux instance.

## [Download latest reports from instance list:](/docs/ocm/7.39.0/integrations/downloading-reports-from-an-existing-metadefender-kiosk-linux-in#download-latest-reports-from-instance-list)

1. Go to the **MetaDefender Kiosk Linux** management page under **Inventory** in the sidebar.

2. Select the MetaDefender Kiosk Linux instance that you want to download the report from.

3. Select one of **Download latest report (json), Download latest report (pdf)** or **Download latest report (txt)**.

## [View and download reports from a specific instance:](/docs/ocm/7.39.0/integrations/downloading-reports-from-an-existing-metadefender-kiosk-linux-in#view-and-download-reports-from-a-specific-instance)

1. Go to the **MetaDefender Kiosk Linux** management page under **Inventory** in the sidebar.

2. Click on a MetaDefender Kiosk Linux instance's entry to go to its details page.

3. Select the report(s) to be downloaded by clicking their checkboxes. Select one of **Download report (json), Download report (pdf)** or **Download report (txt)** from the drop-down action menu.
