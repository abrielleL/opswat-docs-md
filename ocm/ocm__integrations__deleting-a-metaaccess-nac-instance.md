# Deleting an existing MetaAccess NAC instance

View as Markdown Ask ChatGPT about this page Ask Claude about this page

The following guideline describes how to delete a MetaAccess NAC instance from OPSWAT Central Management.

1. Navigate to the **MetaAccess NAC** management page under **Inventory** in the sidebar.

2. Select the MetaAccess NAC instance that you want to delete.

3. Click the **ACTIONS** drop-down menu and choose the **Delete** option.

Info

The dialog will be closed and the MetaAccess NAC page will be reloaded automatically if the result is successful.
