# Changing MetaDefender ICAP Server Configuration

The following guideline describes how to change the configuration of a MetaDefender ICAP Server instance remotely.

1. Go to the **MetaDefender ICAP Server** management page under **Inventory** in the sidebar.

2. Click the **Settings** button in the gear icon's drop-down menu.
3. OPSWAT Central Management will load the settings of the instance. Change the settings as required.

4. Change any settings and click the **Submit** button.
