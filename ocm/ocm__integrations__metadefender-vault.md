# MetaDefender Managed File Transfer

MetaDefender Managed File Transfer (formerly MetaDefender Vault) offers a safe process for transferring files to and from secure networks as well as a way to safely store and limit access to files. With the native integration between MetaDefender Managed File Transfer and MetaDefender Core, you can be sure that only files that were not detected as a threat will be accessible to your organization.
