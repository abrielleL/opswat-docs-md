# Installing OPSWAT Central Management

Before starting OPSWAT Central Management (OCM) installation, please make sure your server meets the [hardware and software system requirements](/docs/ocm/installation/recommended-system-requirements) .

## [Installation steps:](/docs/ocm/installation/installing-opswat-central-management#installation-steps)

1. Download the **OPSWAT Central Management** installer from [My OPSWAT](https://my.opswat.com/portal/products) to your server. Make sure that you download an applicable package for your server operating system/distribution.
2. Please ensure that your server meets the [system requirements.](/docs/ocm/installation/recommended-system-requirements)
3. Install the package on your server:

   1. [On Windows](/docs/ocm/installation/on-windows)
   2. [On Red Hat Enterprise Linux](/docs/ocm/installation/on-red-hat-enterprise-linux)
   3. [On Ubuntu](/docs/ocm/installation/on-ubuntu)
4. After the installation is finished, you can access the OPSWAT Central Management console via two methods.

   1. Use the OPSWAT Central Management shortcut that was created during installation on the desktop.
   2. Open a web browser and point to <server name or IP>:<port>, which is the address of your server : e.g., <http://localhost:9000>
5. Complete the required steps of the [configuration wizard](/docs/ocm/quick-start/configuration-wizard).
6. You must [perform license activation for](/docs/ocm/installation/activating-license) this deployment to use its full features.
