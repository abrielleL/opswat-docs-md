# Configuration wizard

On the first time, you access the OPSWAT Central Management Console, you are requested to complete a basic configuration wizard before using the product. The console will be available only after you have successfully finished this wizard.

To get-started, click on **CONTINUE**.

Warning

Sensitive information

The wizard may transfer sensitive information over an unencrypted connection. Always use this wizard on a secure, closed network or localhost, and with care!

Basic configuration steps

## [Admin User Setup](/docs/ocm/7.39.0/quick-start/configuration-wizard#admin-user-setup)

The next step is to set up an administrator account. This account is the first one allowed to access the Web Management Console and is used to create accounts for other users. You have to fill all the fields in this step before continuing. When you are done, click **NEXT** to continue.

The following information is required for the administrator account:

| EMAIL | The email address of the account. It is used to log into the Web Management Console. |
| --- | --- |
| DISPLAY NAME | The display name of the account. It will be displayed in the top right corner of the Web Management Console. Please note that the display name is not the equivalence of a username and cannot be used to log into the Web Management Console. |
| PASSWORD | The password of the account. |

Warning

The password is sent in plaintext.

## [Wizard Completed](/docs/ocm/7.39.0/quick-start/configuration-wizard#wizard-completed)

After you have completed every step, click the **FINISH** button to complete the wizard. The product's services will be restarted and your browser will be redirected to the web management console. This can take several seconds. If the console doesn't show up, please refer to our [troubleshooting articles](/docs/ocm/7.39.0/troubleshooting/the-management-console-hung-at-the-loading-step).

You can log into the console with the administrator account that has just been created in the previous steps.
