# Deleting an existing MetaDefender Managed File Transfer instance

The following guideline describes how to delete a MetaDefender Managed File Transfer instance from OPSWAT Central Management.

1. Go to the **MetaDefender** **Managed File Transfer** management page under **Inventory** in the sidebar.

2. Select the MetaDefender Managed File Transfer instance that you want to delete.

3. Click the **ACTION** drop-down menu and choose the **Delete** option.

Info

After PIN verification, the management page will reload if the result is successful.
