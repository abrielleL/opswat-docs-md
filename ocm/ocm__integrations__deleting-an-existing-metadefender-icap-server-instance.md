# Deleting an existing MetaDefender ICAP Server instance

View as Markdown Ask ChatGPT about this page Ask Claude about this page

The following guideline describes how to delete a MetaDefender ICAP Server instance from OPSWAT Central Management.

1. Go to the **MetaDefender ICAP Server** management page under **Inventory** in the sidebar.

2. Select the ICAP Server instance that you want to delete.

3. Click the **ACTION** drop-down menu and choose the **Delete** option.

Info

After PIN verification, the management page will reload if the result is successful.
