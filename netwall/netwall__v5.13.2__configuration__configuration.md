In this page you will learn how to configure several aspects of NetWall.

You will learn:

- [MODBUS Connector](/docs/netwall/v5.13.2/configuration/modbus-connector): How to configure MODBUS Connector
- [OPC UA Connector](/docs/netwall/v5.13.2/configuration/opc-ua-connector): How to configure OPC UA Connector

- [IEC 104 Connector](/docs/netwall/v5.13.2/netwall/v5.0.0/configuration/iec-104-connector): How to configure IEC 104 Connector
- [DNP3 Connector](/docs/netwall/v5.13.2/configuration/dnp3-connector): How to configure DNP3 Connector
- [AVEVA PI Connector](/docs/netwall/v5.13.2/configuration/osipi-connector): How to configure OSIPI Connector
- [MQTT Connector](/docs/netwall/v5.13.2/configuration/mqtt-connector): How to configure MQTT Connector
- [Syslog Stream](/docs/netwall/v5.13.2/configuration/syslog-stream): How to configure Syslog streams from RED to BLUE
- [Software Update](/docs/netwall/v5.13.2/configuration/software-update): How to update NetWall
- [Port Scan Detect](/docs/netwall/v5.13.2/configuration/port-scan-detect): How to configure Port Scan Detect feature to avoid brute force attacks and port scan
- [Backups](/docs/netwall/v5.13.2/configuration/backups): How to take snapshots of NetWall configuration and restore them if needed
- [System Log](/docs/netwall/v5.13.2/configuration/system-log): How Syslog feature works
- [Advanced menu](/docs/netwall/v5.13.2/configuration/advanced-menu): How to configure advanced settings
- [User Accounts](/docs/netwall/v5.13.2/configuration/user-accounts): How to create new management Accounts
- [ICCP Connector](/docs/netwall/v5.13.2/configuration/iccp-connector): How to configure ICCP Connector
- [FTP Server](/docs/netwall/v5.13.2/configuration/ftp-server): How to configure FTP Server Connector
- [SPAN Connector](/docs/netwall/v5.13.2/configuration/span-connector): How to configure SPAN Connector
