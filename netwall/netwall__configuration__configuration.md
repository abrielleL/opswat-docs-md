# Configuration

In this page you will learn how to configure several aspects of NetWall.

You will learn:

- [Initial Configuration](/configuration/initial-configuration): How to configure your management IP, DNS and NTP servers
- [Security Dongles](/configuration/dongles): How the dongles work and how you can register them
- [File Transfer](/configuration/file-transfer): How to configure FTP, SFTP and Windows File Share to transfer files from BLUE to RED
- [Managed File Transfer and Kiosk](/configuration/vault-stream): How to configure a specific HTTP stream to work with Vault
- [MODBUS Connector](/configuration/modbus-connector): How to configure MODBUS Connector
- [OPC UA Connector](/configuration/opc-ua-connector): How to configure OPC UA Connector
- [SMTP Connector](/configuration/smtp-connector): How to configure SMTP mail replication
- [IEC 104 Connector](/netwall/v5.0.0/configuration/iec-104-connector): How to configure IEC 104 Connector
- [DNP3 Connector](/configuration/dnp3-connector): How to configure DNP3 Connector
- [AVEVA PI Connector](/configuration/osipi-connector): How to configure OSIPI Connector
- [MQTT Connector](/configuration/mqtt-connector): How to configure MQTT Connector
- [Software Update](/configuration/software-update): How to update NetWall
- [Streams (TCP, UDP, Syslog, HTTP)](/configuration/t): How to Configure Streams
- [Port Scan Detect](/configuration/port-scan-detect): How to configure Port Scan Detect feature to avoid brute force attacks and port scan
- [Backups](/configuration/backups): How to take snapshots of NetWall configuration and restore them if needed
- [System Log](/configuration/system-log): How Syslog feature works
- [Advanced menu](/configuration/advanced-menu): How to configure advanced settings
- [User Accounts](/configuration/user-accounts): How to create new management Accounts
- [ICCP Connector](/configuration/iccp-connector): How to configure ICCP Connector
- [FTP Server](/configuration/ftp-server): How to configure FTP Server Connector
- [SPAN Connector](/configuration/span-connector): How to configure SPAN Connector
