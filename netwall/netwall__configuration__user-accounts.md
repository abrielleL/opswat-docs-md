# User Accounts

User Accounts must be set up prior to accessing the MetaDefender Security Gateway Management UI on both the RED and BLUE sides (User Accounts must be set up independently on the BLUE and RED sides).

Create and manage new users in BLUE and RED from the User Account menu

### [Add User Account](/docs/netwall/configuration/user-accounts#add-user-account)

To add a new user:

1. Go to Configuration-> User Accounts
2. Deploy Action button and select Add User Account
3. Fill in the fields and click on Submit button to save the changes

### [Remove User Account](/docs/netwall/configuration/user-accounts#remove-user-account)

To remove a user:

1. Go to Configuration-> User Accounts
2. Select the user you want to remove from the table
3. Deploy the Action button and select Delete
4. A pop up will be displayed to confirm the deletion, click Submit to confirm
