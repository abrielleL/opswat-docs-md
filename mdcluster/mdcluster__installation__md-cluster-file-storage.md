# MD Cluster File Storage

### [Supported Operating Systems](/docs/mdcluster/installation/md-cluster-file-storage#supported-operating-systems)

| OS | Version |
| --- | --- |
| Windows | Windows 11 23H2+, or Windows Server 2019+. |
| Linux | Ubuntu 22.04+, Ubuntu 24.04+, Debian 12+, Rocky 9+, or RHEL 9+. |

Info

You can use **OpenSSL** or a similar tool (such as **ssh-keygen**) to generate an **X.509 public and private key pair**.
