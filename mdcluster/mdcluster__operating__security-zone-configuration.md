# Security zone configuration

The Security zone page is found under `Workflow Management` > `Security Zones` after successful login.

The following actions are available:

- New zones can be added
- Existing zones can be viewed
- Existing zones can be modified
- Existing zones can be deleted

Each zone contains a name, description and multiple network masks. Both IPv4 and IPv6 network zones are supported [Workflow Configuration Template](https://www.opswat.com/docs/mdcore/configuration/workflow-configuration-template).
