# Redis

Requires Redis version 7.2 or later.

The instructions below are based entirely on the [Redis documentation](https://redis.io/docs/latest/operate/oss_and_stack/install/archive/install-redis/) or [Memurai documentation](https://www.memurai.com/).

### [Supported Operating Systems](/docs/mdcluster/installation/md-cluster-redis#supported-operating-systems)

| Server | OS | Version |
| --- | --- | --- |
| Memurai | Windows | Windows 11 23H2+, or Windows Server 2019+. |
| Redis | Windows | WLS - Ubuntu 24.04 (not recommended) |
| Redis | Linux | Ubuntu 22.04+, Ubuntu 24.04+, Debian 12+, Rocky 9+, or RHEL 9+. |
