# PostgreSQL

Requires PostgreSQL version 16.9 or later.

Info

The instructions below are based entirely on the [PostgreSQL document](https://www.postgresql.org/download/). The following installation guidelines describe how to install PostgreSQL 16.10.

### [Supported Operating Systems](/docs/mdcluster/installation/md-cluster-postgresql#supported-operating-systems)

| OS | Version |
| --- | --- |
| Windows | Windows 11 23H2+, or Windows Server 2019+. |
| Linux | Ubuntu 22.04+, Ubuntu 24.04+, Debian 12+, Rocky 9+, or RHEL 9+. |
