# RabbitMQ

Requires RabbitMQ version 4.2 or later.

RabbitMQ functions effectively only with specific supported versions of Erlang. Please refer to [the link](https://www.rabbitmq.com/docs/which-erlang#compatibility-matrix) for the Erlang-RabbitMQ compatibility matrix.

The instructions below are based entirely on the [RabbitMQ documentation](https://www.rabbitmq.com/docs/download). The following installation guidelines describe how to install RabbitMQ 4.2.5 with Erlang/OTP 27.3.4.9

### [Supported Operating Systems](/docs/mdcluster/installation/md-cluster-rabbitmq#supported-operating-systems)

| OS | Version |
| --- | --- |
| Windows | Windows 11 23H2+, or Windows Server 2019+. |
| Linux | Ubuntu 22.04+, Ubuntu 24.04+, Debian 12+, Debian 13+, Rocky 9+, or RHEL 9+. |
