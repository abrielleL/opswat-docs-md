# How to setup the Multi-scanning server on MetaDefender IT-OT Access ?

## On the MetaDefender IT-OT Access

> **Setup MetaDefender Cloud**
>
> The MetaDefender Cloud server is added by default for each account on the MetaDefender IT-OT Access. However, you need to upgrade the account before using it.

#### Setup MetaDefender Core

- Go to Settings -> Global -> MetaDefender Integration
- Click **Add Server** button, as illustrated in the screenshot below.

![](https://uploads.developerhub.io/prod/2x2P/1myx89wmfyy6op35t2etwenmh8au7bbweypdyqdjvxjmjj0t7yfhhi17hrypuuoa.png)

- Enter the multi-scanning server information to the popup, as illustrated in the screenshot below.

![](https://uploads.developerhub.io/prod/2x2P/8ek0xlmsazvb3k6owg3qtgy3re8qn2npidahukg4px3tx1bl3iwliidim7igkvxu.png)

- Then, you can click on the **Test connection** button to verify the server connection before clicking on **Add** button to finish the setup.
