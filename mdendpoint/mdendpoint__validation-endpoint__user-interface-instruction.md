# User Interface Instruction

Click on the “MetaDefender Endpoint Standalone” tray icon to open the UI window as shown below:

**Step 1:** Selection the command from list

![](https://uploads.developerhub.io/prod/2x2P/ysuuunvrqp1bupw71w382oz4gwqs8bhhqospfk2cyjkjtkr66bgnouej2m62ibiy.png)

(1): Device ID: ID of client’s device.

(2): Select command need to be executed.

**Step 2:** Execute command (MDE allows the input of parameters if needed.)

![](https://uploads.developerhub.io/prod/2x2P/hkwayjng4k8poe3bdmi4m28x7kayvvhaw3u3o00qlfwmvolywbvjcncfcyh5u501.png)

(4): Input the parameter if needed to execute the chosen command. Note that some commands require this input while others do not, so this input box may not appear every time.

(5): Displays all device information (this information is necessary to execute commands related to allowing a device).

(6): Click 'Next' to generate the challenge code needed for admin approval.

**Step 3:** Generate the challenge code

![](https://uploads.developerhub.io/prod/2x2P/qutfez9r3bp8hlds3c9dypwc5icb1ztjwgfodymtmg7fe0bsolyvjsnguwggzea8.png)

(7): Command information

(8): Challenge code generated by MDE

**Step 4:** Bring the challenge code to the administrator and get the response

- The administrator will review the request and determine whether the client is authorized to execute the command. If approved, the admin will provide the client with the response code needed to execute the requested command. The process by which the admin views and approves these requests is detailed in the section for the administrator console instruction.

**Step 5:** Input the response from admin and execute

![](https://uploads.developerhub.io/prod/2x2P/2l2f5ef3kb1s646b0y1v7t9q9kjx8blkor3xum4xwmf2sbb9l71x46qp5xrd46b7.png)

### **Note**

Some commands require peripheral information for execution, such as a device's Product ID, instance path, or vendor name. This pop-up is used for these use cases.

![](https://uploads.developerhub.io/prod/2x2P/k6vktlutjs3c5n5r0n9sj8w90ycz21xn7waul6fdlwom7l3y1m6to29d2moxemws.png)

(7): Rescan list devices information

(8): Copy device information, to use it as parameter in the screen above
