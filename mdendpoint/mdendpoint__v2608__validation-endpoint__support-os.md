# System Requirements

## Minimum System Requirements

- **Processor:** 2 Cores / 2 Logical Processors
- **Memory:** 2 GB RAM

## Supported OS (Windows)

- Windows Embedded Standard 7 (32, 64 bit)
- Windows 7 (32, 64 bit)
- Windows 8.1
- Windows 10 (32, 64 bit)
- Windows 10 Enterprise LTSC
- Windows 10 IOT 64 bit
- Windows 11
- Windows Server 2008 R2, 2012, 2016, 2019, 2022

> **Additional requirements**
>
> The following Windows versions must have **KB3033929** and **KB3063858** installed:
>
> - Windows Embedded Standard 7 (32, 64 bit)
> - Windows 7 (32, 64 bit)
> - Windows Server 2008 R2

## Supported OS (Linux)

- Ubuntu 20.04
- Ubuntu 22.04
- Ubuntu 24.04
- Ubuntu 26.04
