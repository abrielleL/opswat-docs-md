# How to use the Secure OT Access feature?

## What’s this feature about?

Secure OT Access aims to provide secure remote access to OT environment with unmatched precision. Unlike traditional VPN solutions, Secure OT Access operates with granular access controls that enforce strict user permissions while minimizing the OT attack surface. This enables organizations to manage and safeguard their OT environments more efficiently, reducing the risk of unauthorized access and ensuring that only the right individuals, whether it’s remote employees or third-party vendors, have access to the right resources. With Secure OT Access, users can benefit from a safer, more secure pathway to manage their critical systems while maintaining optimal operational integrity.

## How to use this feature?

**Step 1:** Navigate to the Secure OT Access feature on MetaDefender Endpoint.

![](https://uploads.developerhub.io/prod/2x2P/iw0hie8d01sci75b36x4pe330dl4dszuqv9zoe3acjfdsgpi3s32k3fwmqy2e8i0.png)

**Step 2:** Input details such as username, password and service address. These details will be provided by the administrators. If 2FA is enabled, the software will send 2FA authorization to a cell phone number or email for the Remote User account.

![](https://uploads.developerhub.io/prod/2x2P/uy2xxb5t57c3gx5qr3fjev0gps854sybpysdbned6o2g5lvk0lz8r8qrc27zqioo.png)

The Service Address, followed by Port 443, connects the Remote User's machine to the Management Console. Type the Service IP configured on the Console UI. Refer to the [Management Console Guide](https://www.opswat.com/docs/metadefender-ot-access/management-console-guide) for more information.

The Service Address box remains populated with the value you entered, even if you log out of MetaDefender Endpoint. You can change the address if you wish.

**Step 3:** Click Connect. Then, the available services will be displayed. For Remote Desktop Protocol (RDP), double-click on a service to initiate it.

![](https://uploads.developerhub.io/prod/2x2P/j1tc8h8q6du4ilxbiu0cygh7zt3y8h6fnustzgu4hnro7qbpjjiwuhv54hwvuwlq.png)

**Step 4:** Enter your username and password for this service.

![](https://uploads.developerhub.io/prod/2x2P/4duva4fll6u6j1kbwo28dek5kugunii7ziromf821gj4do6wvfs2xtsj3g4rp13k.png)

**Step 5:** After you click OK, the remote session will initiate.

![](https://uploads.developerhub.io/prod/2x2P/cz9hhslkk24r77wq73xc6txaywtb9v04abcfz2k62ezpp8qdfhzqzw140838f2ul.png)

**Step 6:** The Remote User account is connected to the remote machine through the RDP_Demo service.

![](https://uploads.developerhub.io/prod/2x2P/5zfj5pfgy4czzg63hpbh1z7019h9dk4q4yldv85ntvuiwbj48otf02ifdqc4k14t.png)

**Step 7:** When you complete your task, close the Remote Desktop Connection window.

![](https://uploads.developerhub.io/prod/2x2P/n7jbvgrbo359zut1ohcm3bt33ih0sudslynjzxb6roa76tol2wmq1qstotax458g.png)
