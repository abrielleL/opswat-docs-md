# MetaDefender Endpoint Release Notes

| Version | 2611 |
| ---- | ---- |
| **Release date** | November 4, 2026 |
| **Scope/Release Summary** | This release introduces enhanced security and endpoint management capabilities across Windows, macOS & Linux. Key highlights include: AI-Powered Malware Scan Threat Intelligence, Enhanced Application Control, Real-time Endpoint Performance Monitoring, Enhanced Application Control & Flexible Compliance Management |

### MetaDefender Endpoint - Windows Persistent (7.6.2611.1342)

**Release date:** November 4, 2026

New Features

- Introduces AI-powered Malware Scan threat intelligence with actionable insights for faster risk assessment and response
- Users can request admin-approved temporary bypasses in Peripheral Media Protection and Download Protection
- Admins can configure application allowlists in Application Control
- Extends Deep Compliance and SDP support to ARM64 devices
- Admins can grant time-bound compliance exemptions to specific devices or groups for temporary access 

Enhancements

- Adds a Security Score data table to the Endpoint Security dashboard for improved monitoring and visibility MetaDefender Endpoint - MacOS (10.4.2610.304)

> **NOTE**
>
> Starting with this release (version 7.6.2611.1342), the MetaDefender Endpoint Windows installer package size has increased to over 1 GB. As a result, these packages can no longer be uploaded to My OPSWAT Central Management On-Premises versions earlier than 2609.
>
> We recommend upgrading to My OPSWAT Central Management On-Premises version 2609 or later to ensure compatibility.

### MetaDefender Endpoint - MacOS Persistent (10.4.2611.332)

**Release date:** November 4, 2026

- Admins can configure application allowlists in Application Control
