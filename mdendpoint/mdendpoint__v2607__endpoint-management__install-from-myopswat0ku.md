# Installed from OPSWAT Central Management

## Downloading MetaDefender Endpoint (MD Endpoint) package

1. Log into your **MyOPSWAT** portal.
2. Go to **Home** -> **MetaDefender Endpoint** and click the **Download** button, as illustrated in the screenshot below.
3. Click the **MetaDefender Endpoint** tab, as illustrated in the screenshot below.

![](https://uploads.developerhub.io/prod/2x2P/40kvqgubvyzrolnpq5onkfbiiw6una702ba4cwm86dd1naejekhya0q70jcqfy3v.png)

![](https://uploads.developerhub.io/prod/2x2P/o0rf2sgcyfx81fqtdqxo8uzcvmiscbcn9hko045v7ljfq9xeqp6onsjeop0ju5ok.png)

4. Choose the platform which you want to install the MD Endpoint
   - You need to download two files before uploading to the server.
   - Persistent:
     - Persistent Agent [<platform>]
     - Persistent Agent Descriptor [<platform>]
   - On-Demand:
     - On-Demand Agent [<platform>]
     - On-Demand Agent Descriptor [<platform>]

## Upload the MetaDefender Endpoint to the OPSWAT Central Management v7

Refer to the link: [OPSWAT Client, OESIS, and the vulnerability database - Central Management](https://docs.opswat.com/ocm/configuration/update-client-oesis-vul#manual)
