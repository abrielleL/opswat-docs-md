# Which MetaDefender Endpoint supports TLS1.2?

> **Check Your Product:**
>
> This article applies to all MetaDefender Endpoint releases deployed on Windows, macOS, Linux and Android systems.

OPSWAT is dedicated to ensuring that its products stay up to date with the latest technology, privacy protocols, and data security best practices. This includes offering full support for TLS 1.2 throughout the range of MetaDefender Endpoint products.

> **Pro Tip:**
>
> Transport Layer Security 1.2 is an advanced cryptographic protocol that relies on a combination of symmetric and asymmetric cryptography to protect data from cybercriminals, hackers and eavesdroppers as it moves through the internet.
>
> TLS 1.2 features include:
>
> - single hash verification
> - TLS extensions
> - AES cipher suites
> - increased authentication encryption
> - allows both clients and servers to designate hash and signature algorithms.
