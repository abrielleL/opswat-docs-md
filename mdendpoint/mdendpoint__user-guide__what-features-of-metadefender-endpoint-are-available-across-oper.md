# What features of MetaDefender Endpoint are available across operating systems?

> **Check your product:**
>
> This article applies to all MetaDefender Endpoint releases deployed on Windows, macOS, and Linux

This document provides an overview of the MetaDefender Endpoint feature availability matrix across different platforms (Windows, Windows ARM64, MacOS and Linux), outlining which features are supported on each platform.

It serves as a reference to help readers easily compare feature availability and identify platform-specific capabilities and differences.

# Feature matrix

| Features | Windows | Windows ARM64 | MacOS | Linux | Notes |
| ---- | ---- | ---- | ---- | ---- | ---- |
| **Peripheral Media Protection & Device Control** |
| Peripheral Media Protection | Yes | Yes | Yes | No | Scanning peripheral and removable media file contents |
| Peripheral Device Control | Yes | No | No | No |  |
| BadUSB Protection | Yes | No | No | No |  |
| **Endpoint Management & Security** |
| Deep Compliance | Yes | Yes | Yes (User Interface currently unavailable) | Yes | Device compliance checks |
| Vulnerability Detection | Yes | No | Yes | Yes |  |
| OS Updates | Yes | No | Yes | No |  |
| Application Patches  | Yes | No | Yes | No | Automatic patching for 3rd party applications |
| BIOS & Driver Updates | Yes (**Dell **and **Lenovo Windows devices **only) | No | No | No |  |
| Security Score | Yes | No | Yes | No | Calculate risk posture based on security controls |
| Endpoint Health Performance Monitoring | Yes | Yes | Yes | Yes | Real-time endpoint performance including CPU, memory, disk, and network usage |
| Application Control  | Yes | No | Yes | No | Application allowlist & manage unwanted apps |
| Application Remover | Yes | No | Yes | Yes |  |
| Malware Scan | Yes | No | Yes | No |  |
| **Download Protection** | Yes | No | No | No |  |
| **Managed File Transfer** | Yes | No | Yes | No |  |
| **SDP/VPN** | Yes | Yes | Yes | Yes |  |
| **Secure OT Access** | Yes | No | No | No |  |
