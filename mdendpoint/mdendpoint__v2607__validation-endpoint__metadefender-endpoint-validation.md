# MetaDefender Endpoint Validation

**MetaDefender Endpoint Validation** is a software installed on endpoints to validate data from removable media scanned and sanitized with enforced policies from the MetaDefender Kiosk. Adding extra security layer to entry points of critical infrastructure sectors, safeguarding OT assets and secured networks by detecting unauthorized media files.

**MetaDefender Endpoint Validation** is positioned as Scan Enforcement Technology within Peripheral and Removable Media Protection solutions. This solution supports organizations in defending SCADA/HMIs/Engineering Workstations against significant threats from removable media and transient cyber assets.
