# MetaDefender Endpoint Release Notes

---

| Version | 2607 |
| ---- | ---- |
| **Release date** | July 22, 2026 |
| **Scope/Release Summary** | This release introduces enhanced security and endpoint management capabilities across Windows, macOS and Linux platforms. ### MetaDefender Endpoint - Windows Persistent (7.6.2607.1075)

**Release date:** August 05, 2026

New Features

- Detect and block malicious peripheral devices by identifying automated malicious behaviors, such as keystroke injection, to prevent BadUSB and other peripheral device-based attacks.
- Introduced a new threat scanning and detection user interface in Peripheral Device Control that prompts users with real-time progress and warnings for device-borne and file content-based threats.

Enhancements

- Administrators can configure to allow folders and individual file paths for specific machines, providing device-level exclusions for Malware Scan.
- Enhanced the anti-malware scanning engines pop-up with a complete engine list and a new column showing administrator-selected engines used to evaluate file scanning results.

### MetaDefender Endpoint - Linux

**Deb: 15.4.2607.193 | SDK: 4.3.5255.0**

**Release date:** August 05, 2026

New Features

- Malware Scan feature is now available on Linux devices, protecting critical endpoints with Predictive Alin AI, Metascan Multiscanning, Deep CDR, Proactive DLP, and Country of Origin technologies

> **NOTE**
>
> Malware Scan feature is currently only available for Debian-based Linux devices

### MetaDefender Endpoint - Windows Persistent (7.6.2607.1064)

**Release date:** July 22, 2026

New Features

- Admins can configure to allow users to skip individual file scans or device blocks for immediate access in Peripheral Media Protection
- Automatic scan server failover for uninterrupted threat detection in Peripheral Media Protection

Enhancements

- Custom configuration to automatically display the remediation page
- Notify administrators on the management console of the specific KB that needs updating and how many days it is overdue
