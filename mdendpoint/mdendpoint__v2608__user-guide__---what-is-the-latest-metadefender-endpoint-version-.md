#  What is the latest MetaDefender Endpoint version?

> **Check Your Version:**
>
> This article applies to all MetaDefender Endpoint releases deployed on Windows, MacOS and Linux systems.

Browse MetaDefender Endpoint [Release Notes](https://www.opswat.com/docs/mdendpoint/release-notes/metadefender-endpoint-release-notes) for details on the latest version, version history, version comparisons and release notes.

Alternatively, go directly through the [My OPSWAT](https://my.opswat.com/portal) for a list of available downloads.:

1. Login to My OPSWAT portal
2. Click on “MetaDefender Endpoint”

![](https://uploads.developerhub.io/prod/2x2P/vuoqe0ufwzpf29fpgpxd2r8jftrw2mmxbpgsn9ida81sc6xmma93qzsthtj4nndg.png)

3. Click on “Download” button

![](https://uploads.developerhub.io/prod/2x2P/gllvynxlp3s5pzp9wptl5451s8jjkavwmcjommcpgfntposih7krz2ifo6pimq00.png)

4. In the new window opened, always the version from the top is the latest version

![](https://uploads.developerhub.io/prod/2x2P/i55qlznm6mr0y6c2hniy3bq2tp8npyofdm62iyqxkkj2q7l9fp9ksfou61tvicv7.png)

> **Pro Tip:**
>
> OPSWAT highly recommends that users upgrade to the latest version of MetaDefender Endpoint. Current versions incorporate state-of-the-art features and necessary bug fixes, and are freely available for all license holders to download.

> **Support:**
>
> Feel free to contact OPSWAT support for further guidance through your Upgrade process. Please follow these instructions on [How To Create a Support Package](https://docs.opswat.com/mdcore/troubleshooting/how-to-create-support-package-), before logging a [Support Ticket](https://www.opswat.com/support) with the OPSWAT team.
