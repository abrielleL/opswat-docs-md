# How to deploy MetaDefender Endpoint Agent on macOS using Intune without a .pkg installer?

> **Check Your Version:**
>
> This article is applied to MetaDefender Endpoint Agent releases deployed on MacOS systems through Intune.

**Issue:** There is no .pkg installer available for MetaDefender Endpoint Agent on macOS.

**Affected Platforms:** macOS

**Workaround:** As Intune has support for .dmg installer deployment, we can use the .dmg installer with Intune for deployment on MacOS.

**Resolution:**

To deploy the .dmg file through Intune, follow the Microsoft Learn guide: [Add a macOS DMG app to Microsoft Intune](https://learn.microsoft.com/en-us/intune/intune-service/apps/lob-apps-macos-dmg).
