# Operating System Updates

## Overview

MetaDefender Endpoint can automatically update an OS to the latest version when available. Through the user interface of MetaDefender Endpoint, users can gain insights on the CVEs that would be resolved when applying a specific missing patch detected on the system.

## For administrators

For administrators' user guide, please refer to the following documents and resources for more details on configuration, policy set up, and monitoring using the management console in My OPSWAT Central Management

- [On-Demand Deployment (OS)](https://www.opswat.com/docs/cm/patch-management/on-demand-deployment): Execute specific patches immediately on targeted endpoints for urgent fixes or critical vulnerabilities.
- [Patch Management Policy (OS)](https://www.opswat.com/docs/cm/patch-management/patch-management-policy): Set policy-based automated deployments to maintain endpoint updates with minimal manual work.
- [Deployment Management (OS)](https://www.opswat.com/docs/cm/patch-management/deployment-management): A monitoring hub to track real-time progress, success rates, and logs for active and historical deployment.
- [Missing Patch Management](https://www.opswat.com/docs/cm/patch-management/missing-patches-management): An automated system that monitors missing patches and vulnerabilities across all managed endpoints.
- [Patch Dashboard (OS)](https://www.opswat.com/docs/cm/patch-management/patch-dashboard): A centralized dashboard providing full visibility into patches, vulnerabilities, deployment outcomes, and so much more.
- [Patch Reports & Notifications (OS)](https://www.opswat.com/docs/cm/patch-management/patch-reports---notifications): Provide timely reporting and automated alerts across patching operations.
