# How do I solve User Authentication issues on MetaDefender Endpoint/MetaDefender IT-OT Access devices?

> **Check Your Product:**
>
> This article applies to the current MetaDefender IT-OT Access Console and API, and all MetaDefender Endpoint releases deployed on Windows, macOS and Linux systems.

Users running MetaDefender Endpoint on one or more Windows, macOS or Linux devices may occasionally see MetaDefender IT-OT Access device compliance warnings/flags related to **User Authentication**.

These warnings/flags are triggered by device issues and will appear under **MetaDefender IT-OT Access** **Console>Inventory>Devices>Relevant Device>Detailed Device Information>Deep Compliance>User Authentication**.

For detailed remediation instructions on user authentication-related device compliance issues, please select the relevant operating system from the list below.

- [Windows: User Authentication](https://docs.opswat.com/macloud-sdp/kb/how-do-i-solve-user-authentication-issues-on-win)
- [macOS: User Authentication](https://docs.opswat.com/macloud-sdp/kb/how-do-i-solve-user-authentication-issues-on-macos)
- [Linux: User Authentication](https://docs.opswat.com/macloud-sdp/kb/how-do-i-solve-user-authentication-issues-on-linux)
