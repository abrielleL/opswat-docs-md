# Third-Party Application Patching

## Overview

MetaDefender Endpoint offers automatic patching across 425+ third-party applications, keeping your systems secure and up to date. Through the user interface, users can view the list of applications with details such as current version, latest known update version, and action needed for easy review and monitoring.

![](https://uploads.developerhub.io/prod/2x2P/tqxbt0u6qphcxx5wk43yypqnbfnga2hjwr8qw07zspfzrkjto5waf61wyv1i8fqr.jpg)

For unavailable applications in the Application Patches section, users can send requests through the **Request Support** button with a built-in form for application patch support requests.

![](https://uploads.developerhub.io/prod/2x2P/zuf87dz48tkryeo0xi02q04xu845l26bss3o8qqzvoxca7fvofj37w6dqclaxwdt.png)

## For administrators

For administrators user guide, please refer to the following documents and resources for more details on configuration, policy set up, and monitoring using the management console in My OPSWAT Central Management

- [Third-Party Application Patch Management](https://www.opswat.com/docs/cm/patch-management/third-party-application-management): Track and manage third-party applications across all endpoints, with visibility into installed versions, available updates, and associated vulnerabilities.
- [On-Demand Deployment (Application)](https://www.opswat.com/docs/cm/patch-management/on-demand-deployment--application-): Push critical application updates immediately to targeted endpoints.
- [Patch Policy (Application)](https://www.opswat.com/docs/cm/patch-management/patch-policy-application): Automate recurring policies to keep software current across your organization with minimal manual effort.
- [Deployment Management (Application)](https://www.opswat.com/docs/cm/patch-management/deployment-management--application-): Monitor deployments with real-time progress tracking and detailed installation logs.
- [Patch Dashboard (Application)](https://www.opswat.com/docs/cm/patch-management/patch-dashboard--application-): Visualize application patching coverage, track installation success rates, all from a dedicated application updates view.
- [Patch Reports & Notifications (Application)](https://www.opswat.com/docs/cm/patch-management/application-patch-reports---notification): Receive email reports on deployment outcomes.
