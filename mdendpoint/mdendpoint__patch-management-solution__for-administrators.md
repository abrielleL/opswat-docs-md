# For Administrators

## **Patch workflow at a glance**

Workflow to manage, deploy, and monitor patch status across your environment using My OPSWAT Central Management

![](https://uploads.developerhub.io/prod/2x2P/y7oomnahtrs7hhtwzidx1rg3geda3zrp096fi5piyrsrr1wc35z2uqvf05rxsu6b.png)

| Steps | Details |
| ---- | ---- |
| **Step 1. Discover** | Use** **[Patch Dashboard](https://www.opswat.com/docs/cm/patch-management/patch-dashboard) to identify security gaps and prioritize remediation efforts across your environment |
| **Step 2. Prioritize** | Open [Patches](https://www.opswat.com/docs/cm/patch-management/manage-missing-patches)** **list to review missing OS patches and outdated third-party applications. Use filters to focus on critical or high-priority items as needed |
| **Step 3. Deploy** | Choose the patch deployment method: - Select any patches and deploy them immediately via [On-Demand Deployment](https://www.opswat.com/docs/cm/patch-management/on-demand-deployment) - Define a [Policy Deployment](https://www.opswat.com/docs/cm/patch-management/policy-deployment)** **that applies patches on a repeating schedule - Roll out patches in staged [Ring Deployment](https://www.opswat.com/docs/cm/patch-management/ring-deployment) to reduce risk |
| **Step 4. Monitor & Review** | Use [Jobs ](https://www.opswat.com/docs/cm/patch-management/monitor-deployment)to monitor active deployments and review results |
| **Step 5. Report & Notify** | - Measure patch compliance and remediation progress using [Custom Patch Reports](https://www.opswat.com/docs/cm/patch-management/custom-patch-reports) - Configure [Patch Notification](https://www.opswat.com/docs/cm/patch-management/patch-notification) to alert key patch events |

## **Resource Directory**

| Features | What you'll get |
| ---- | ---- |
| [Patch Dashboard](https://www.opswat.com/docs/cm/patch-management/patch-dashboard) | Get a single-pane view of your environment's patch posture |
| [Missing Patches](https://www.opswat.com/docs/cm/patch-management/manage-missing-patches) | Find and act on missing patches and outdated application across your environment |
| [Deploy Patches](https://www.opswat.com/docs/cm/patch-management/deploy-patches) | Roll out patches and application updates  |
| [Monitor Deployment](https://www.opswat.com/docs/cm/patch-management/monitor-deployment) | Track a specific deployment |
| [Custom Patch Reports](https://www.opswat.com/docs/cm/patch-management/custom-patch-reports) | Configure point-in-time patch reports  |
| [Patch Notification](https://www.opswat.com/docs/cm/patch-management/patch-notification) | Set real-time alerts for key patch events |
| [Patch SLA](https://www.opswat.com/docs/cm/patch-management/patch-sla) | Define SLA timeframes to maintain compliance visibility |
