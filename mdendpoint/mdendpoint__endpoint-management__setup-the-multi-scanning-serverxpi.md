# Setup the Multi-scanning server on OPSWAT Central Management v7

Go to Settings -> Global Settings -> MetaDefender Integration

![](https://uploads.developerhub.io/prod/2x2P/x000l2o8za1qnrgk2cnudg5de9ee1cw2vez7og7y4jgthipnoca05sq20kihbbrg.png)

#### Setup MetaDefender Cloud

- Enter API Key on the text box, then click **SAVE** button to apply the configuration, as illustrated in the screenshot below.

![](https://uploads.developerhub.io/prod/2x2P/mkr5md3gvcd1dkqvam2kew6j693du5ie37bwo0vr2ks56u6k6b9ydm0kkt6ytpjm.png)

#### Setup MetaDefender Core

- Click **Add Server** button, as illustrated in the screenshot below.

![](https://uploads.developerhub.io/prod/2x2P/4mhoq2mfvoi8x1yd9nmavcmyl5mrti3a2elwxqqska981vzw69xaxqb1rbee7z78.png)

- Enter the multi-scanning server information to the popup, as illustrated in the screenshot below.

![](https://uploads.developerhub.io/prod/2x2P/tgq54s97u1jojnif5eeqmzvpm0lbjk1wwjwxpdzw5r4f0x3sf3sapsf8tk5mdtqk.png)

- Then, you can click on the **TEST CONNECTION** button to verify the server connection before clicking on **ADD** button to finish the setup.
