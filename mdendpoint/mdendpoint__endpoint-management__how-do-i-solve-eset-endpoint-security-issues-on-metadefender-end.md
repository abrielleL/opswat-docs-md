# How do I solve ESET Endpoint Security issues on MetaDefender Endpoint/MetaDefender IT-OT Access devices?

> **Check Your Product:**
>
> This article applies to ESET Endpoint Security for Windows, the current MetaDefender IT-OT Access Console and API, and all MetaDefender Endpoint releases deployed on Windows systems.

The following article covers three common MetaDefender IT-OT Access device compliance warnings that users may encounter when running ESET Endpoint Security in conjunction with MetaDefender IT-OT Access/MetaDefender Endpoint.

These warnings/flags are triggered by device issues and will appear under **MetaDefender IT-OT Access** **Console>Inventory>Devices>Relevant Device>Detailed Device Information>Deep Compliance>Anti-Malware**.

Please follow the relevant instructions below.

## MetaDefender IT-OT Access Compliance Warning: ESET Endpoint Security - No Successful Scan Recently

1. Launch **ESET Endpoint Security** for Windows.

![](https://uploads.developerhub.io/prod/2x2P/arovm4e104dzrlr41bnpmrtk7qd9odujnplo5tgb1e03oyqyou7fs5dpv9cmov41.png)

2. Click **Computer scan** in the left-hand navigation bar.
3. On the **Computer scan** page, click on **Custom scan**.

![](https://uploads.developerhub.io/prod/2x2P/l6g9xrj1gv30u7tz9w77vd5nnliov1en2fme4uyl80lzgeef4cu59hojaprk7607.png)

4. From the **Custom scan** pop-up window, select **Local drives**, then click the **Scan** button, as illustrated below.

![](https://uploads.developerhub.io/prod/2x2P/f76m0j5grvrrzbnw9hfaasl6pg28anbt5nwgpxfrvuymevs4j56402kds06f100i.png)

5. Open the Windows **Start** menu, then search for **MetaDefender Endpoint** (or **MetaDefender IT-OT Access**) and select **Run as administrator**.

![](https://uploads.developerhub.io/prod/2x2P/a6q0wj0yos41s7emmqibx8zan6xz3xsf5wb7jban5yye6g0d5vkc92gyo6r8x8ec.png)

6. Once the app is running, right-click on the MetaDefender Endpoint tray icon and, from the pop-up menu, click **Recheck**.

> **Please note:**
>
> This will trigger the MetaDefender Endpoint to scan all device compliance data and report to the MetaDefender IT-OT Access servers again.

![](https://uploads.developerhub.io/prod/2x2P/ku98b7do2c999nxerzineocbvb87rb16a841zemoqz2jbvxwgtvxvs7r6bzkzaje.png)

## MetaDefender IT-OT AccessCompliance Warning: ESET Endpoint Security - Realtime Protection Disabled

3. On the **Setup** page, click **Real-time file system protection** to enable it.

![](https://uploads.developerhub.io/prod/2x2P/4jk5817cxbot44xrqa8qxffe24dij0707lqm56o5ir4ntyj0b3abj1ahcpusb82x.png)

4. Open the Windows **Start** menu, then search for **MetaDefender Endpoint** (or **MetaDefender IT-OT Access**) and select **Run as administrator**.

![](https://uploads.developerhub.io/prod/2x2P/ccxh6u7pvw1gml5v9bu9h52m6x92gzp768f6bkf2i1wbgvurar02pwxoa1107bd0.png)

5. Once the app is running, right-click on the MetaDefender Endpoint tray icon and, from the pop-up menu, click **Recheck**.

> **Please note:**
>
> This will trigger the MetaDefender Endpoint to scan all device compliance data and report to the MetaDefender IT-OT Access servers again.

![](https://uploads.developerhub.io/prod/2x2P/oy8bz0z43n0g9cxhymqbux3329vpabggup8mn0gsx1msyw539ikdyvmq4zw5g4w2.png)

## MetaDefender IT-OT Access Compliance Warning: ESET Endpoint Security - Virus Definition Out Of Date

3. On the **Update** page, click on **Update virus signature database**.

![](https://uploads.developerhub.io/prod/2x2P/463tlwia4kedbdsv6lm4ne7brbzxenzpjfgft30vf3f7g4yt9ftmom9yglo7u13g.png)

4. Open the Windows **Start** menu, then search for **MetaDefender Endpoint** (or **MetaDefender IT-OT Access** and select **Run as administrator**.
