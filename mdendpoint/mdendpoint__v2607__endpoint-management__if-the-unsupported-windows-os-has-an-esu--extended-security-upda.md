# If the unsupported Windows OS has an ESU (Extended Security Updates) license, will it still show as an unsupported OS in MetaDefender IT Access?

> **Check Your Product:**
>
> This article applies to all MetaDefender Endpoint releases deployed on Windows systems.

**Yes.** OPSWAT currently **does not detect ESU (Extended Security Updates) licensing on Windows platforms**. Even if the customer purchased ESU from Microsoft, the device will still show as **Unsupported OS (EOL)** inside Central Management.
