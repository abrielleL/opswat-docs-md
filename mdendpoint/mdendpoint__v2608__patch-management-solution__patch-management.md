# Patch Management

## Operating System (OS) Updates

MetaDefender Endpoint can automatically update an OS to the latest version when available. Through the user interface of MetaDefender Endpoint, users can gain insights on the CVEs that would be resolved when applying a specific missing patch detected on the system.

![](https://uploads.developerhub.io/prod/2x2P/ngsoun1wchb5q6xvlcr4rwc8ikxffwcvxspmp0a1jl0ysufeb1c6bg20khrag776.png)

## Third-Party Application Patching

MetaDefender Endpoint offers automatic patching across 425+ third-party applications. Through the user interface, users can view the list of applications with details such as current version, latest known update version, and action needed for easy review and monitoring.

![](https://uploads.developerhub.io/prod/2x2P/tqxbt0u6qphcxx5wk43yypqnbfnga2hjwr8qw07zspfzrkjto5waf61wyv1i8fqr.jpg)

> **Supported Platforms**
>
> The patching capability with MetaDefender Endpoint currently supports Windows & macOS. Support for Linux devices will be added in the future.

## Step-by-Step Patching Process

Leveraging **MetaDefender Endpoint** and **My OPSWAT Central Management**, users gain a single view of all missing patches across an environment among OS and third-party applications.

Continuously monitor all managed endpoints, identify missing patches, categorize them by severity and device compliance status, and deploy seamless patching with the OPSWAT Patch Management solution.

Here's an overview of how it works:

**Step 1:** MetaDefender Endpoint actively detects and reports missing patches to the management console.

![](https://uploads.developerhub.io/prod/2x2P/tqxbt0u6qphcxx5wk43yypqnbfnga2hjwr8qw07zspfzrkjto5waf61wyv1i8fqr.jpg)

**Step 2:** When a vulnerability is detected, it's instantly highlighted in the management console in My OPSWAT Central Management with severity level, CVE details, and affected asset information.

![](https://uploads.developerhub.io/prod/2x2P/rwc2q364e6dnu5m3cs91bga0zyvf9fuxxt72zh4kt063gwahrnfm7aaiifi4xz1r.png)

**Step 3:** Through My OPSWAT Central Management, admins instantly view severity level, associated CVEs, release date, category, and current patching status. Admins can search, filter, and sort by severity, KB, application name, category, or approval status.

Admins can also approve or reject patches; rejected patches are auto-excluded from all deployments

![](https://uploads.developerhub.io/prod/2x2P/79ybxugeg4xtwh4rqv1exi88zqs3rm12jsttonfijwmszl2wzmwb8i1l2n8jwqmf.png)

For more details on how to set up, configure, and monitor using My OPSWAT Central Management, please refer to these following user guides:

- [Missing Patch Management User Guide for OS](https://www.opswat.com/docs/cm/patch-management/missing-patches-management)
- [Missing Patch Management User Guide for Third-Party Applications](https://www.opswat.com/docs/cm/patch-management/third-party-application-management)

**Step 4:** Deploy patches

**Step 5:** Automatically deploy across managed endpoints

At the scheduled time, the platform automatically distributes verified patches across all targeted endpoints, no manual intervention is needed.

![](https://uploads.developerhub.io/prod/2x2P/567rkgzvlwidygy5kidh9ss8j3gk0je92x3i3h5i3tngjtp0wbghz1t47ilyewb6.png)

**Step 5:** Receive real-time notifications

Gain full awareness with installation result notifications delivered to end users on MetaDefender Endpoint.

![](https://uploads.developerhub.io/prod/2x2P/5qcy1j0674pl7zb71s65bus5m2rv0ltjhqhvjcg7optqybclhravr3zs0uot4i79.png)

**Step 6:** View Patching Status in the Management Console

Patching status is recorded in the management console in My OPSWAT Central Management for full visibility and auditability.

![](https://uploads.developerhub.io/prod/2x2P/79ybxugeg4xtwh4rqv1exi88zqs3rm12jsttonfijwmszl2wzmwb8i1l2n8jwqmf.png)
