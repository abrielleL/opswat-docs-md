# Auto Run

The Auto Run feature, introduced in v4.0.0, enables MetaDefender Drive to run scans automatically once all engines are initiated without user interaction. Only full scans can be run automatically. Quick and Custom scans must be run manually by the user.

To enable and configure the Auto Run settings:

1. Go to **Settings** → **Preferences** and click the **Edit** button under **Auto Run**.
2. From the **Scan Auto Run** settings window, you can:

   1. Enable auto runs by checking the **Enable** checkbox.
   2. Set the **Timeout before scanning starts**, in minutes. The auto scan won't start if this time value has passed and all engines weren't initiated.
3. Click the **Confirm** button and reboot your drive.
