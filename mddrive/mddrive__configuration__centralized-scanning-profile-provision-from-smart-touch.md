# Centralized Scanning Profile - Provisioning from Smart Touch

### [**Administrator Provisioning**](/docs/mddrive/configuration/centralized-scanning-profile-provision-from-smart-touch#administrator-provisioning)

#### [Enrollment and Lock MetaDefender Drive](/docs/mddrive/configuration/centralized-scanning-profile-provision-from-smart-touch#enrollment-and-lock-metadefender-drive)

To enroll MetaDefender Drive with Smart Touch to **Centralized Scanning Profile,** perform the following procedure under administrator

1. Go to **Settings tab**
2. Select **Centralized Scanning Profile**

3. Tap **Enroll Now**

4. Confirm the acknowledgement of **any running work will be interrupted**

5. Follow on-screen instructions

#### [Assign an Approver](/docs/mddrive/configuration/centralized-scanning-profile-provision-from-smart-touch#assign-an-approver)

1. Enter a name to identify the Approver's name with the built-in keyboard, then click Next

2. Using **Google Authenticator, Microsoft Authenticator** or **Okta Verify** 2-factor authentication applications (to generate a 6-digit OTP (one-time password) in the next steps)

3. Enter the 6-digit retrieved from 2-factor authenticator of your choice

4. Tap **Verify** then wait for the **Success!** message

Info

Codes are only valid for a short time, so if it takes too long to enter, you will see this red message. Just need to wait for new one and enter again.

#### [Unenrollment for MetaDefender Drive](/docs/mddrive/configuration/centralized-scanning-profile-provision-from-smart-touch#unenrollment-for-metadefender-drive)

After booting the MetaDefender Drive the administrators wish to unenroll from Centralized Scan Profile

1. Go to **Settings** tab
2. Notice that the status of **Centralized Scanning Profile** now is **Enrolled**

3. Tab **Enrolled** label then tap **Unenroll Profile**

4. Confirm that you want to **Unenroll**

5. Enter the OTP retrieve from the 2-Factor Authenticator then tap Verify

6. Smart Touch will verify the entered OTP and will unenroll the device if the provided OTP is correct
