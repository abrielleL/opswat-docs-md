# Updates and Support

## [New Release Notification](/docs/mddrive/getting-started/updates-and-support#new-release-notification)

When a new version of MetaDefender Drive Toolkit or a new MetaDefender Drive software image becomes available, a clickable yellow notification bar will be displayed, which directs you the **Updates** page.

Then, you can check for MetaDefender Drive Toolkit updates by at the **Advanced Options** → **Tool Version Management** page

You can also check for MetaDefender Drive software upgrades at the **Advanced Options** → **MD** **Drive Version Management** page

## [Support](https://www.opswat.com/docs/mddrive/maintenance/drive-toolkit#supports)

In case you face an issue that you can't resolve using the [troubleshooting](https://docs.opswat.com/mddrive/troubleshooting) page or one of your Drives is malfunctioning, you can contact OPSWAT's support team and attach a support package. A support package can be generated by going to **Advanced Options** → **Support**.

After selecting Drive, then clicking **Generate Support Package,** follow the on-screen instruction

Until you see the green status, click the folder icon to open the folder and locate the **SupportPackage.zip**

### [Drive Toolkit Logs](https://www.opswat.com/docs/mddrive/maintenance/drive-toolkit#drive-toolkit-logs)

In the *"****C:\ProgramData\MetaDefender\MetaDefenderDriveToolkit\Log****"* folder, you will find the *MetaDefenderDriveToolkit.log* file. This file includes debugging information. If you face any issues while creating or upgrading a MetaDefender Drive, please attach this log file with your support request.

Info

From the Toolkit version 3.8.3 and before, the log was located in the same folder where you start MetaDefenderDriveToolkit.exe:

`"..\MetaDefenderDriveToolkit\MetaDefenderDriveToolkit.log"`
