# Getting Started with MetaDefender Drive Smart Touch

MetaDefender Drive with Smart Touch features a mobile form factor to add more flexibility and connectivity to transient device scanning. Similar to other form factors, it ships as an out-of-the-box solution with the latest software and scanning engine versions installed.

Prerequisite

If your system's hardware is below the [recommended specifications](https://www.opswat.com/docs/mddrive/getting-started/system-requirements-and-compatibility), please expect slow processing and performance reduction

WPA3 Wi-Fi

This device currently supports WPA2 security and does not offer compatibility with the WPA3 standard.

Caution

If you insert MetaDefender Drive into the target device while this device is already booted, please DON'T format the Drive's partition if prompted by the operating system. Such formatting will erase MetaDefender Drive's software and prevent it from functioning.

Caution

The user should only use the provided cable or similar, and avoid using any converter to have the best compatibility and performance

## [First Use With MetaDefender DR](/docs/mddrive/v4.4.2a/getting-started/getting-started-with-metadefender-drive-smart-touch#first-use-with-metadefender-dr)

For first-time use, please follow these steps:

1. Power on MetaDefender Drive with Smart Touch
2. Unlock it using the default password: **123456 (**or **386135** for Smart Touch v1.6.0 and before**]**
3. The device will be ready when it shows the **Ready to Scan** message

4. You can expand the navigation bar by tapping the top left icon to show full icon names

## [Activation](/docs/mddrive/v4.4.2a/getting-started/getting-started-with-metadefender-drive-smart-touch#activation)

1. From anywhere, tap **Settings** (the Gear icon) on **Navigation** bar.
2. Tap **License Activation**

2. From this **License** screen, type in a valid license
3. Tap **Activate** button

5. Make sure you don't currently have any activity on the host computer. Tap **Proceed to Activate**

6. MetaDefender Drive with Smart Touch will validate the input license within 1 or 2 minutes

7. After all, the details of license will populate accordingly

## [Check for Updates](/docs/mddrive/v4.4.2a/getting-started/getting-started-with-metadefender-drive-smart-touch#check-for-updates)

Tip

Despite MetaDefender Drive shipping with the latest software version, it is always a good practice to check for updates before use.

1. From anywhere, tap **Settings** (the Gear icon) on **Navigation** bar.
2. Notice **the red dot** displays next to **System Updates** notifying about any updates available for Smart Touch

3. Wait for MetaDefender Drive with Smart Touch to check for available updates.

3. If new updates are found, a **red dot** will be displayed by the **System**, **MetaDefender Drive Image,** and **Engines** tabs

### [Perform System, Image, and Engine Updates](/docs/mddrive/v4.4.2a/getting-started/getting-started-with-metadefender-drive-smart-touch#perform-system-image-and-engine-updates)

The experience is almost the same for the three types of updates:

1. Select **System Update** screen, noticing that there are updates available, tap **System**, **MetaDefender Drive Image**, or **Engines**, then tap **Download** or **Install**, and wait for the new version of the application to be downloaded.

2. After the download is completed, a prompt will be displayed to confirm if you would like to proceed with the installation.

3. Monitor the Installation progress.

4. In case of system and image updates, MetaDefender Smart Touch will restart. After rebooting, go back the the **System Update** page to confirm that all updates are installed.

Info

During the update process, MetaDefender Drive will not be ready to perform a scan.

## [Change Screen Display Time-Out](/docs/mddrive/v4.4.2a/getting-started/getting-started-with-metadefender-drive-smart-touch#change-screen-display-time-out)

To change screen lock time-out:

1. Tap the Settings icon, then Screen Display button
2. Select the desired time-out value

## [Connect, Boot, and Run your First Scan](/docs/mddrive/v4.4.2a/getting-started/getting-started-with-metadefender-drive-smart-touch#connect-boot-and-run-your-first-scan)

To run your first scan:

1. Ensure the target device is powered off
2. Use the USB-C to USB-C cable to connect MetaDefender Drive with Smart Touch to a USB-C port on the powered-off device.
3. Run your first scan

Recommendation

It is recommended to connect the target device to a power source throughout the setup and scanning processes to avoid disruptions

To run your first scan, you will go through the same experience as the USB form factor of MetaDefender Drive. For more details, please follow the instructions on [this page](https://www.opswat.com/docs/mddrive/process)

## [Change Pass Code](/docs/mddrive/v4.4.2a/getting-started/getting-started-with-metadefender-drive-smart-touch#change-pass-code)

To change pass code

1. On MetaDefender Drive with Smart Touch, navigate to **Settings --> Change Passcode**
2. Enter current pass-code then tap Enter (please be noted that the default pass code is **123456** **(**or **386135** for Smart Touch v1.6.0 and before**]** if you have not changed it
3. Enter **New Passcode**, then **Confirm New Passcode**
