# MetaDefender Drive Toolkit v3.8.10

|  |  |
| --- | --- |
| **Released on** **Sep 29, 2026** | This release includes new features, improvements, bug fixes. |

**New Features**

- **Paired version update:** MetaDefender Drive and MetaDefender Drive Toolkit are now release together. User need latest Toolkit for latest MetaDefender Drive.
- **Import List of Skipping Hash from Toolkit:** Administrators now can provision the allowed/skipped files by importing in Drive Toolkit. Refer to [Skip by Hash](/docs/mddrive/getting-started/skip-by-hash-using-dtk) for details.
- Limit the elevated permission for required tasks only like Flashing, Image updating, Generating Support Package.

**Improvements and Bug Fixes**

- Drive Toolkit reports why a partition resize failed and retries the mount point rather than leaving the flash in an unusable state.
