# Preferences → System Policy

View as Markdown Ask ChatGPT about this page Ask Claude about this page

The System Policy setting allows administrator to enforce alignment with organizational software upgrade policies. This preference settings defines the allowed dates since last version update.

To enable this feature,

1. Go to **Settings** → **Preferences** → **System Policy**.
2. Check the Enable **Number of Days since Last Version Update [in Days]** checkbox.
3. Save the setting.
