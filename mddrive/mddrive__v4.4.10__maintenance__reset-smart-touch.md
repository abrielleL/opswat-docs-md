# Reset MetaDefender Drive Image with Smart Touch

View as Markdown Ask ChatGPT about this page Ask Claude about this page

When a MetaDefender Drive with Smart Touch has a corrupted or unusable image and needs to be restored without a full reflash. The **Reset MetaDefender Drive Image** option resets the drive from a previously saved recovery package.

### [Reset the image](/docs/mddrive/v4.4.10/maintenance/reset-smart-touch#reset-the-image)

1. Open **Settings**.
2. Locate **Reset MetaDefender Drive Image**, below **About**.
3. If no recovery package is saved, follow the on-screen guidance to run a **System Update** first.
4. If a saved package is available, review the version shown on the screen.
5. Click **Reset** to start the reset from the saved package.
6. If the drive is enrolled with Central Scanning Profile, enter the one-time password (OTP) when prompted to authenticate the reset. If the drive is not enrolled, enter the PIN instead.
7. Wait for the reset to complete. Do not power off the drive while the reset is running.
8. It will also apply the new engines if previously engines have been downloaded and will finish.
