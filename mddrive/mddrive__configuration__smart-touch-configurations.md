# Configure MetaDefender Drive with Smart Touch

This section covers the **Settings and Configuration** available for **MetaDefender Drive with Smart Touch**

## [Activation](/docs/mddrive/configuration/smart-touch-configurations#activation)

MetaDefender Drive Scan Mode will only available after activated

MetaDefender Drive with Smart Touch can also be activated with Toolkit

Please follow the steps in [Activate License](/docs/mddrive/getting-started/activate-license)

The follow steps will walk you through the process to **activate MetaDefender Drive with Smart Touch from within the Smart Touch**

1. From anywhere, tap **Settings** (the Gear icon) on **Navigation** bar.
2. Tap **License Activation**

3. From this License screen, type in a valid license
4. Tap **Activate** button

5. Make sure you don't currently have any activity on the host computer. Tap **Proceed to Activate**

6. MetaDefender Drive with Smart Touch will validate the input license within 1 or 2 minutes

7. After all, the details of license will populate accordingly

## [Check for Updates](/docs/mddrive/configuration/smart-touch-configurations#check-for-updates)

Tip

Despite MetaDefender Drive shipping with the latest software version, it is always a good practice to check for updates before use.

1. From anywhere, tap **Settings** (the Gear icon) on **Navigation** bar.
2. Notice **the red dot** displays next to **System Updates** notifying about any updates available for Smart Touch

3. Wait for MetaDefender Drive with Smart Touch to check for available updates.

4. If new updates are found, a red dot will be displayed by the System, MetaDefender Drive Image, and Engines tabs

## [Perform System, Image, and Engine Updates](/docs/mddrive/configuration/smart-touch-configurations#perform-system-image-and-engine-updates)

The experience is almost the same for the three types of updates:

1. Select **System Update** screen, noticing that there are updates available, tap **System**, **MetaDefender Drive Image**, or **Engines**, then tap **Download** or **Install**, and wait for the new version of the application to be downloaded.

2. After the download is completed, a prompt will be displayed to confirm if you would like to proceed with the installation.

3. Monitor the Installation progress.

4. In case of system and image updates, MetaDefender Smart Touch will restart. After rebooting, go back the the **System Update** page to confirm that all updates are installed.

Info

During the update process, MetaDefender Drive will not be ready to perform a scan.

## [Change Screen Display Time-Out](/docs/mddrive/configuration/smart-touch-configurations#change-screen-display-time-out)

To change screen lock time-out:

1. Tap the Settings icon, then Screen Display button
2. Select the desired time-out value

## [Change Date, Time and Time Zone](/docs/mddrive/configuration/smart-touch-configurations#change-date-time-and-time-zone)

To set Date Time for Smart Touch

1. On MetaDefender Drive with Smart Touch, navigate to **Settings → Date & Time**
2. There are two method to set Date and Time for Smart Touch

   1. Auto

      1. Switch **Set Automatically** to ON then tap **Sync Now**
      2. If Smart Touch is connecting to Internet, Date & Time will automatically be fetched and populated accordingly from Network Time Server
   2. Manual

      1. Switch **Set Automatically** to OFF
      2. Manually set Date, Time and Time Zone for the device
3. Press **Apply** to save

## [Change Pass Code](/docs/mddrive/configuration/smart-touch-configurations#change-pass-code)

To change pass code

1. On MetaDefender Drive with Smart Touch, navigate to **Settings → Change Passcode**
2. Enter current pass-code then tap Enter (please be noted that the default pass code is **123456** **(or 386135 for Smart Touch v1.6.0 and before]** if you have not changed it
3. Enter **New Passcode**, then **Confirm New Passcode**

## [Network configuration for Smart Touch](/docs/mddrive/configuration/smart-touch-configurations#network-configuration-for-smart-touch)

1. Tap **Network Settings**

2. Wait for the network modal loading

3. Tap **Refresh** to scan for available networks. Each network is listed with the security type detected for it, and is labelled as **in use** for the network currently connected, or **saved** for a network whose credentials are already stored on the device.
4. Tap the network you want to join, then enter its credentials: a **Password** for a WPA-Personal network, or a **Username** and a **Password** for a WPA/WPA2-Enterprise (PEAP/MSCHAPv2) network.
5. If the CA certificate is require, press **Import CA Certificate** then follow the on screen instructions

   1. Make sure you are not scanning a device, and not using Secure Files Storage, then go ahead to press **Import CA Certificate**
   2. Prepare the CA Certificate on a computer and connect Smart Touch to the computer to copy the certificate to "Configuration USB Device"
   3. After copying and if the certificate is valid, the imported certificate will show
   4. Enter Username and Password then tap **Connect**
