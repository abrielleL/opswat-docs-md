# Getting Started with MetaDefender Drive Smart Touch

MetaDefender Drive with Smart Touch features a mobile form factor to add more flexibility and connectivity to transient device scanning. Similar to other form factors, it ships as an out-of-the-box solution with the latest software and scanning engine versions installed.

Prerequisite

If your system's hardware is below the [recommended specifications](https://www.opswat.com/docs/mddrive/getting-started/system-requirements-and-compatibility), please expect slow processing and performance reduction

WPA3 Wi-Fi

This device currently supports WPA2 security and does not offer compatibility with the WPA3 standard.

WPA2 Enterprise

To connect the device with Enterprise Wi-Fi, please follow the document at [Network Configuration for Smart Touch.](https://www.opswat.com/docs/mddrive/configuration/smart-touch-configurations#network-configuration-for-smart-touch)

Caution

If you insert MetaDefender Drive into the target device while this device is already booted, please DON'T format the Drive's partition if prompted by the operating system. Such formatting will erase MetaDefender Drive's software and prevent it from functioning.

Caution

The user should only use the provided cable or similar, and avoid using any converter to have the best compatibility and performance

## [Getting Started](/docs/mddrive/v4.4.9/getting-started/getting-started-with-metadefender-drive-smart-touch#getting-started)

For first-time use, please follow these steps:

1. Power on MetaDefender Drive with Smart Touch
2. Unlock it using the default password: **123456 (**or **386135** for Smart Touch v1.6.0 and before**]**
3. The device will be ready when it shows the **Ready to Scan** message

4. You can expand the navigation bar by tapping the top left icon to show full icon names

## [Activate and Update Drive with Smart Touch using Drive Toolkit](/docs/mddrive/v4.4.9/getting-started/getting-started-with-metadefender-drive-smart-touch#activate-and-update-drive-with-smart-touch-using-drive-toolkit)

To Activate, Update or Enroll Drive with Smart Touch to Central Management or Central Scanning Profile, follow the instructions:

- Change Smart Touch to "Device Scanning"
- Plug Smart Touch to a PC with Drive Toolkit is running
- Make sure on Smart Touch, the screen with message "Drive Toolkit Detected" is showing
- Follow next steps in [Activate License](/docs/mddrive/v4.4.9/getting-started/activate-license) and [Download Engine Updates](/docs/mddrive/v4.4.9/getting-started/update-engines) to provision your Drive with Smart Touch

## Generate [S](https://www.opswat.com/docs/mddrive/process/results--management#sync-reports-for-central-management)upport Packages

To generate a support package for MetaDefender Drive with Smart Touch, ensure your drive is not connected to a target device or performing any operations.

1. Tab **Setting** icon on the **Navigation bar,** then tap **Support Package**.

2. Read the notification careful, the tab **Proceed To Generation**

3. Prepare an external USB (formatted in NTFS/FAT/exFAT) with USB-A-to-C adaptor. Insert it into the type C port of MetaDefender Drive with Smart Touch then tab **Generate Support Package**

4. Wait for the package creation process to complete

5. Once completed, press **Done** and remove the USB storage from Smart Touch.

6. The Support Package will be created and located in the root of your MetaDefender Drive with Smart Touch storage under the ***smclog*** folder.

About the Process

This process is to generate support packages for MetaDefender Drive with **Smart Touch**. To generate a support package for MetaDefender Drive, please follow the instruction on [this page](https://www.opswat.com/docs/mddrive/troubleshooting/generate-support-packages).
