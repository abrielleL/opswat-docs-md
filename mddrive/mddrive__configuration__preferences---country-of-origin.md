# Preferences → Country Of Origin

The Country of Origin detection feature enables MetaDefender Drive to scan binaries on the target system to attempt to determine in which country the publisher of each file resides, or where a file first originated from.

Note

Country of Origin is available on Meta Defender Drive **Advanced** and **Enterprise** only.

To enable this feature,

1. Go to **Settings** → **Preferences** → **Country of Origin**.
2. Check the Enable **Country of Origin** checkbox.
3. Select the countries you intend to add to the **Forbidden List**.
