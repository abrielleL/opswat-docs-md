# Centralized Scanning Profile - Unlock in MetaDefender Drive In-Session

After being managed by Centralized Scanning Profile, when starting Memory Scan or Custom Sca from In-Session, an Operator will be asked to "**Unlock to Scan**".

Unlock to run Custom Scan

Unlock to run Memory Scan

To **Unlock**, click U**nlock To Scan** then enter a 6-digit OTP provided by an Approver. Once the correct OTP is entered, the scan modes unlock immediately.
