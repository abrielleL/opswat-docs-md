# Copy Files to Secure Files Storage

View as Markdown Ask ChatGPT about this page Ask Claude about this page

To start using Secure File Storage:

1. Tap the Disk Icon to expand the left navigation bar, then tap **Secure Storage**

2. Confirm your selection by tapping **Proceed to Secure Storage**

3. **Secure File Storage** will start first with **calculating the Total Files**

   1. The **Calculating file hashes***...* message will be displayed. A progress bar with the estimated time left is shown while this runs.
   2. The files count will be updated once the calculation is completed. This time of this process depends on the number of files being transferred.

4. Once the initialization is complete, files counter completes and populated, Secure File Storage opens on the **Share Files** tab and the **Connect to a host machine to copy clean files** message is displayed on the MetaDefender Drive with Smart Touch screen.

## [Share Files](/docs/mddrive/process/copy-files-to-secure-files-storage#share-files)

Secure File Storage has two modes, **Share Files** and **Scan Files**.

1. Insert MetaDefender Drive with Smart Touch with Secure File Storage enabled to the target device and wait for a new partition to appear in your file browser with the size of 32 GB and NTFS file system.

2. After the copying files is completed and the USB cable is safely unplugged, Secure File Storage will recount the files.
3. When the calculation finishes, the page stays at **Share Files**, ready for a next copy.

   1. The **Total Files** number will be populated.
   2. The **Available Space** will show up, giving clear visibility into total and remaining Secure File Storage capacity.

5. The newly copied files will be stored and listed in **Unscanned Files**

After Copying Files into Secure File Storage

If you plug the Secure File Storage into a host you will see an empty 32GB storage that is ready for another copy session, and the files that were previously copied into Secure File Storage can only be accessed from a computer **only when they have been scanned and confirmed safe** by an OPSWAT MetaDefender Kiosk.

Unscanned Files now are ready to be examined by MetaDefender KIOSK, follow this instruction to [Scan Files in Secure File Storage with KIOSK](/docs/mddrive/process/san-secure-files-storage-with-kiosk).
