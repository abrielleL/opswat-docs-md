# My OPSWAT Central Management Integration

View as Markdown Ask ChatGPT about this page Ask Claude about this page

MetaDefender Drive Toolkit automatically checks for the latest engine versions included in your license. The downloaded updates will be stored in the host device's local storage. From the **Manage Engines** page, you can check if any of your drives' engines is outdated so you can copy the latest version to this drive.

1. Click **Check for Updates** and wait until all engine update downloads are completed and the engines show the **ready** status under the **Version** and **Database** columns, then click the **Copy Engines to Drive** button.

Drive Toolkit will download all of the engines that are available for every license tier

Please notice that by click check for updates, all of engines that are available for all of license tiers will be downloaded, including the engines for In-Session scanner.

Error

If you click the **Copy Engines to Drive** button before the engine updates are downloaded, you will receive the following *"Engine update is still in progress"* error.

2. Track the engines copying progress until you see the *"Engines copied successfully"* status displayed next to all drives.

Info

Copying engines to MetaDefender Drive from MetaDefender Drive Toolkit's Manage Engines page only copies the engine definition packages to the MetaDefender Drives. The engines will be fully installed and become fully functional with the next boot.
