# MetaDefender Drive v4.0.5

| [MetaDefender Drive v4.0.5](/docs/mddrive/release-notes/metadefender-drive-v4-0-x#metadefender-drive-v405) Released on Jul 30, 2024 | A major release for MetaDefender Drive with new features and enhancement. This Release supports MetaDefender Drive Enterprise and MetaDefender Drive Advanced USB Drive. Users must download and install MetaDefender Drive Toolkit version 3.5.0 to accompany MetaDefender Drive major release v4.0.5.  MetaDefender Drive major release v4.0.5 and MetaDefender Drive Toolkit version 3.5.0 now officially support MetaDefender Drive with Digital Display.  The MD Drive Toolkit can be downloaded from [this link.](https://installer-cdn.opswat.com/MD_Drive_Toolkit/3.0/update_infra/main/MetaDefenderDriveToolkit.zip) |
| --- | --- |
| **New Features** | - **[4.0.5]** **Resource Utilization is shown in the taskbar area. With this, user can quickly have visual about how the hardware is being occupied.** - **[4.0.4] Remediation for** **Faulty Update on Falcon Sensor.** - **[4.0.3]** Information of reports has been enhanced with system information and filter slider - **[4.0.3]** Show details of unwanted apps detected by K7 in reports - **[4.0.0]** New User Interface for ease of navigation and status reports. - **[4.0.0]** Threat Removal capability for any potentially malicious threat identified. All Threats identified can be removed permanently. Since this process is irreversible, You are responsible for ensuring that you have any necessary consent and/or authorization from the device owner to use Threat Removal option. OPSWAT Inc. disclaims any and all liability related to any alleged loss of data arising from your voluntary selection of this option. - **[4.0.0]** Scan Automation enhancement, where MD Drive automatically runs a full scan after a configurable preset time. - **[4.0.0]** Changes to MetaDefender Drive Anti-Malware engines (Drives must be reactivated in order to get updated list of engines):    - For MetaDefender Drive Enterprise: Removed **Kaspersky** engine and replaced it with **ESET** engine, remaining a total of **5 engines.** ​Added **DLP** and **Vulnerability** offering to Enterprise SW offering.   - For MetaDefender Drive Advanced: Added **CrowdStrike** and **Ahnlab** engines, bringing a total of **7 engines.** |
| **Enhancements** | - **[4.0.4] We stabilize and improve performance of the DigitalDisplay** - **[4.0.4] New popup shows when encrypted disks exist and lands to Disk Remediation screen** - **[4.0.2]** Show Disk Access (Mounted/Unmounted) and Archive Settings in text reports. - **[4.0.2]** ZFS (unencrypted) is now officially supported but not yet ready for Threat Removal. - **[4.0.0]** Introduce the new, vivid, use interface, for ease of navigation and reports viewing. - **[4.0.0]** Reflects scan progress with all available information and filters for ease of monitoring. The user can visually see the files scanned and malicious threats detected with complete information. - **[4.0.0]** Show the scan type (Full, Quick, and Custom Scan) in the Report - **[4.0.0]** Show date of definitions of Engines in Scan Session and Reports - **[4.0.0]** Ability to search dynamically reports by name. - **[4.0.0]** Ability to stop a scanning session and save the progress. The uncompleted scan reports can be reviewed as needed. - **[4.0.0]** Ability to enable clean file hash under settings -> preferences. All reports will display file hashes under /data/reports/. - **[4.0.0]** Provide the ability to automatically unlock BitLocker disks with Windows recovery Key, tied with Windows BitLocker Encryption process. - **[4.0.0]** Show Engines Version and Definition Date in Session Report. |
| **Known Issues** | - For cleaning files transferring to second USB, we are not yet validating if the selected USB’s capacity is lower than the total size of selected files. Checking capacity size will be supported in a subsequent release. |
