# How to Use the Fend Cloud Web App

View as Markdown Ask ChatGPT about this page Ask Claude about this page

You can log into you Fend account at <https://app.fend.tech/login>. In the Fend web app you can submit support requests, download the latest software and users’ manuals, and, if you are subscribed to the Fend Cloud service, you can monitor and access your diode’s cloud data. There are four main sections, Dashboard, Devices, Credentials, and Support.

## [Dashboard](/docs/fenddiode/how-to-use-the-fend-cloud-web-app/how-to-use-the-fend-cloud-web-app#dashboard)

In this section you can monitor diodes that are assigned to your Fend Cloud account if your devices are subscribed to Fend Cloud. This view can be filtered by device to see a live stream of device data.

## [Devices](/docs/fenddiode/how-to-use-the-fend-cloud-web-app/how-to-use-the-fend-cloud-web-app#devices)

This section shows all of your Fend Cloud-enabled diodes at a glance, giving a snapshot of status information such as Diode Serial, Name, Location, and Last Event

## [Credentials](/docs/fenddiode/how-to-use-the-fend-cloud-web-app/how-to-use-the-fend-cloud-web-app#credentials)

For Fend Cloud subscribers, this section provides the necessary keys and identification to use the API to pull diode data into other software platforms. A section with example code for how to access the API is provided.

## [Support](/docs/fenddiode/how-to-use-the-fend-cloud-web-app/how-to-use-the-fend-cloud-web-app#support)

Clicking on "Support" will take you to <https://my.opswat.com/> where you can update download the latest firmware and software utilities for your diode. For instructions on getting firmware from MyOPSWAT please see the section on [Firmware & Software Downloads](https://www.opswat.com/docs/fenddiode/firmware-software-downloads). If you have issues logging in or downloading support material, contact us at [fendsupport@opswat.com](mailto:fendsupport@opswat.com).
