# Using the Fend Configuration Interface

The screenshot below shows the four main action areas of user interface:

1. **Menu section** –

   1. **Session countdown timer (upper left)** - Begins when the tool is connected to the diode and counts down from 30 minutes. At the end of the 30-minute timer, the diode will close the session automatically without saving changes and reboot. To continue configuration, you can log in again.
   2. **Gear icon (upper right)** – Contains the following fields:

      1. Set password button – Allows the user to change the diode login password.
      2. Export configuration button - Saves a backup of the diode’s configuration as a local file.
      3. Import configuration button – Loads a previously saved configuration file onto the diode.
   3. **Exit Without Save button** – Ends the configuration session and will return the diode to operational mode without saving the changes made during the current session.
   4. **Save & Exit button** – Saves all changes made during the current configuration session and ends the session. This will reboot the diode and return it to operational mode.
2. **Input side configuration section** - Contains the settings for the input side of the device. It is divided into two sections “Interface Settings” which contains settings for the ethernet and serial connections and “Protocol Settings” which allows you to specify specifics about the operational protocol mode for the input side.
3. **System configuration section** – Contains system-wide settings and functions for the diode.
4. **Output side configuration section** - Contains the settings for the output side of the device. It is divided into two sections “Interface Settings” which contains settings for the ethernet, serial, and cellular connections and “Protocol Settings” which allows you to specify specifics about the operational protocol mode for the output side.
