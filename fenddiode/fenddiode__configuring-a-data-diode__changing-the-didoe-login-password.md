# Changing the Diode Login Password

To change the diode’s login password:

1. Log into your data diode using your web browser.
2. Navigate to the top right section and click the “gear” icon, then select “Change Password” from the drop-down menu as seen below.

3. A window will pop up prompting for the new password. New passwords have a required minimum length of 15 characters, 1 lowercase, 1 uppercase, 1 number and 1 special character. New passwords must be typed in twice to confirm.
4. Press “OK” to save the new password. Note: The password change will only apply after the current configuration session is ended with the “Save & Exit” button. Clicking “Exit Without Save” will discard all setting changes including the new password. After saving and exiting, the new password will be required to log into the diode to start a new configuration session.
