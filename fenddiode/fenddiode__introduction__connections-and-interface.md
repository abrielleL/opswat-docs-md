## [Fend Data Diode Model Numbers](/docs/fenddiode/introduction/connections-and-interface#fend-data-diode-model-numbers)

Fend Data Diodes come in two different series with three hardware configurations each. The input side of all configurations is the same, but the output side varies, offering different combinations of serial, cellular, and ethernet. Each hardware option is shown below.

You can tell which model you have by looking at the second and fourth grouping of alphanumeric characters in model number on the diode, as follows:

Example: FD-**5M**-SE1-**SE2**-**B4-**BLK

- Second grouping (series)

  - 5M – 5-Series Diode
  - 15M – 15-Series Diode
- Fourth grouping (output configuration)

  - SE2 – Serial (S) + Ethernet (E)
  - CE2 – Cellular (C) + Ethernet (E)
  - XE2 – None (X) + Ethernet (E)

## [Hardware Configurations](/docs/fenddiode/introduction/connections-and-interface#hardware-configurations)

### [XE5 / XE15 Model (Ethernet)](/docs/fenddiode/introduction/connections-and-interface#xe5--xe15-model-ethernet)

All XE-based model data diodes have Ethernet and RS485 (serial) inputs. The RS485 port can receive serial machine protocol inputs. The Ethernet port accepts a standard Ethernet cable.

XE-based models have a single Ethernet output which accepts a standard Ethernet cable.

### [SE5 / SE15 Model (Ethernet + Serial)](/docs/fenddiode/introduction/connections-and-interface#se5--se15-model-ethernet--serial)

All SE-based model data diodes have Ethernet and RS485 (serial) inputs. The RS485 port can receive serial machine protocol inputs. The Ethernet port accepts a standard Ethernet cable.

SE-based models have Ethernet and “RS485” (serial) output ports identical to their input ports.

### [CE5 / CE15 Model (Ethernet + Cellular)](/docs/fenddiode/introduction/connections-and-interface#ce5--ce15-model-ethernet--cellular)

All CE-based model data diodes Ethernet and RS485 (serial) inputs. The RS485 port can receive serial machine protocol inputs. The Ethernet port accepts a standard Ethernet cable.

CE-based wireless models have Ethernet and cellular antenna output ports.
