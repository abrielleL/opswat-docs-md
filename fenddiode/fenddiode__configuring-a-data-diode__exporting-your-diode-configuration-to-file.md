# Exporting Your Diode Configuration to File

View as Markdown Ask ChatGPT about this page Ask Claude about this page

To export a copy of the diode’s configuration, or to transfer the configuration onto another diode, click the Gear button. Select ‘Export Configuration’ to pull the current configuration from the diode and save it to a local file.

To import a previously saved diode configuration, click ‘Import Configuration’. Select the file in the dialog box provided and it will be loaded onto the diode. The imported changes will only apply after the current configuration session is ended with the “Save & Exit” button. Clicking “Exit Without Save” will discard all imported setting changes.
