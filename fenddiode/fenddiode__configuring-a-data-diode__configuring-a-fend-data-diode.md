# Configuring a Fend Data Diode

This section describes how to use a web browser to log into and configure a diode.

### [Required Materials](/docs/fenddiode/configuring-a-data-diode/configuring-a-fend-data-diode#required-materials)

1. Fend Data Diode
2. Two (2) diode power supplies
3. Ethernet cable
4. Computer with a web browser and an Ethernet port.

### [Supported Browsers](/docs/fenddiode/configuring-a-data-diode/configuring-a-fend-data-diode#supported-browsers)

Fend Data Diodes are compatible with the following supported browsers:

- Edge
- Chrome
- Firefox
- Safari
