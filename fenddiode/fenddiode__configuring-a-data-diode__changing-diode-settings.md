# Changing Diode Settings

**Diode settings are divided into two main sections: Input Side Settings and Output Side Settings.** The input side configuration section is further divided into two sections “Interface Settings”, which contains settings for the ethernet and serial connections, and “Protocol Settings”, which allows you to specify specifics about the operational protocol mode for the input side. Similarly, the output side configuration section contains the settings for the output side of the device and is also divided into two sections “Interface Settings”, which contains settings for the ethernet, serial, and cellular connections, and “Protocol Settings”, which allows you to set specifics about the operational protocol mode for the output side.

Within these sections are **submenus dedicated to specific groups of settings around a common function**. To view the contents of a sub-menu, select the corresponding function from the dropdown. The settings for that category will appear with the appropriate fields. For a detailed description of each parameter see [**Diode Settings Overview**](https://www.opswat.com/docs/fenddiode/configuration-settings)**.**

A successful parameter change is indicated by a green flash in the field being changed. If the parameter is invalid, the field will flash red.
