# Accessories and Cables

View as Markdown Ask ChatGPT about this page Ask Claude about this page

Fend Data Diodes are shipped with various accessories, including optional DIN rail mounts and custom power cable connectors. This section provides an overview of these accessories

## [12V Power Supplies (Standard)](/docs/fenddiode/introduction/accessories-and-cables#12v-power-supplies-standard)

Each diode is shipped with two 120V AC to 12V DC power supplies. One for each side of the diode. The diode has separate power supplies for each side in order to keep the input and output sides of the diode electrically isolated.

## [DIN-rail Mounting Plates (Standard)](/docs/fenddiode/introduction/accessories-and-cables#din-rail-mounting-plates-standard)

Each diode is shipped with DIN-rail mountable back plates.

####

## [Wall Mounting Feet (Optional Add On)](/docs/fenddiode/introduction/accessories-and-cables#wall-mounting-feet-optional-add-on)

Optional factory-installed wall mount feet are available that allow the diode to be mounted flush to a wall or server rack.

## [Screw-in Power Leads (Optional Add On)](/docs/fenddiode/introduction/accessories-and-cables#screw-in-power-leads-optional-add-on)

Optional screw-in power leads are available for industrial environments where local DC power is available and where the additional security of a screw-in power connector is desirable. Screw is power leads are designed with blue positive (+) and white negative (-) wire leads for direct connection to an existing DC power supply.
