# Ending a Configuration Session and Disconnecting from the Fend Diode

Entering a configuration session disables all running applications on the diode (such as FTP, Modbus, TCP, UDP, etc.) When the configuration of the diode is complete, you must click “Save & Exit” (to keep your changes) or “Exit Without Save” (to discard your changes) in the upper right-hand corner of the configuration interface.

“Save & Exit” will end the configuration session, confirm the saved changes with the diode, and reboot into the diode into operational mode using the new configuration.

“Exit Without Save” will end the configuration session, discard any changes that were made and reboot into the diode into operational mode using the existing configuration.

**You cannot use any protocols or test any settings changes while the diode is still in an active configuration session**.
