# How often do we update Windows patching data?

The Windows patching data is divided into two support lines:

- For third-party applications, the data is stored in patch.dat and updated every 8 hours
- For OS and system applications, the data is stored in wuo.dat and updated approximately 3 days after each Patch Tuesday event
