# How many applications are now supported for N-Day detection?

### [Overview](/docs/mdsdk/knowledge-base/how-many-applications-are-now-supported-for-n-day-detection#overview)

We support N-Day detection for Tier 1 & Tier 2 Applications on Windows, macOS, and Linux with the following focus:

- Tier 1 applications focus on the most popular **consumer and business applications** across all modules
- Tier 2 applications focus on the most popular **security applications** across all modules
