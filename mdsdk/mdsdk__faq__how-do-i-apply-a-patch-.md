# How do I apply a patch?

You can trigger the update of certain apps using two methods: GetLatestInstaller and InstallFromFile. GetLatestInstaller allows you to download the installer to update the app or simply get the download link. InstallFromFile uses the downloaded file to install the update on the device. Note: Installers are either hosted on the vendor site or obtained using the vendor's tool.
