# 2027

View as Markdown Ask ChatGPT about this page Ask Claude about this page

This page lists the planned OESIS Framework releases for 2027. Planned dates may change, and SDK versions for each release are announced in the release notes on the release date.

Bi-weekly release cadence

OESIS Framework releases on a bi-weekly cadence. Scheduled releases ship on the last Tuesday of each month (monthly release) and on the Tuesday two weeks before it. Hotfix releases may ship between scheduled releases when needed.
