# 2026

View as Markdown Ask ChatGPT about this page Ask Claude about this page

This page lists every OESIS Framework release in 2026, including releases that have shipped and releases planned for the rest of the year. Select a release date to open its release notes. Planned dates may change, and SDK versions for upcoming releases are announced in the release notes on the release date.

Release schedule change from October 2026

Starting October 2026, OESIS Framework moves from a weekly to a bi-weekly release cadence. Scheduled releases ship on the last Tuesday of each month (monthly release) and on the Tuesday two weeks before it. Hotfix releases may still ship between scheduled releases when needed.
