# [Dashboard](/docs/mdces3/operating/dashboard#dashboard)

The **Dashboard** provides a centralized overview of **MetaDefender Cloud Email Security™** activity, including threat detection, content sanitization, pending actions, and recent system events. It enables administrators to quickly assess the health of their email security environment and identify areas requiring attention.

## [Filtering Options](/docs/mdces3/operating/dashboard#filtering-options)

### [Time Range](/docs/mdces3/operating/dashboard#time-range)

Use the **Time Range** selector in the upper-right corner to filter all dashboard widgets by a specific period (for example, **Last 24 hours**).

---

# [Dashboard Widgets](/docs/mdces3/operating/dashboard#dashboard-widgets)

## [Threat Detection](/docs/mdces3/operating/dashboard#threat-detection)

The **Threat Detection** widget provides a summary of malicious emails detected during the selected time period.

It includes:

- **Emails Processed:** Total number of emails analyzed.
- **Threats Detected:** Total number of detected threats.
- **Detection Sources:** Breakdown of detections by protection engine (for example, **Multiscanning** and **MetaDefender Aether**).
- **Detection Timeline:** Line chart showing when threats were detected throughout the selected time period.
- **View Details:** Opens a drawer for additional threat detection results.

---

## [OPSWAT AI](/docs/mdces3/operating/dashboard#opswat-ai)

The **OPSWAT AI** widget displays detections generated by AI-powered analysis engines.

It includes:

- **AI Detections:** Number of threats identified using AI analysis.
- **Detection Confidence:** Overall confidence level for AI detections.
- **AI Engine Breakdown:** Displays detections generated by AI services such as **AI Predictive AI**.
- **Detection Timeline:** Shows AI detections over time.
- **View Details:** Opens a drawer for additional AI detection details.

## [Content Sanitization](/docs/mdces3/operating/dashboard#content-sanitization)

The **Content Sanitization** widget summarizes files that have been sanitized to remove potentially malicious active content.

It includes:

- **Files Sanitized:** Total number of sanitized files.
- **Sanitization Rate:** Percentage of processed files successfully sanitized.
- **Sanitized File Types:** Breakdown of sanitized file formats (for example, **ASCII Text**, **Hypertext Markup Language etc.**).
- **Sanitization Timeline:** Displays sanitization activity over time.
- **View Details:** Opens a drawer for additional sanitization details.

## [Action Items](/docs/mdces3/operating/dashboard#action-items)

The **Action Items** widget displays tasks that require administrator attention.

Typical action items include:

- Reviewing blocked malicious emails.
- Completing administrative actions.
- Tracking pending tasks.

Each action displays:

- **Task description**
- **Current status** (for example, **Pending** or **Done**)
- Quick action buttons for opening or completing the task.

Select **View All** to display all outstanding action items.

## [Top Blocked](/docs/mdces3/operating/dashboard#top-blocked)

The **Top Blocked** widget identifies the senders or recipients responsible for the highest number of blocked emails.

You can switch between:

- **Senders**
- **Recipients**

The widget displays:

- Email address
- Number of blocked messages
- Bar chart showing relative volume

Select **View All** to view the complete list.

To add a blocked sender to the allowlist, click the  icon and the sender’s **From address** can be directly added to the [allowlist](/docs/mdces3/configuration/allowlist).

## [Country of Origin & Geolocation](/docs/mdces3/operating/dashboard#country-of-origin--geolocation)

The **Country of Origin & Geolocation** widget displays the geographic locations associated with recent email activity.

It includes:

- Interactive world map showing detected locations.
- Country and city information.
- Geographic distribution of processed email traffic.

Use the map controls to zoom in or out.

Click **All Traffic** or **Threats only** to filter between displaying all traffic or Threats only. Select **View All** for additional location information.

## [Recent Activity](/docs/mdces3/operating/dashboard#recent-activity)

The **Recent Activity** widget provides a chronological list of recent administrative and system events.

Examples include:

- Integration completed or removed
- Notification template updates
- User synchronization
- Email release actions
- Administrative operations

Each entry displays:

- **Time of event**
- **Description**
- **User or system responsible**
- **Event type**
- Quick link to additional details

Select **View All** to display the complete activity history.

# [Navigation](/docs/mdces3/operating/dashboard#navigation)

Most dashboard widgets include a **View Details** or **View All** option.

Selecting these links opens the corresponding page with the appropriate filters already applied, allowing you to investigate the underlying events without manually configuring filters.
