# Onboarding

Summarize Page

**MetaDefender Cloud Email Security ™** provides industry-leading protection against malware, exploits, and advanced threats that bypass traditional email security defenses. This solution integrates seamlessly with your email infrastructure, ensures a secure communication environment, and safeguards your organization from evolving cyber threats.

## [Getting Started](/docs/mdces3/getting-started/onboarding#getting-started)

### [Register an Account with My OPSWAT](/docs/mdces3/getting-started/onboarding#register-an-account-with-my-opswat)

To use **MetaDefender Cloud Email Security ™**, you need to create an account on **My OPSWAT**.

- Visit My OPSWAT Registration Page [https://my.opswat.com](https:://my.opswat.com).

### [Request a License](/docs/mdces3/getting-started/onboarding#request-a-license)

To access the full features of **MetaDefender Cloud Email Security ™**, you need an evaluation or product license.

- Go to <https://www.opswat.com/get-started> to request a license.

### [Onboard MetaDefender Cloud Email Security™](/docs/mdces3/getting-started/onboarding#onboard-metadefender-cloud-email-security)

- In **My OPSWAT**, simply click **MetaDefender Cloud Email Security**, or go to <https://ces.metadefender.opswat.com/>
- Select your platform

  - [Microsoft Exchange Online](/docs/mdces3/configuration/microsoft-exchange-online)
