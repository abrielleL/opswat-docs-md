# Is there advanced search?

Yes, we offer an Advanced Search as part of [Threat Hunting](/docs/filescan/3.1.1/datasheet/advanced-search) process with a wide range of options (e.g. file type, time of analysis, verdict, IOC, etc.). It is available at the top search bar by clicking the three dots.

See the "Technical Datasheet" for a complete list of features: <https://docs.opswat.com/filescan/datasheet/technical-datasheet>
