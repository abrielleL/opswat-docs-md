# Extra Button

The admin can create a programmable button on the interface. Its settings can be parameterized in the **Admin Panel > Setting > Configurations > Extra Button** section.

After configuration, the extra button appears on the homepage, to the left of the profile icon:

### [Configuration options](/docs/filescan/3.1.1/configuration/extra-button#configuration-options)

| Field | Description |
| --- | --- |
| `EXTRA_BUTTON_TEXT` | The text of the button. |
| `EXTRA_BUTTON_LINK` | The link where the button goes to. |
| `EXTRA_BUTTON_ACTIVE` | Enable or disable the extra button. |

See the "Technical Datasheet" for a complete list of features: <https://docs.opswat.com/filescan/datasheet/technical-datasheet>
