# User Groups

### [User group descriptions](/docs/filescan/adminguide/user-group-access#user-group-descriptions)

Multiple groups can be assigned to a single user, and they are not mutually exclusive.

| User Groups Name | Description |
| --- | --- |
| **Admin** | User with access to admin panel |
| **Auditor** | User with read-only access to admin panel |
| **Guest** | Not authenticated user |
| **Intel** | User with access to advanced threat-intel |
| **User** | Ordinary authenticated user |

See the "Technical Datasheet" for a complete list of features: <https://docs.opswat.com/filescan/datasheet/technical-datasheet>
