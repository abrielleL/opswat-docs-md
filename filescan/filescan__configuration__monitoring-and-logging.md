# Monitoring and Logging

At the **Admin Panel > Setting > Configurations** section, various settings related to jobs, health checks, and audits can be configured.

- [Jobs](/docs/filescan/configuration/jobs) settings, where e.g.: retry attempts on failure, maximum rescan limit, and storage-related settings can be configured.
- [Healthcheck](/docs/filescan/configuration/healthcheck) settings, such as healthcheck period, healthchecks URI, or queue healthcheck configurations
- [Audit Logging for Admin Settings and User Authentication](/docs/filescan/configuration/audit-logger), where audit logs can be enabled or disables

See the "Technical Datasheet" for a complete list of features: <https://docs.opswat.com/filescan/datasheet/technical-datasheet>
