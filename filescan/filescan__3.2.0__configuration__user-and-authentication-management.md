# User and Authentication Management

View as Markdown Ask ChatGPT about this page Ask Claude about this page

In the admin panel, there are several options to configure user and authentication management (User -> Admin panel -> Settings). Such options include

- [Authentication](/docs/filescan/3.2.0/configuration/authentication), where internal and external token keys can be generated
- [Terms of Use](/docs/filescan/3.2.0/configuration/terms-of-use), where you can configure various usage terms, such as several Termly settings
- and [Third Party](/docs/filescan/3.2.0/configuration/third-party) components, like Google Analytics

See the "Technical Datasheet" for a complete list of features: <https://docs.opswat.com/filescan/datasheet/technical-datasheet>
