# OCM

View as Markdown Ask ChatGPT about this page Ask Claude about this page

You can configure settings related to [OPSWAT Central Management](https://docs.opswat.com/ocm) under Admin panel -> Settings -> OCM.

### [Configuration options](/docs/filescan/3.2.0/configuration/ocm#configuration-options)

| Field | Description |
| --- | --- |
| `OCM_DISCONNECTED_TIMEOUT` | Disconnection timeout in minutes |
| `OCM_CLIENT_URL` | OCM client URL, for example: *https://my.opswat.com/product-management/* |

See the "Technical Datasheet" for a complete list of features: <https://docs.opswat.com/filescan/datasheet/technical-datasheet>
