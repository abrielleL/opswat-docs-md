# Features Access

View as Markdown Ask ChatGPT about this page Ask Claude about this page

Restrictions can be set for different user groups regarding which features they can access. It can be set under the **Admin panel > Settings > Features Access**

## [General](/docs/filescan/3.2.0/adminguide/features-access#general)

Under the "General" tab, the following group restrictions can be set:

- Sign up
- Sign up by invitation
- Healthcheck
- Banner
- User management
- Site management
- Restricted statistics
- Jobs info

Submissions

Under the "Submissions" tab, the following group restrictions can be set:

- Scanning
- Advanced scanning - Advanced scanning options in file upload modal
- ChatGPT

## [Search](/docs/filescan/3.2.0/adminguide/features-access#search)

Under the "Search" tab, the following group restrictions can be set:

- All reports list
- Simple search
- Advanced report search
- Search without date limit
- IOCs reputation

## [Sample Access](/docs/filescan/3.2.0/adminguide/features-access#sample-access)

Under the "Sample Access" tab, the following group restrictions can be set:

- Daily archives
- Daily archives of public execs
- Daily archives of public docs
- Daily archives of private execs
- Daily archives of private docs
- File download
- Latest feed XML

## [Moderation](/docs/filescan/3.2.0/adminguide/features-access#moderation)

Under the "Moderation" tab, the following group restrictions can be set:

- Report moderation - Manually change report verdict

See the "Technical Datasheet" for a complete list of features: <https://docs.opswat.com/filescan/datasheet/technical-datasheet>
