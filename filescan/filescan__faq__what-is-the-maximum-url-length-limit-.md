# What is the maximum URL length limit?

The maximum URL length limit has been extended to **2048 characters**. This change ensures better compatibility with modern browsers and improves the accuracy of URL analysis.

See the "Technical Datasheet" for a complete list of features: <https://docs.opswat.com/filescan/datasheet/technical-datasheet>
