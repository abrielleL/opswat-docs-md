# Output Report Formats

MetaDefender Aether supports exports in the following formats:

- HTML
- PDF (1.4)
- MISP JSON (misp-core-format-16 +)
- STIX JSON (2.1)
- Raw JSON

Select the preferred format on the report page by clicking *"Download Report"*:

Note

The export process may take several minutes, depending on the size of the report and its contents. This duration is largely influenced by the selected settings, such as whether to include interesting strings or not

In case of **PDF** or **HTML**, the exported files can be downloaded from *"My Downloads"* :

See the "Technical Datasheet" for a complete list of features: <https://docs.opswat.com/filescan/datasheet/technical-datasheet>
