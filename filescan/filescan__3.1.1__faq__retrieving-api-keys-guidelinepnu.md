# How do I get my API key?

An extensive OpenAPI (OAS3) Documentation is available from the [API](https://www.filescan.io/api/docs) link at the top menu.

You can generate your API key for authorization at the API Key tab of your [profile settings](https://www.filescan.io/users/profile).

Users can navigate to **My Settings > API Keys**

## [Step 1](/docs/filescan/3.1.1/faq/retrieving-api-keys-guidelinepnu#step-1)

Go to the **Admin Panel** icon and choose the **My Settings** menu option.

## [Step 2](/docs/filescan/3.1.1/faq/retrieving-api-keys-guidelinepnu#step-2)

Select the **Professional Info >** **API Key** tab in order to retrieve, change or remove the API keys.

See the "Technical Datasheet" for a complete list of features: <https://docs.opswat.com/filescan/datasheet/technical-datasheet>
