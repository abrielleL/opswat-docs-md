# Can I analyze the same file multiple times?

View as Markdown Ask ChatGPT about this page Ask Claude about this page

Yes, every upload generates a new report. Due to the nature of e.g. download URLs becoming unavailable, reporting for the same file may vary depending on the time of analysis.

See the "Technical Datasheet" for a complete list of features: <https://docs.opswat.com/filescan/datasheet/technical-datasheet>
