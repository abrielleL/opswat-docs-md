# Adding users

In this section, you will be shown how to add user to MetaDefender Aether.

Right to add users to MetaDefender Aether

Only Admins are able to invite users and give certain right to those users.

### [Step 1 - Go to "Admin panel"](/docs/filescan/3.1.1/adminguide/add-user#step-1---go-to-admin-panel)

Go to your "**Admin panel**" by clicking on Your account icon on the top right corner.

### [Step 2 - Select "User Management"](/docs/filescan/3.1.1/adminguide/add-user#step-2---select-user-management)

After you arrive to the Report Statistics Dashboard, where you can select "**User Management**" on the top left area of the menu bar.

### [Step 3 - Click on "Invite user"](/docs/filescan/3.1.1/adminguide/add-user#step-3---click-on-invite-user)

By selecting "Invite user", you will get a pop-up window.

### [Step 4 - Generate invitation link](/docs/filescan/3.1.1/adminguide/add-user#step-4---generate-invitation-link)

You may choose between the following user group types from the drop-down to generate a link for the designated MetaDefender Aether user

- Admin
- Auditor
- Intel
- User
- Guest

See the "Technical Datasheet" for a complete list of features: <https://docs.opswat.com/filescan/datasheet/technical-datasheet>
