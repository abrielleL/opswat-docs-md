# How long is the previous version of a MetaDefender Aether deployment compatible?

We maintain backward compatibility within each major version of MetaDefender Aether (as well as MetaDefender Sandbox 2.x.x) . However, due to the evolving nature of the threat landscape, we recommend that users upgrade to the latest version to ensure they benefit from the most up-to-date features, improvements, and security enhancements. **Our release cycle typically spans 90 days, with each version designed to work seamlessly within its respective major release.**

See the "Technical Datasheet" for a complete list of features: <https://docs.opswat.com/filescan/datasheet/technical-datasheet>
