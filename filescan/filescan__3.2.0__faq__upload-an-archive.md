# Can I upload an archive?

View as Markdown Ask ChatGPT about this page Ask Claude about this page

Yes, a wide range of archives is supported (zip, gzip, tar, wim, 7z, rar, etc.). If the archive contains multiple files, all embedded files are analyzed.

More details about archives are available: [Supported File Types](/docs/filescan/3.2.0/datasheet/supported-file-type)

See the "Technical Datasheet" for a complete list of features: <https://docs.opswat.com/filescan/datasheet/technical-datasheet>
