# Communication and Integration

Communication and integration settings can also be specified under the admin panel (User -> Admin panel -> Settings). These include the following:

- [Providers](/docs/filescan/configuration/providers) settings, such like MetaDefender Cloud
- [Reputation](/docs/filescan/configuration/reputation) settings, such as the threshold for various provider verdicts, bulk limit, or limits for IOC reports
- [SMTP / Email](/docs/filescan/configuration/email) configurations
- [Chat GPT](/docs/filescan/configuration/chat-gpt) authentication and fine-tuning settings
- [OCM](/docs/filescan/configuration/ocm), OPSWAT Central Management settings, like timeout and URL
- [MISP](/docs/filescan/configuration/misp) integration settings, like API-key or URL

See the "Technical Datasheet" for a complete list of features: <https://docs.opswat.com/filescan/datasheet/technical-datasheet>
