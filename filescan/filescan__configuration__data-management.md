# Data Management

The configuration of data management is also accessible from the admin panel (User -> Admin panel -> Settings), such as database settings, storage settings, retention policy, or secondary storage. The following are included under data management:

- [Database](/docs/filescan/configuration/database) settings
- [Storage](/docs/filescan/configuration/storage) settings
- [Retention Policy Configuration](/docs/filescan/configuration/retention-policy-configuration)
- [S3 Report Storage](/docs/filescan/configuration/s3-report-storage) settings (for secondary storage)

See the "Technical Datasheet" for a complete list of features: <https://docs.opswat.com/filescan/datasheet/technical-datasheet>
