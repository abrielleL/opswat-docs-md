# Appearence

The appearance can also be customized under the **Admin panel >** **Settings >** **Appearance**.

You can select which logo to display:

- On the homepage
- In the top menu
- In the footer

See the "Technical Datasheet" for a complete list of features: <https://docs.opswat.com/filescan/datasheet/technical-datasheet>
