# Can I specify an archive password?

Yes, the submission dialogue and API have options to specify an archive password. If you upload an archive with a typical password (e.g. "infected"), no password needs to be specified, as all standard passwords will be attempted under-the-hood.

See the "Technical Datasheet" for a complete list of features: <https://docs.opswat.com/filescan/datasheet/technical-datasheet>
