# ChatGPT (Executive Summary)

MetaDefender Sandbox on premise / platform integrates with OpenAI using the ChatGPT model, providing the ability to generate a concise executive summary for files.

The primary aim of this executive summary is to make threat analysis easier to understand by highlighting the most significant aspects of the malware report. Relevant features are extracted using MetaDefender Aether, with input from malware analysts, to offer a concise overview of the malware's key insights and capabilities.

Warning

The ChatGPT integration is **disabled** **by default** and requires an OpenAI key that needs to be generated by the user. Data sent to OpenAI will remain private in accordance with their privacy policy: <https://openai.com/policies/privacy-policy>

## [Configuration of the ChatGPT integration](/docs/filescan/3.1.1/integrations/open-ai-executive-summary#configuration-of-the-chatgpt-integration)

**Step #1 - Go to "***Admin panel***" and then "***Settings*_**"**_ **page. Then select "**Communication and Integration**s" in the "**Configuration**" page.**

**Step #2 - Go to "***Chat Gpt***" sub-page and configure Open-AI API key, model, prompt**

### [Configuration options](/docs/filescan/3.1.1/integrations/open-ai-executive-summary#configuration-options)

| Field | Description |
| --- | --- |
| `**CHAT_GPT_API_URL**` | **The URL of the ChatGPT server**  *In case of Azure API, this should be a full URL, including model deployment ID and API version. Example with Azure API:*   - https://`myopenairesource`.openai.azure.com/openai/deployments/`gpt-35-turbo`/chat/completions?api-version=`2023-03-15-preview`    - `myopenairesource` is the name of your Azure OpenAI resource.   - `gpt-35-turbo` is the deployment ID for the model.   - `2023-03-15-preview` is the API version being used. |
| `**CHAT_GPT_API_SECRET**` | **ChatGPT API-key** |
| `**CHAT_GPT_PAYLOAD_MODEL_NAME**` | **The name of the payload model, for example: gpt-3.5, gpt-4**  *In case of Azure API, this field could be left empty* |
| `**CHAT_GPT_PAYLOAD_SYSTEM_CONTENT**` | **With the payload system content, you can further customize ChatGPT's responses. For example: "You are a malware expert who highlights the 5 most interesting properties of the malware."** |
| `**CHAT_GPT_PAYLOAD_USER_CONTENT**` | **How would you like ChatGPT to respond** |
| `**CHAT_GPT_IS_AZURE_API**` | **Checkbox** |

## [Integration Workflow](/docs/filescan/3.1.1/integrations/open-ai-executive-summary#integration-workflow)

1. Define the ChatGPT prompt and model.
2. Extract specific file fields and information
3. Construct the query string utilizing the acquired information and request input for the selected model.
4. Invoke the ChatGPT API to produce the generated summary.
5. Display the ChatGPT summary

See the "Technical Datasheet" for a complete list of features: <https://docs.opswat.com/filescan/datasheet/technical-datasheet>
