# Communication and Integration

View as Markdown Ask ChatGPT about this page Ask Claude about this page

Communication and integration settings can also be specified under the admin panel (User -> Admin panel -> Settings). These include the following:

- [Providers](/configuration/providers) settings, such like MetaDefender Cloud
- [Reputation](/configuration/reputation) settings, such as the threshold for various provider verdicts, bulk limit, or limits for IOC reports
- [SMTP / Email](/configuration/email) configurations
- [Chat GPT](/configuration/chat-gpt) authentication and fine-tuning settings
- [OCM](/configuration/ocm), OPSWAT Central Management settings, like timeout and URL
- [MISP](/configuration/misp) integration settings, like API-key or URL

See the "Technical Datasheet" for a complete list of features: <https://docs.opswat.com/filescan/datasheet/technical-datasheet>
