# What file types are supported?

A wide range of documents (e.g. Office OOXML, PDFs), scripts (VBS, Jscript, Powershell) and executable file formats (e.g. PE, APK). In general, any file can be submitted, but your results may vary. The best coverage is for the analysis of Office files.

More details about supported file types are available: [Supported File Types](/docs/filescan/datasheet/supported-file-type).

See the "Technical Datasheet" for a complete list of features: <https://docs.opswat.com/filescan/datasheet/technical-datasheet>
