# Sandbox Engine Exit Codes

| Code | Definition |
| --- | --- |
| 0 | Successful |
| 1 | Configuration self-test failed |
| 5 | YARA update failed (transform only) |
| 8 | Email test failed |
| 9 | Application servers could not be verified (broker only) |
| 11 | Licence error (transform only) |
| 100 | Unexpected error |

See the "Technical Datasheet" for a complete list of features: <https://docs.opswat.com/filescan/datasheet/technical-datasheet>
