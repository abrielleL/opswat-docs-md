# NAC Basic Installation Guide

Learn how to download and configure NAC to enable basic features like enforcement roles to control users' network access and device profiling and visibility. The following two steps show admins how to configure their virtual environment. The first step shows how to integrate NAC with a network. The second step allows for admins to optionally configure Profiling and Visibility. The third step allows for identity of unmanaged devices.

- [Network Integration](/docs/manac/installation/network-integration)
- [Optional - Configure Device Profiling/Visibility](/docs/manac/installation/optional---configure-device-profiling-and-visibility)
- [Configure Identity for Unmanaged Devices](/docs/manac/installation/configure-identity-for-unmanaged-devices)
