# Introduction

## [What is MetaDefender NAC Cloud?](/docs/manac/nac-v8.1.1/nac-cloud/introduction#what-is-metadefender-nac-cloud)

MetaDefender NAC Cloud is what we call the set a features in [MetaDefender IT Access](https://www.opswat.com/products/metadefender/access/it) that allow it to fill the role of a NAC. Like MetaDefender NAC discussed in the tabs to the left, MetaDefender NAC Cloud can be used to dynamically assign devices on your network to different VLANs, apply ACLs, or enforce other low-level networking controls based on policies defined in an feature-rich admin console. Unlike the on-premise MetaDefender NAC, though, with MetaDefender NAC Cloud everything is managed from a centralize cloud-native platform maintained by OPSWAT.

## [Who is MetaDefender NAC Cloud for?](/docs/manac/nac-v8.1.1/nac-cloud/introduction#who-is-metadefender-nac-cloud-for)

MetaDefender NAC Cloud is not yet at feature parity with MetaDefender NAC, but it does support most of the core capabilities of a NAC, and we're adding more features with each release! Still it may not be the best fit for all customers.

If your use case for NAC focuses on assigning network access based on user identities defined in an on-premise directory server like AD, then an on-premise deployment of MetaDefender NAC might still be better for you.

If your use case for NAC focuses on assigning network access based on advanced endpoint posture checks, or admin-assigned device groups, MetaDefender NAC Cloud may be perfect for you!

## [Is the on-premise version of MetaDefender NAC going away?](/docs/manac/nac-v8.1.1/nac-cloud/introduction#is-the-on-premise-version-of-metadefender-nac-going-away)

No. With OPSWAT's core mission of "Protecting the Worlds Critical Infrastructure", we understand that cloud-based solutions aren't right for everyone. We're aware that having an on-premise NAC solution running on self-managed infrastructure is a hard requirement for many of our most valued customers. Because of this, OPSWAT always intends to offer an on-premise NAC solution.
