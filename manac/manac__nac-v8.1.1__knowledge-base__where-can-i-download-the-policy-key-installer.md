# Where can I download the Policy Key installer?

This article applies to the current NAC Enforcer, and the latest NAC Policy Key installed on Windows or macOS systems.

Click the relevant link below to download the latest **NAC Policy Key** installer directly from the Enforcer.

This installer can be used for manual distribution or for distribution via group policy (for Windows).

|  |  |
| --- | --- |
| Windows MSI | <https://portal.myweblogon.com:8443/downloads/ServiceMSI.msi> |
| Windows | <https://portal.myweblogon.com:8443/downloads/ServiceInstaller.exe> |
| MacOS | <https://portal.myweblogon.com:8443/downloads/SafeConnectMacInstaller.zip> |

Please Note:

1. Custom branded URL users should navigate to the custom branded URL of NAC with the **9443** port going forward. For example: <https://custom.branded.hostname:9443/downloads/ServiceMSI.msi> . Those who are not on a NAC managed network should substitute [portal.myweblogon.com](http://portal.myweblogon.com/) for the **Public IP** of their NAC appliance. If the NAC appliance doesn’t have a public IP address, users may need to visit an NAC-managed network to download the **Policy Key**.
