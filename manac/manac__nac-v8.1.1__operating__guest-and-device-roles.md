# Guest and Device Roles

The Guest and Device Roles page is used for configuring end user roles. This can be accessed by navigating to [https://portal.myweblogon.com:8443/manage/#/configuration/GuestandDeviceRoles](https://onlinehelp.opswat.com/safeconnect-enforcer/attachments_4084910_1_example_role.PNG) . “ [portal.myweblogon.com](http://portal.myweblogon.com) ” can be replaced with the IP address of the NAC appliance or the custom hostname of the appliance, if applicable.

To configure a new end user role, click on the "Create new role" button.

A new entry form with the name "A New Role" will appear. Change this to the name of the role that will be used. This field is what will be used throughout the system. User roles must not contain any spaces.

Optionally, enter a description for the new role. When finished, click on the “Save Changes” button. You will be taken back to the list of roles with the newly added role included.

To edit a role, click the pencil button under the Operation column. Once changes are ready, click the “Save Changes” button.

To delete a role, click the trash can button under the Operation column.
