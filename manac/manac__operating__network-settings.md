# Network Settings

The first section in the Configuration Manager displays the Network Settings for your NAC appliance.

You can only view the Network Settings through this page. To edit these, an admin user with a NAC Appliance will have to connect a keyboard and a monitor to their NAC appliance and log in with the username of "admin". The console configuration menu should come up. Admin users with virtual environments should access the configuration menu through their VM provider's interface. The second section of this menu, "Network Settings", is where these settings can be edited.

If an admin user is not sure what their password is, call or email OPSWAT Support to have it reset to default.
