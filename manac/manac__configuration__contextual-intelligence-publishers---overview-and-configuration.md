# Contextual Intelligence Publishers - Overview and Configuration

Contextual Intelligence Publishers provide the ability to export data to a third party system. With this data, the system can use identity based rules without the need to require users to authenticate multiple times. To enable this feature, an entry must be added for each system where data should be sent. The third party system must also be configured to receive data.

## [Accessing the Contextual Intelligence Interface](/docs/manac/configuration/contextual-intelligence-publishers---overview-and-configuration#accessing-the-contextual-intelligence-interface)

Login to the NAC management interface at: <https://portal.myweblogon.com:8443/manage> . If this does not work, you can replace ‘ [portal.myweblogon.com](http://portal.myweblogon.com/) ’ with the IP address of your NAC appliance. In a cluster environment, this must be the manager node. If a branded URL is configured, replace ‘ [portal.myweblogon.com](http://portal.myweblogon.com/) ’ with the branded URL chosen. Once Logged in, choose Configuration Manger > Security Orchestration > Contextual Intelligence.
