# Configuration Manager - Backup

The "Backup" page enables NAC administrators to control when and where NAC content is backed up. Navigate to <https://portal.myweblogon.com:8443/manage/#/configuration/backup>. “[portal.myweblogon.com](http://portal.myweblogon.com/)” can be replaced with the IP address of the NAC appliance or the custom hostname of the appliance if applicable.

Check the box for "Backup will be saved to location of your choice." and select the location.

Info

The information box next to the URL entry form alerts users that FTP, SFTP, custom ports, and custom paths are supported and provides examples of URL formats.
