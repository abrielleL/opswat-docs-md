# User Management

The User Management page is used for configuring user access to the NAC UI. This can be accessed by navigating to <https://portal.myweblogon.com:8443/manage/#/configuration/UsersManagement> .

NOTE: “[portal.myweblogon.com](http://auth.impulse.com/) ” can be replaced with the IP address of the NAC appliance or the custom hostname of the appliance, if applicable.

## [Users Tab](/docs/manac/nac-v8.1.1/operating/user-management#users-tab)

This tab shows all of the currently configured users along with their assigned profiles.

Clicking the pencil button under the Modify column will allow you to edit a user's username, password and profile.

## [Profiles Tab](/docs/manac/nac-v8.1.1/operating/user-management#profiles-tab)

This tab allows you to view every configured profile along with what users are assigned to it.

The default profiles allow you to view their permissions by clicking the eye button under Modify. Any additional profiles will have a pencil button for editing.

Clicking "Add" will allow you to add a new user profile with custom permissions.
