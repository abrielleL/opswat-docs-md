# Centralized Resource Monitoring

If you have a need to monitor resource utilization across all NAC VMs from a single centralized dashboard, and your hypervisor does not support this, this can still be achieved via the tool, "[Cacti](https://github.com/Cacti/cacti)".

If you are interested in this functionality, please contact OPSWAT Support, and we can assist you with deployment and configuration of this monitoring dashboard on your standalone NAC VM or your cluster's "Manager" node.
