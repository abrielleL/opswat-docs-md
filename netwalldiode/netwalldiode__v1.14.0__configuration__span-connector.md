# SPAN Connector

SPAN Connector allows the user to copy ethernet traffic from a physical port of the MetaDefender Optical Diode (hereinafter Optical Diode) BLUE and replicates it to a designated SPAN port n Optical Diode RED.

### [Optical Diode BLUE](/docs/netwalldiode/v1.14.0/configuration/span-connector#optical-diode-blue)

Important

A security dongle must be inserted in the BLUE and RED servers to change configuration.

1. Login into Optical Diode BLUE.
2. Go to SPAN menu (in Connectors section), deploy Action button and select Add SPAN.
3. Type or select values in the following boxes:

   1. **Port:** Dropdown list of the available ports for span connector. A span port can't be used for any other purpose on the Optical Diode. A port used by other process (management IP associated, for instance) will not be displayed on the list.
   2. **Description:** Free text box to include a description of the configured SPAN.
   3. **Enabled**: Check/Uncheck this box to enable/disable this SPAN.
4. Click on Submit button.
