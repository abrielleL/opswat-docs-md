# Overview

View as Markdown Summarize this page Ask ChatGPT about this page Ask Claude about this page Connect your AI tool

**File Security** in My OPSWAT Central Management gives you centralized visibility into file processing across your MetaDefender instances and lets you trace and act on suspicious files without signing in to each instance.

You'll find it in the left navigation under **Solution > File Security**. It contains five sub-pages: **Dashboard, Files Processing History, Quarantined Files, Skip By Hash, Password Storage, and Policies**.

## [File Security Workflow at a Glance](/docs/cm/file-security-solution/file-security-solution-overview#file-security-workflow-at-a-glance)

| Steps | Details |
| --- | --- |
| **Step 1: Enroll** | Enroll MetaDefender instances into My OPSWAT Central Management by following [Enroll Products](/docs/cm/product-management/other-products) |
| **Step 2: Monitor** | Track processed, blocked, sanitized, and quarantined files, plus threat detections, across all instances with the [File Security Solution Dashboard](/docs/cm/file-security-solution/file-security-solution) |
| **Step 3: Enforce** | Block, allow, or skip engines for known files with [Skip by Hash.](/docs/cm/file-security-solution/skip-by-hash) Manage archive passwords centrally with [Password Storage](/docs/cm/file-security-solution/password-storage) |
| **Step 4: Investigate** | Trace a file's full path across products with [File Audit Trail](/docs/cm/file-security-solution/File-Audit-Trail). Retrieve, protect, or delete files with [Quarantined Files](/docs/cm/file-security-solution/quarantined-files) |
| **Step 5: Maintain** | Roll out module updates on selected groups before production with [Staged Module Rollout](/docs/cm/file-security-solution/staged-module-rollout). Collect logs for OPSWAT Support with [Generate Support Package](/docs/cm/file-security-solution/generate-support-package) |
