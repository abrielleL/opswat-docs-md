# Deploy Patches

You have three way to roll out patches and application updates to endpoint, each built for different needs and situation.

## Choose Your Methods

| Your situation | Use |
| ---- | ---- |
| You need to push a fix immediately | [On-Demand Deployment](https://www.opswat.com/docs/cm/patch-management/on-demand-deployment) |
| You want patches to install automatically, on a recurring schedule, without manual work | [Policy Deployment](https://www.opswat.com/docs/cm/patch-management/policy-deployment) |
| You want to roll out updates in stages before deploying broadly | [Ring Deployment](https://www.opswat.com/docs/cm/patch-management/ring-deployment) |
