# Product Updates Domains

My OPSWAT Central Management contacts the below domains to update product firmware, software, and modules for product updates.

| Product | Domain |
| ---- | ---- |
| MetaDefender Kiosk Windows | kiosk-hardened-image.s3.us-west-1.amazonaws.com |
| MetaDefender Kiosk Linux | update.my.opswat.com |
| MetaDefender Drive | installer-cdn.opswat.com |
| MetaDefender Endpoint | agent-update.opswat.com |
| Modules | update.dl.opswat.com |
