# How do I increase the Phishing Protection score on Security Score Windows devices?

## How to get max score

To get the max score for this category, we need to enable the antiphishing for all the browsers on your computer.

## How to set default browser:

Go to Windows Settings and select Apps tab → choose “Default apps”

![](https://uploads.developerhub.io/prod/1yda/d8td0313e3pdq64i4m6ru69rfx60xhrq4ta3xe0uojjvqb4qywkainlkeyq7liuu.png)

Start select default browser

![](https://uploads.developerhub.io/prod/1yda/hu5ozfxsky3it12jab76tlobafmk7t6w2cdymehi6uob03owp1pr1l9petaa26tp.png)

Click "Set Default"

![](https://uploads.developerhub.io/prod/1yda/qo2h629bywkxofblkg1urhzjwfg942t9v92rgae1btyj7gks710h3w6xx72rwk7l.png)

## How to enable Antiphishing in Chrome:

Google Chrome

Open settings of Chrome → select tab “Privacy and Security” → Click on “Security” field

![](https://uploads.developerhub.io/prod/1yda/vu345xwoc4p3grpv0210ct9mzoehg59mujv0b0obp88ldjc2vrtiakojf6ocshqb.png)

Select protect option for Chrome browser

![](https://uploads.developerhub.io/prod/1yda/1mo4i2397lvlcwigckr2aj5rafrr5scyjubp62npn43s9joz14inxc0e4swz04f0.png)

Note: we must enable antiphishing on all profile users of Chrome to make it right
