# Customizable Dashboard

My OPSWAT Central Management features the ability to customize the My OPSWAT Central Management console dashboards. With the ability to add and delete widgets, move widgets, and resetting the dashboards, administrators can establish dashboards personalized to their needs and be presented with a device's state at a glance.

## Types of dashboards

Within the **Dashboard** section, My OPSWAT Central Management  provides five dashboard pages that users can utilize to tailor the widgets to the different pages according to what they want to look for at any given time. The dashboard pages are:

- Overview
- Secure Access
- Vulnerabilities
- Compliance
- Threat Detection

Each one is established with an initialized dashboard with preset added widgets relevant to the categorized dashboard. However, users are able to update these pages and add/remove widgets to their liking

## Setting up the dashboard

When users log into My OPSWAT Central Management, they will be directed to the Overview page under **Dashboard**. Within the **Dashboard** section, console users are able to view and edit the dashboards to their liking. By utilizing the dashboard tools, users are able to navigate within **Edit Mode** and make other dashboard changes.

## The tools with the dashboard:

- Refresh - This tool allows the user to refresh the data displayed on the dashboard.
- Edit Mode - This tool allows the user to access Edit mode of the dashboard. Here users can make change to the order of widgets and add/remove widgets.
- Reset to Factory - This tool allows the user to amend all their customizations and revert back to the initial My OPSWAT Central Management dashboard.
- Cancel Changes - This will allow the user to discard changes made.
- Save Changes - This will allow the user to save changes made.
