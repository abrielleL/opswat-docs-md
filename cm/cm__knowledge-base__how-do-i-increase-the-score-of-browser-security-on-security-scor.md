# How do I increase the score of Browser Security on Security Score in MacOS devices?

## How to get a max score

To get the max score for this category, we need to enable Antiphishing for all the browsers on your computer.

![](https://uploads.developerhub.io/prod/97qW/xb13iw46q9uzgptffgk24p9f6tppycfs4gzns5q4j01ok7nha99w5hl7sdustwwd.png)

## How to set default browser on macOS

Go to **System Settings** to search for Default Web Browser.

![](https://uploads.developerhub.io/prod/97qW/a9ieldq02rgleuq5b8jjre9ubv499ybdxh1ooou1k776kd4ki3lh5u13bu9u1vo3.png)

## How to enable Antiphising in Chrome

Open **Chrome Browser**, go to the three dots on top right of the Chrome Browser, click Setting. Select "Privacy and Security on the left menu of Settings page, then choose "Security"

![](https://uploads.developerhub.io/prod/97qW/dgyzytp0tuyyx64cldj0rpijt6fagi2tphg3ty3inyb3b9ymuhhaff9ntvva01o3.png)

Select any protect options for Chrome browser to enable Antiphishing in Chrome

![](https://uploads.developerhub.io/prod/97qW/q9nkamy7177xjmn9d6cdkn1p2c4uxznu5tpojos4urwz9o94wk7tli0yqnwu04sd.png)

Note: This action is only valid for the dedicated profiles on Chrome. Thus, to get max score, users must enable all profiles within Chrome Browser.
