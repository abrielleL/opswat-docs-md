# Enroll MetaDefender Endpoint

View as Markdown Summarize this page Ask ChatGPT about this page Ask Claude about this page Connect your AI tool

MetaDefender Endpoint devices can be added into My OPSWAT Central Management by obtaining an installer for the MetaDefender Endpoint. Administrators can also go a step beyond and have their devices be sorted into groups via auto-assignment. For more information on device groups and auto-assignment, please use the links below:

- [Device Groups](/docs/cm/product-management/groups)
- [Auto-Assign Endpoints to a Group](/docs/cm/product-management/auto-assign-endpoints-to-a-group)

## [Enroll a device](/docs/cm/endpoint-security-solution/metadefender-endpoint#enroll-a-device)

To add devices into My OPSWAT Central Management, administrators need to do the following:

1. Log into My OPSWAT Central Management .
2. In the top-right corner of any page, select **Enroll Product**. The Enroll Product page opens.
3. In the **Add an endpoint device** card, select a group from the **Group** dropdown. Devices installed from this link are assigned to that group.

4. Select **Go to Download**. The **Download MetaDefender Endpoint** page opens.

   1. To share the download with someone else, such as the device owner, select the copy-link icon next to **Go to Download** instead.
5. Select the operating system and agent type, then download the installer.

6. On the device, run the installer with administrator privileges.

## [Next Steps](/docs/cm/endpoint-security-solution/metadefender-endpoint#next-steps)

- Review or create the policy that applies to the device's group.
- Check device posture on the Endpoint Security Dashboard.
