# What versions of Hard Disk Encryption software do you support?

> **Check Your Product:**
>
> This article applies to the current My OPSWAT Central Management solution and all component product releases deployed on Windows, macOS, Linux, Android and iOS systems.

My OPSWAT Central Management currently supports full detection of the encryption state of all hard disks, along with software and version detection for a limited selection of hard disk encryption software.

For the most up-to-date list/s of supported software, please refer to the relevant link/s below, where you can select your encryption category, before looking for the relevant vendor and product names.

|  |  |
| ---- | ---- |
| Windows | [https://software.opswat.com/OESIS_V4/Win/docs/support_charts/support_charts.html](https://software.opswat.com/OESIS_V4/Win/docs/support_charts/support_charts.html) |
| MacOS | [https://software.opswat.com/OESIS_V4/Mac/docs/support_charts/support_charts.html](https://software.opswat.com/OESIS_V4/Mac/docs/support_charts/support_charts.html) |
| Linux | [https://software.opswat.com/OESISV4/Linux/docs/support charts/support_charts.html](https://software.opswat.com/OESIS_V4/Linux/docs/support_charts/support_charts.html) |

> **Please Note:**
>
> If you do not find your hard disk encryption software or version on the list, please contact us as instructed below, so that we can add it to our list.
