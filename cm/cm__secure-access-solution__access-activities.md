# Access Activities

My OPSWAT Central Management understands the complex BYOD ownership problem in managing BYOD devices. Now, My OPSWAT Central Management uniquely addresses this problem by recording a user identity such like application username with each device they use when accessing protected applications, increasing unmanaged device control without requiring any IT infrastructure changes, network traffic manipulation, or mobile device management (MDM).

With protected apps via IdP method, you need to enable "***Allow*** My OPSWAT Central Management ***to*** ***record a user who is using a device to access an application***" option to allow My OPSWAT Central Management record users who are using devices to access protected applications when IdP forwards user authentication to My OPSWAT Central Management.

From My OPSWAT Central Management console or through [Get Access Activities](https://www.opswat.com/docs/cm/developer-guidelines/get-access-activities) API, administrators can now see who is using a device to access what application and which action My OPSWAT Central Management took for that access activities. This brings more visibility to administrators to address who is trying to access protected applications from unknown devices. By this way, administrators is easy to identify risk from unknown devices.

From My OPSWAT Central Management console, you can audit access activities by navigating to Secure Access > Activities
