# Enroll MetaDefender Endpoint

## [Add a device](https://www.opswat.com/docs/macloud-sdp/configuration---management/devices#add-a-device-into-metadefender-it-access)

Endpoint devices can be added into My OPSWAT Central Management by obtaining an installer for the MetaDefender Endpoint. Administrators can also go a step beyond and have their devices be sorted into groups via auto-assignment. For more information on device groups and auto-assignment, please use the links below:

- [Device Groups](https://www.opswat.com/docs/cm/product-management/groups)
- [Auto-Assign Endpoints to a Group](https://www.opswat.com/docs/cm/product-management/auto-assign-endpoints-to-a-group)

To add devices into My OPSWAT Central Management , administrators need to do the following:

1. Log into My OPSWAT Central Management .
2. Select the **+Enroll Product** button on the left menu.
3. Select MetaDefender Endpoint button
4. A popup will appear with downloading steps. *Note: if utilizing the auto-assignment via installation package, please refer to the auto-assignment document above.*
5. Select **Download MetaDefender Endpoint for Distribution**, and a new window will appear. Select the desired client version specific to the endpoint's operating system, as well as the type of client the endpoint needs.
6. Once completed, run the installer on the endpoint. When the installation is finished, verify that the device is present under **Inventory > Devices**.
