# File Security Solution

View as Markdown Summarize this page Ask ChatGPT about this page Ask Claude about this page Connect your AI tool

The **File Security Dashboard** provides a detailed overview of the security status and activities related to file security within the **MetaDefender Core** and **MetaDefender ICAP Server**. It includes key metrics and statistics that help in monitoring and managing the security measures effectively.

In the left navigation, select **File Security > Dashboard.**

Choose the tab you need:

- [MetaDefender Core Dashboard](/docs/cm/product-management/metadefender-core-dashboard)
- [MetaDefender ICAP Server Dashboard](/docs/cm/product-management/metadefender-icap-server-dashboard)
