# Which version of MetaDefender Endpoint supports setting for anti-phishing according to the default browser

> **Check Your Product:**
>
> This article applies to all My OPSWAT Central Management releases deployed on Windows, macOS, Linux, Android and iOS systems.

The **Default Browser** setting in your My OPSWAT Central Management Console under **Policy Management>Policies>Relevant Policy>Relevant Device Tab>Deep Compliance>Anti-Phishing,** as illustrated below, is applicable to all MetaDefender Endpoint versions and releases.

![](https://uploads.developerhub.io/prod/97qW/r9hf29gwg5ghgspdsab619l6lbe6p0q0puf8u08wydct2ilco3ew1qxo1l19q8cj.png)

While the **All Browsers** setting is applicable to all MetaDefender Endpoint releases subsequent to:

- **For Windows**
  - Persistent MetaDefender Endpoint V7.6.2209.65
  - On-demand MetaDefender Endpoint V7.3.2209.29
- **For macOS**
  - Persistent MetaDefender Endpoint V10.4.2209.18
  - On-demand MetaDefender Endpoint V10.5.2209.9

![](https://uploads.developerhub.io/prod/97qW/5ckus0226swq7l6uiq54p4ev1qltydhoclciao109m4ehpiuvh9q8uqwc5qi50em.png)
