# MSI Installation - Standalone mode

Before starting My OPSWAT Central Management On-premises installation, please make sure your server meets the [system requirements](https://www.opswat.com/docs/cm/deployment/system-requirements)

Please follow the guidelines below:

1. Install the Software Requirement in the [system requirements](https://www.opswat.com/docs/cm/deployment/system-requirements)
2. Download the package My OPSWAT Central Management  from the My OPSWAT Portal
3. Unzip the downloaded package, then run the file .msi.

![](https://uploads.developerhub.io/prod/97qW/1onn8km6yhar0a6az3jgtui460viinpucsl4gt067lbwcpfr4rknrazn55agy1xc.png)

4. An installation wizard will show up to walk you through the installation process.

![](https://uploads.developerhub.io/prod/97qW/bp04ft38fi5lshlbblmip28n8rpcupba5scnxt2waoh31lar6f7pmt6zwp1wf030.png)

5. Accept the license agreement, click Next to continue

![](https://uploads.developerhub.io/prod/97qW/ctua1orpuy40asq064yfnd44dxe36wznkb314o8n3je7i47so9hvcafs2ntttvm1.png)

6. Select "Standalone" mode → Click Next ![](https://uploads.developerhub.io/prod/97qW/n4jze60zak1dqemhive4e0945df4o87qyfhkog7b2gz2tewxza2z89enuvwzio52.png)
7. Set the port that will be used by OPSWAT Central Management. Please make sure this port is not used by any other services on your server. Click Next to continue

![](https://uploads.developerhub.io/prod/97qW/17q5ppyjrpfjyna5o3h35c58qii0wp9f61lcjwignnln4toacv7kmfseknutlphy.png)

7. Select the desired installation path. OPSWAT Central Management will be installed in the ‘MOCM’ subfolder under the chosen directory. Click Next to continue

![](https://uploads.developerhub.io/prod/97qW/505m0cb46rg3a58dql53lscecer3nuyhlb4zxuzwbkc2ujmk9s3v8wbjw2s8kn1w.png)

8. Select the desired logs path. OPSWAT Central Management will write logs in the ‘MOCM/Logs’ subfolder under the chosen directory. Click Next to continue

![](https://uploads.developerhub.io/prod/97qW/7jryjwu76vhuy7i1ylmpjt62yg4wcks3c24xy1dm272x337ri3yi300y812x26fm.png)

9. Click Install to start installing My OPSWAT Central Management

![](https://uploads.developerhub.io/prod/97qW/b481n3gr4y9o0b3l88pl4zfk03hlx53jzoa1j9s1wn9yzn14f107z2h560r36p3v.png)

10. Installation in progress. This process may take some time.

![](https://uploads.developerhub.io/prod/97qW/ej6e580k10gszzyyhalg8molc992uhfel6mto61l99ka7bc173fkd6iuv8fsgvu4.png)

11. Click Finish to complete the installation. You can check the option "Launch My OPSWAT Central Management" to launch the web management console immediately. If this is the first time you are installing My OPSWAT Central Management, the setup wizard will guide you through the initial setup.

![](https://uploads.developerhub.io/prod/97qW/af24grof5mtztxcdtunookbcm2eg5ycm034mwmd3petls9xdz2pd1jfbccv92if9.png)

12. Once installation is completed, the My OPSWAT Central Management tray icon will appear and display the server's status.

![](https://uploads.developerhub.io/prod/97qW/7acby5ruk9mj5d11zk4ag9nor6ssfqyhxf01kxhh4bd6yvjxrjvq2gevtrvp9c6k.png)
