# How do I increase the score of Vulnerabilities on Security Score Windows devices?

![](https://uploads.developerhub.io/prod/97qW/dmeltmujxkxvushy2wk3yz9ua7ult0ijo1itv229q4yw1u72bzi5v08bduwwfmrq.png)

## How to get the max score:

**Step 1**: Click “here” on the Vulnerable Applications popup to go to the  Vulnerable Application page

**Step 2**: Upgrade (via MetaDefender Endpoint UI or manual updates, as-needed) or Uninstall the apps that have CVEs

**Step 3**: Go back to the Security Score page and Refresh the Security Score
