# Device Enrollment FAQ

#### Frequently Asked Questions (FAQs)

**Question**: What file formats are supported?

- **Answer:** Currently, only .xlsx files are supported. You may see an alert if you attempt to import a different file type.

**Question:** Can I re-enroll an managed Device?

- **Answer:** No,  the Device Enrollment feature is only applicable to Unmanaged Devices. If you attempt to re-enroll a Managed Device, you will receive an alert message:
