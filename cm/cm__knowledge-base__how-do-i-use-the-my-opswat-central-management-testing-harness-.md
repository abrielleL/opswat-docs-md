# How do I use the My OPSWAT Central Management Testing Harness?

> **Check Your Product:**
>
> This article applies to the current My OPSWAT Central Management oAuth Portal and MetaAccess API.

The **My OPSWAT Central Management** **API Testing Harness** is accessible via the My OPSWAT Central Management oAuth Portal,

1. Log into the My OPSWAT Central Management console and click your account **Name** in the top, right-hand corner of the screen, select **OAuth Application** menu to access oAuth Portal.
2. Click the **Testing Harness** on the left navigation. Note that if you have not registered any oAuth application yet, you need to **Register New Application** firstly before you can test any oAuth APIs
3. Select an API you would like to test and fill required parameters for that API. You can refer the API details by clicking on the API documentation link on the screen.
4. Click Send.
5. If it's sent successfully, you will see the API's response
