# Enable Secure Access on My OPSWAT Central Management account

This step tells My OPSWAT Central Management if you want to enforce device posture check for every request which is forwarded from an IdP when a user accesses to a protected application. If you have not enabled Secure Access, My OPSWAT Central Management just simply forwards the SAML authentication from IdP to the specified application (service provider) in the request.

To enable Secure Access,

1. Log into the My OPSWAT Central Management console as an administrator
2. Navigate to **Secure Access** and then **Protected Apps**
3. Check "**Enable Secure Access**"
4. Enter your PIN to confirm the change
