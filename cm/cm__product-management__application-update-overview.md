# Overview

**Remote Application Update** is a scalable solution that keeps your OPSWAT instances running the latest, most secure software versions.

With this feature, you can reduce administrative burden of manual update, ensure consistency across your entire fleet, and respond rapidly to new version releases from a single pane of glass.

## Supported Products

Remote Application Update supports the following products:

- **MetaDefender Kiosk Windows**:  Version 4.8.0.xxxx or later
- **MetaDefender Kiosk** **Hardened Image**:  Version 4.8.3.xxxx or later
- **MetaDefender Core**: Version 5.20.x or later. Only supports standalone mode.
- **MetaDefender Industrial Firewall**: Version 3.4.1.xxxx or later. The Automatic Application Upgrade setting must be enabled within the individual MetaDefender Industrial Firewall instance.
  - OPSWAT Industrial OS (x86_64): version 3.4.1.xxxx or later
  - OPSWAT Industrial OS (ARM64): version 3.5.0.xxxx or later
  - MetaDefender Industrial Firewall Toolkit: extended options supported

## Key Capabilities

- [Update Application](https://www.opswat.com/docs/cm/product-management/update-application): Initiate and configure update jobs for one or more instance.
- [Roll Back Application](https://www.opswat.com/docs/cm/product-management/creating-rollback-job): Revert specific instances to their previous stable version (currently exclusive to MetaDefender Kiosk).
