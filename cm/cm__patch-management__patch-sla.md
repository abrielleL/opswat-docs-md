# Patch SLA

**Patch Management SLA** (Service-Level Agreement) lets you set timeframes for how quickly patches must be applied, based on severity level. Track compliance in real time, identify overdue updates, and receive automatic alerts when a patch misses its due date

## Configure Patch SLA

1. Open the **Patch Dashboard**
2. On the **SLA Compliance** widget, select the gear icon. This is visible only to administrators with write access to the Patch Management dashboard
3. In the **Update Service-Level Agreement** dialog, set the maximum number of days (1 to 365) for each severity level

## Track Patch SLA

Use the Patch Dashboard to quickly identify patches that are approaching or exceeding your remediation targets.

1. Open** Patch Dashboard**
2. Use the following widgets to assess patch SLA compliance:

| Goal | Widgets To Look At | What It Tells You |
| ---- | ---- | ---- |
| Get an overall SLA compliance snapshot | SLA Compliance ![](https://uploads.developerhub.io/prod/97qW/h87xiuxtvg3ry9caf2coca5por7nodpmcimlz08ljogy065xq62zqhqco45woar5.png) | Shows how many missing patches are Overdue versus Due Soon, helping you quickly assess compliance status |
| Find your most urgent patching risks | By SLA Due Dates ![](https://uploads.developerhub.io/prod/97qW/esv00egijxc8f5vytpj2ioaf3c0q89i9bctqxno60jrr5jmosuguxddeigi8asej.png) | Breaks down missing patches by severity and SLA status so you can identify overdue items and remediation priorities |

3. To investigate further, **select a widget entry** to open the corresponding patch list.
4. From the **Patches** page, review affected devices, assess risk, and approve or deploy updates as needed.

Next Step See [Manage Missing Patches and Outdated Applications ](https://www.opswat.com/docs/cm/patch-management/manage-missing-patches)for instructions on reviewing, approving, and deploying patches.

## Get Notified on Patch SLA

Patch notifications can alert in real time when **SLA deadline approaching** and **SLA deadline passed**.

Refer to [Patch Notification](https://www.opswat.com/docs/cm/patch-management/patch-notification) guidelines for detailed instruction on creating patch SLA notification.
