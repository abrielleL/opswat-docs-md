# Bulk Action: Assign Endpoints to Groups

This document covers the options that My OPSWAT Central Management provides for bulk group assignment for endpoints. This feature can be found by navigating to **Inventory > Device Groups >** and selecting an endpoint group you would like to update.

Administrators are able to move endpoints in bulk to groups in My OPSWAT Central Management by utilizing the **Bulk Group Assignment**. To proceed with bulk group assignments, please follow the following instructions:

- Navigate to  **Inventory > Groups >** and selecting an endpoint group you would like to perform the bulk assignment.
- Select the (⋮) in the right hand corner of the device group page, and select **Bulk Group Assignment**.
- A pop-up window will appear. Select the type of sample list you want to download (based on device ID or hostname) and select the **here** button to download the sample device list.
- This will prompt a CSV download.
- Open the CSV file and input the relevant data and save the changes.
- Navigate back to the pop-up window and upload the CSV file with your changes.
- Select **Add Devices to Group**.
- All devices should appear in the device group immediately.

For other methods of group assignment, both manual and automatic, please review [Auto-Assign Endpoints to a Group](https://www.opswat.com/docs/cm/product-management/auto-assign-endpoints-to-a-group)
