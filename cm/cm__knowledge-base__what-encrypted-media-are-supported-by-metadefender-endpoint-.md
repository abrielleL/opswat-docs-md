# What encrypted media are supported by MetaDefender Endpoint?

> **Check Your Product:**
>
> This article applies to all MetaDefender Endpoint releases deployed on Windows, macOS, Linux, iOS and Android systems.

Encrypted media pose a unique challenge to the MetaDefender Endpoint, and while Client supports certain encrypted media, we occasionally encounter pieces of hardware that cannot be fully supported by the product.

Below is a list of known encrypted media that are supported, and have been rigorously tested by the MetaDefender Endpoint development team.

| **Media** | **Minimum Client Version** |
| ---- | ---- |
| Microsoft BitLocker | 7.6.304.0 |
| Kingston DataTraveler 4000 | 7.6.349.0 |
| Kingston DTL GP3 | 7.6.349.0 |
| Kanguru Defender Elite 200 | 7.6.349.0 |
| Kanguru Defender Manager Elite | 7.6.424.0 |

> **Pro Tip:**
>
> If your encrypted media’s functionality resembles that of any of the media listed above, there is a likelihood that MetaDefender Endpoint will support it.
>
> If you require support for encrypted media that are dissimilar to those aforementioned, please contact OPSWAT Support to submit an enhancement request.
