# Deployment for Hybrid

## Download and Install Your NAC VM

Please follow these instructions to download and configure the NAC VM.

1. Download NAC VM:
   1. Login to your **My OPSWAT Central Management**
   2. Navigate **RADIUS NAC**
   3. On **NAC Edge Deployment** tab, click on **Download OVA**
   4. Follow the instructions in the [VM Deployment Guide](https://www.opswat.com/docs/cm/secure-access-solution/cloudnac-vm-deployment-guide) to install and configure a NAC Edge instance in your virtual environment.
