# Active Directory

**Configure Active Directory in My OPSWAT Central Management:**

1. Log in to the My OPSWAT Central Management console with administrative privileges.
2. Navigate to **User Management > Active Directory**, then click the **Add New Directory** button.
3. Enter your Active Directory (AD) information, then click **Test Connection** to verify that the configuration is valid

![](https://uploads.developerhub.io/prod/97qW/gl0zi81h79xeazjdxpizxh9fwep4orxva75nk9yrcyyzupnyc1324otkl95qoz8y.png)

4. Click **Add** to save this directory.
5. To allow a directory user to log in to My OPSWAT Central Management, you must add the user to the system. If you add a group, all users within that group will also be able to log in. Navigate to **User management** > **Users and Groups**
6. Click **Create User** and select **Active Directory**

![](https://uploads.developerhub.io/prod/97qW/5tlv46se8v1wbk0pieozanx2dkl3z4raccwl2qwvl2gjof3oe0wuz4gg2im4hm2w.png)

7. To add users, select the directory and choose **User** as the type. Then, search for users within the directory and add them to the right-hand box.

![](https://uploads.developerhub.io/prod/97qW/n8pz6e1ry5vozql90ki67utbtkngquw8fdb93qtjfwqz4srabhmwvy48k401o66v.png)

8. To add groups, select the directory and choose Group as the type. Then, search for groups within the directory and add them to the right-hand box.

![](https://uploads.developerhub.io/prod/97qW/ubfzf30vcv9sodqplux8ho71nxyf7r01laqigdzzf5m33law9hhciihi1tgrxdfj.png)

9. Click **Save** to add users and groups to My OPSWAT Central Management.
10. To log in with a directory user:
    1. Go to the login page.
    2. Enter your credentials.
    3. Select the appropriate directory.
    4. Click **Sign In**.

![](https://uploads.developerhub.io/prod/97qW/amsrnfsd8mxo63ik98qtodfhnrwbjkrqrle0k8a4yh7eiqn6t41s9nnc36qo4fs1.png)
