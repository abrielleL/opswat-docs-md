# Widget Definitions

> **Info**
>
> My OPSWAT Central Management users can customize their dashboards and use any of the widgets mentioned below on any dashboard. Users are limited to a maximum of 20 widgets per page.

## Overview

- Device Information - A broad overview of critical device statistics
- Protected App Accesses - App access statistics for the last 24 hours
- Active SDP Sessions - Compliance statistics for current SDP sessions
- Advanced Malware Detection - Infection statistics for monitored devices
- 3rd-Party Vulnerabilities - Vulnerability statistics for monitored devices
- Endpoint Compliance - Risk statistics for monitored devices

## Secure Access

- Sessions Blocked by Application - Sessions blocked by application statistics
- Applications by Access - Protected applications by access mode statistics
- Blocked Sessions - Statistics on recent blocked sessions
- Total vs Blocked Session Trends - Trends of recent total vs blocked sessions
- Blocked Session Trends - Trends of recent blocked sessions

## Vulnerabilities

- Devices by Severity - Vulnerable device statistics presented by severity
- Vulnerabilities by Severity - Vulnerability statistics by severity
- Applications by Severity - Vulnerable app statistics presented by severity
- Vulnerabilities and Exposures - Exposure statistics for monitored devices
- Vulnerability Category Trends - Recent vulnerability trend statistics

## Compliance

- Device Information - A broad overview of critical device statistics
- Compliance - A broad overview of device compliance statistics
- Non-Compliant Devices - A breakdown of non-compliant devices by device type.
- Non-Compliant OS - A breakdown of non-compliant devices by operating system.
- Anti-Malware - Anti-malware statistics for monitored devices
- Encryption - Encryption statistics for monitored devices
- User Authentication - Authentication statistics for monitored devices
- Antiphishing - Antiphishing statistics for monitored devices
- Backup - Backup statistics for monitored devices
- Firewall - Firewall statistics for monitored devices
- Hard Drive - Hard drive statistics for monitored devices
- Operating System - OS statistics for monitored devices
- Custom Category - Selected categorical statistics for monitored devices
- Compliance Category Trends - Recent compliance trend statistics
- Category Trends - Statistics for user defined categories

## Threat Detection

- Active Threats - Devices with active threats statistics
- Active Threats by Group - Top 5 groups with active threats
- Repeated Threats - Devices with repeated threat statistics
- Repeated Threats by Group - Top 5 groups with repeated threats
