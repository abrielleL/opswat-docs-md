# Overview

View as Markdown Summarize this page Ask ChatGPT about this page Ask Claude about this page Connect your AI tool

**Endpoint Security** in My OPSWAT Central Management gives you real-time visibility into device health, automates vulnerability discovery, enforces endpoint compliance policies, and provides remote remediation tools across managed Endpoint.

You'll find it in the left navigation under **Solution > Endpoint Security**. It contains four sub-pages: **Dashboard**, **Regulation and Standards**, **Vulnerabilities**, and **Policies**.

## [Endpoint Security Workflow at a Glance](/docs/cm/endpoint-security-solution/endpoint-security-overview#endpoint-security-workflow-at-a-glance)

| Steps | Details |
| --- | --- |
| **Step 1: Enroll** | Enroll MetaDefender Endpoint devices into My OPSWAT Central Management by following [Enroll MetaDefender Endpoint](/docs/cm/endpoint-security-solution/metadefender-endpoint) |
| **Step 2: Assess** | Get a single view of your endpoint security posture with [Endpoint Security Dashboard](/docs/cm/endpoint-security-solution/endpoint-security-dashboard) |
| **Step 3: Enforce** | Configure [MetaDefender Endpoint Policies](/docs/cm/endpoint-security-solution/metadefender-endpoint-policies) for anti-malware engines, local firewalls, disk encryption, and browser extensions. |
| **Step 4: Remediate** | Identify unpatched operating system and application CVEs, filter by severity, and suppress approved exceptions with Allowlist CVEs. |
| **Step 5. Maintain** | Run automated full-image [Backup & Restore](https://www.opswat.com/docs/cm/product-management/backup---restore). Track device health with [Endpoint Performance Monitoring](/docs/cm/endpoint-security-solution/endpoint-security-overview#). |
