# How to allow a specific threat in My OPSWAT Central Management admin console?

1. Login to the My OPSWAT Central Management admin console.
2. Go to Policy Management and select the policy.
3. In Deep Compliance – Anti Malware, add the threat exclusion you want.

![](https://uploads.developerhub.io/prod/97qW/xf47bhd1unhruw60a30ligze11rjlm09xyfmon016rim3hfo7r6mkgzlepecudu1.png)

4. Enter the file name and hash of the threat to be excluded, then select Add.

![](https://uploads.developerhub.io/prod/97qW/pyg41h8pv6qvrogk7x97cdwyb7nqcy1d0uyvo72il4rru5vdssoq9u1kvys5cbb1.png)

5. Once all of your exclusions have been entered, select Save to save all changes to your policy.
