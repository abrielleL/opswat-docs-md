# File Security Protection

The **File Security Dashboard** provides a detailed overview of the security status and activities related to file security within the **MetaDefender Core** and **MetaDefender ICAP Server**. It includes key metrics and statistics that help in monitoring and managing the security measures effectively.

How to Access The dashboard can be accessed from the left navigation menu, in **Dashboard> File Security**

![](https://uploads.developerhub.io/prod/97qW/rk5otkxu6tk9ghqp6m2vb5a1d2q1ycqjpl5gq4w4kowfav249mu8gwlho483m16p.png)

This page serves as a central hub for monitoring and managing the security status of files within the following products:

- MetaDefender Core
- MetaDefender ICAP Server

This page allows you to **view and analyze data** from MetaDefender Core & MetaDefender ICAP Server based on specific **timeframes**. You can customize the displayed data to get insights tailored to your needs.

Here's how to use it effectively.

## **MetaDefender Core Dashboard**

### **Overview Section**

This section offers an overview of the file scanning results from all CORE instances. It includes:

- The number of CORE instances with at least one scan session**.**
- A review of the total number of processed, blocked, sanitized, and quarantined files. This information helps understand the current system load and the effectiveness of recent security scans.
- Monitoring the number of detections for various threat types, including number of detected threats, zero-day protection, adaptive sandboxing, sensitive data detection, spoofing detection, OSS vulnerabilities, insights threat intelligence, vulnerability assessment, and COO detection. This section provides insights into the system's ability to detect and prevent threats.

![](https://uploads.developerhub.io/prod/97qW/95qppkzaml23d24x8dfhkw4r80lsoy9philcg8dt7hhekh82u2vqakoh9163bth3.png)

By regularly reviewing these sections, you can maintain a robust security posture and quickly address any vulnerabilities or issues.
