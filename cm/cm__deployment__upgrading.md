# Upgrading

To upgrade your My OPSWAT Central Management instance to the latest version:

1. Manually download the latest .msi installer (available on [my.opswat.com](https://my.opswat.com/portal/home/myopswat-central-management))
2. Copy the file to the My OPSWAT Central Management instance
   1. You can RDP into the instance using your private key and download directly from [my.opswat.com](https://my.opswat.com/portal/home/myopswat-central-management) or copy the file from your host server.
3. Run the newest installer
   1. This maintains any data that was already written to the My OPSWAT Central Management Instance
