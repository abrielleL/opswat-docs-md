# Patching Tool for Downloading Patch Installer

Patching Tool allows you to download patch installers, which is useful when you need to prepare patch packages for offline environments or manually upload patch installers to My OPSWAT Central Management On-Premises.

For installation instructions, command-line options, supported CSV formats, package generation, and detailed usage examples, see:

[**Patching tool for downloading patch installer (MetaDefender Endpoint)**](https://www.opswat.com/docs/mdendpoint/patch-management-solution/patching-tool-for-downloading-patch-installer)

This document provides the complete reference for configuring and using the patching tool.
