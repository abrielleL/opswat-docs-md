# What PDF file annotations are Supported/Non-Supported by MetaDefender Core’s Deep CDR?

This article applies to all MetaDefender Core V4 and V5 releases deployed on Windows or Linux systems.

**MetaDefender Core Deep CDR’s annotation support is clarified in the table below:**

| **Supported** | **Non-Supported** |
| --- | --- |
| *Link, File Attachment, 3D,* and *Widget*. | Text, FreeText, Line, Square, Circle, Polygon, PolyLine, Highlight, Underline, Squiggly, StrikeOut, Stamp, Caret, Ink, Popup, Sound, Movie, Screen, PrinterMark, TrapNet, Watermark, and Redact. |

**The relationship between MetaDefender Core’s configurations and annotations is outlined in the table below:**

| **Configuration** | **Annotation** |
| --- | --- |
| Remove Hyperlink | Remove Link annotation |
| Remove Embedded Object | Remove File Attachment and 3D annotation |
| Remove Form | Remove Widget annotation |

Support:

For further assistance regarding **MetaDefender Core Deep CDR**’s supported/non-supported **PDF Annotations**, please follow these instructions on [How to Create Support Package With Bundle Tools?](/docs/mdcore/v5.21.0/troubleshooting/how-to-create-support-package-), before [creating a support case or chatting with our support engineer](https://my.opswat.com/portal/support).
