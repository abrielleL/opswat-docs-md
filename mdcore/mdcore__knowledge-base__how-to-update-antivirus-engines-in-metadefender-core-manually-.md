# How to Update Antivirus Engines in MetaDefender Core Manually?

This KB's purpose is a POV of the user on how to download the Antivirus engine individually or a specific selection that the user wants.

### [Online download](/docs/mdcore/knowledge-base/how-to-update-antivirus-engines-in-metadefender-core-manually-#online-download)

1. One of the issues that we commonly see is that the engine is unable to be uploaded, or a network error, which results in Metascan features missing engines. Specifically for this case, which is the **AhnLab** and **Avira**.

Ahn Lab and Avira missing

2. We will use the online download option, which is to click on the Upload all button to retrieve all the engines that were missing or unfinished downloads.

Step 1

3. After hitting the button, MetaDefender Core will automatically find a suitable engine and download it to the Metascan tab.

Step 2

### [Offline download](/docs/mdcore/knowledge-base/how-to-update-antivirus-engines-in-metadefender-core-manually-#offline-download)

1. For the offline download, we will choose the Antivirus engine that is the same as the online downloader, which is **AhnLab** and **Avira**.

Ahn Lab and Avira missing

2. In this situation, we will utilize the tool MetaDefender Update Downloader. Please follow the link on how to download the tools here: [How do I deploy MetaDefender Core to an offline Windows environment?](/docs/mdcore/knowledge-base/how-do-i-deploy-metadefender-core-to-an-offline-windows-envir)

3. From this step, we choose the option that are needed from the tab and click on “Download Package” to download the zip that contains all the package we need for the Antivirus engines.

Download the package zip

4. From the Zip that was downloaded, please extract it and prepare for uploading the packages to the MetaDefender Core. From the folder, the Engine and the databases of the engine can be seen from the folder.

AhnLab and Avira packages

5. Navigate back to the MetaDefender Core Module tab, click on the “Upload Packages”. And manually upload 1 engine at a time as follows from the image below.
