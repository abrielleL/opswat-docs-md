# QR code sanitization

View as Markdown Ask ChatGPT about this page Ask Claude about this page Connect your AI tool

To enable QR code sanitization, please check "Sanitize QR code" the image configuration

**Supported file type:** JPG, PNG, BMP, MS Office

**Limitation:**

- Style or rotated QR codes are changed to normal QR code.
