# Are MetaDefender Core version upgrades automatic?

View as Markdown Ask ChatGPT about this page Ask Claude about this page Check Your Version:

This article applies to all MetaDefender Core V5 releases deployed on Windows or Linux systems.

No.

New versions of the MetaDefender Core system must be manually installed. Manual installation allows users to follow prompts and engage the necessary customizations along the way.

V5 releases allow for quick manual installation of new versions directly over existing installations.

As a best practice policy, we urge clients to perform a disk file snapshot of their machine prior to upgrade (for systems deployed on virtual machines), or make use of our built-in **Config Export/Import** feature (for all systems, virtual or physical).

The **Config Export/Import** feature, as illustrated in the screenshot below, allows users to preserve their configurations through the upgrade process. [Read This](/docs/mdcore/v5.22.1/operating/import-export-configuration) learn more.

Please Note:

If you are upgrading from a V4 or V5 release, visit [Product Upgrading](/docs/mdcore/v5.22.1/installation/upgrading-metadefender-core) and follow the links to install your new version.

Pro Tip:

OPSWAT highly recommends that users upgrade to the latest version of MetaDefender Core. Current versions incorporate state-of-the-art features and necessary bug fixes, and are available for all license holders to download.

Updates of specific features within the MetaDefender Core system (such as scan engines) can be configured to either **Internet** (**Automatic**), **Local** (**Automatic**) or **Manual**.

Visit our [Release Note](/docs/mdcore/v5.22.1/release-notes/release-notes) section to learn more about feature updates and bug fixes.
