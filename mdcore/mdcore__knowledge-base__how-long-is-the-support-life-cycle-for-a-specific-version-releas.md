# How long is the support lifecycle for a specific version of MetaDefender Core?

View as Markdown Ask ChatGPT about this page Ask Claude about this page Check Your Version:

This article applies to all MetaDefender Core V4 and V5 releases deployed on Windows and Linux systems. Version 3 and prior releases are no longer under support.

OPSWAT provides support on each release of MetaDefender Core for 18 months after the publication of the **following** release of the product. So, once a new release is published, you have 18 more months of support on the previous release.

Keep in mind, however, that bug fixes and enhancements are applied only to the next release of a product, not to the current release or historical releases - even when those releases are still under support.

In some cases, hot-fixes can be provided for the current release of the product, and then incorporated as regular fixes in the next release.

Pro Tip:

OPSWAT highly recommends that users regularly upgrade to the latest version of MetaDefender Core and not wait until the end of a release’s support cycle.

Please take note that running an unsupported product version may result in engine failure at any time.

Current versions incorporate state-of-the-art features and necessary bug fixes, and are freely available for all license holders to download.

To upgrade, follow these steps:

1. Browse [Release notes](/docs/mdcore/release-notes/release-notes) for details on the latest MetaDefender Core version release.
2. Visit [My OPSWAT](https://my.opswat.com/) to download a new version under the relevant package license.

If you are upgrading from a V4 or V5 release, visit [Product Upgrading](/docs/mdcore/installation/upgrading-metadefender-core) and follow the links.

## [How can I check the support lifecycle for a specific MetaDefender Core version?](/docs/mdcore/knowledge-base/how-long-is-the-support-life-cycle-for-a-specific-version-releas#how-can-i-check-the-support-lifecycle-for-a-specific-metadefender-core-version)

To check the release and end-of-life information for a specific MetaDefender Core version:

1. Sign in to [My OPSWAT](https://my.opswat.com/portal/home).
2. Go to **Product Downloads**.
3. Select **MetaDefender Core**.
4. Click **Download**.
5. Enable **Archived** to display previous MetaDefender Core releases.
6. Select the version you want to check and review the version information displayed on the page, including its release and end-of-life information.
