# Data Retention

View as Markdown Ask ChatGPT about this page Ask Claude about this page

Clean up settings are accessible under **Settings > Data retention** after successful login.

Info

Data marked as deleted in the MetaDefender Core database still occupies the data storage, and shall be targeted for the data retention.

Warning

Setting the clean up value to off can have performance penalty.
