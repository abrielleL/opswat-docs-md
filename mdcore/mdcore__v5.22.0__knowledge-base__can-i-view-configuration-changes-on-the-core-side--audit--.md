# Can I view configuration changes on the Core side (audit)?

This article applies to all MetaDefender Core V4 and V5 releases deployed on Windows and Linux systems.

Admin users are able to view all configurations that have taken place on the core side via the History\Configuration History tab, this can be found on the Core console.

There is also a filter option on the configuration page to allow for a more granular search regarding the time frame.
