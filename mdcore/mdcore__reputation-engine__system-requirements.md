# System requirements

## [Dependencies](/docs/mdcore/reputation-engine/system-requirements#dependencies)

### [Windows dependencies](/docs/mdcore/reputation-engine/system-requirements#windows-dependencies)

- [Visual C++ Redistributable for Visual Studio](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) version 14.38 or higher.
