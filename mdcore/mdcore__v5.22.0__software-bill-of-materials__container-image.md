# Container image

Support a .tar input file which is generated from **docker save** command

Support OS libraries in

- Alpine Linux
- RedHat
- CentOS
- Rocky
- Oracle Linux
- Ubuntu
- Debian
- SUSE
- Amazon Linux 2023
