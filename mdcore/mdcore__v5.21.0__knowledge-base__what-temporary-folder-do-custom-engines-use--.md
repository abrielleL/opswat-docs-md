# What temporary folder do Custom Engines use ?

This article applies to all MetaDefender Core V4 and V5 releases deployed on Windows systems.

Currently, there are six **Custom Engines** which use **C:\Windows\temp** as a temporary folder, instead of the **Metadefender Core** folder.

These Custom Engines are:

- Filseclab
- Huorong
- Windows Defender
- Netgate
- Systweak
- Emsisoft

Support:

For further assistance regarding **Custom Engine** temporary folders, please follow these instructions on [How to Create Support Package With Bundle Tools?](/docs/mdcore/v5.21.0/troubleshooting/how-to-create-support-package-), before [creating a support case or chatting with our support engineer](https://my.opswat.com/portal/support).
