# Does installing an antivirus impact a containerized deployment?

Both Docker and Kubernetes deployments of MetaDefender Core use storage internal to their containers for the temporary files generated during the scanning process. For this reason, installing any form of antivirus or real-time protection solution on the host operating system will **not** have any impact on the operation of MetaDefender Core.
