# Mark Sanitization Result as Skipped

View as Markdown Ask ChatGPT about this page Ask Claude about this page

Users can configure to mark Sanitization results with certain categories as Skipped instead of Failure.

To mark sanitization result as Skipped, enable **Mark Categories as Skipped** under **Workflow Management> Workflows > Workflow Name > Deep CDR > Advanced configuration > General Configuration.**
