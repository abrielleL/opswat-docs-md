# Can you import configuration settings from the latest version to the previous version of Core?

View as Markdown Ask ChatGPT about this page Ask Claude about this page Check Your Version:

This article applies to all MetaDefender Core V4 and V5 releases deployed on Windows/Linux systems.

### [Summary](/docs/mdcore/v5.22.1/knowledge-base/can-you-import-configuration-settings-from-the-latest-version-to#summary)

Importing configuration settings from a newer version (e.g., **5.14.2**) of MetaDefender Core into a previous version (Example: **5.9 or below**) may lead to the following errors:

**Error 1:** `Invalid configuration file`.

**Error 2:** `Configuration import failed.`

**OR**

### [Solution:](/docs/mdcore/v5.22.1/knowledge-base/can-you-import-configuration-settings-from-the-latest-version-to#solution)

It is recommended to **upgrade MetaDefender Core to the latest version** before importing configuration settings. Each new version of Core introduces updated schemas and feature support, which may not be backward-compatible with older versions.
