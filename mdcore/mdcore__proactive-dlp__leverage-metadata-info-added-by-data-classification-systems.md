# Leverage metadata info added by data classification systems

Metadata can provide information that is useful for classifying the file sensitivity. There are several systems that automatically categorize documents using custom metadata or document properties, such as Windows Azure Information Protection, Titus, etc. These systems add specific information to files’ properties demonstrating how confidential the documents are. Proactive DLP now can read files’ properties and block the sensitive items based on rule configurations.

**To set the detection:**

- *Workflow Management > Workflows > Workflow name > Proactive DLP > Check for metadata*

_ _

Supported file types: pdf, xls, xlsx, MS Excel XML, doc, docx, MS Word XML, ppt, pptx, rtf, bmp, jpg, png, gif, tiff
