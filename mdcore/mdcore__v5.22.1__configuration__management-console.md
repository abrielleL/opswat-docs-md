# Management Console - Login

View as Markdown Ask ChatGPT about this page Ask Claude about this page

The management console is available at: http://<MetaDefender Core Server>:<port> where <MetaDefender Core Server> is the name or IP address of the system where MetaDefender Core is installed. For example: <http://localhost:8008>

The "Forgot Password" feature requires authentication via email, and force the affected user to change their password at the first login time for security reason. More details at [Password Recovery](/docs/mdcore/v5.22.1/configuration/password-recovery).

Therefore, it is mandatory for MetaDefender Core's administrators to follow steps at [Email Configuration](/docs/mdcore/v5.22.1/configuration/email-configuration) and ensure all SMTP configurations set properly beforehand.
