# Are MetaDefender Core v5 upgrades free?

This article applies to all active-license MetaDefender Core releases deployed on Windows or Linux systems.

Yes.

The latest version of MetaDefender Core is free for all license holders to download and run.

In fact, OPSWAT recommends that you upgrade to the latest release as soon as possible, so that you can benefit from, state-of-the-art features, necessary bug fixes and ongoing support ([Read This](/docs/mdcore/v5.22.0/knowledge-base/how-long-is-the-support-life-cycle-for-a-specific-version-releas)).

If you are interested in upgrading, please:

1. Browse our [Release Notes](/docs/mdcore/v5.22.0/release-notes/release-notes) to view current and prior versions, comparisons and notes.
2. Visit the [My OPSWAT](https://my.opswat.com/home/metadefender-core) to download the latest version of MetaDefender Core.
3. Finally, check our [Upgrade Guide](/docs/mdcore/v5.22.0/installation/upgrading-metadefender-core) and follow the links to install.

Support:

If you are a **MetaDefender Core Custom** customer, OPSWAT highly recommends that you contact OPSWAT Support for expert guidance through the upgrade process. [Creating a support case or chatting with support engineer](https://my.opswat.com/portal/support) today to get in touch with the OPSWAT team.
