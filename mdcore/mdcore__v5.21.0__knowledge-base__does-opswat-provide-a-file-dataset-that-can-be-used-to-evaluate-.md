# Does OPSWAT provide a file dataset that can be used to evaluate MetaDefender Core's capabilities?

We do not offer pre-prepared test files for evaluating **MetaDefender Core's** capabilities. However, you may obtain safe, non-malicious test files from reputable third-party sources that specialize in antivirus and network performance testing. These files can be found through trusted file repositories available online.

If you are looking to test the malware detection capabilities, we recommend using the **EICAR test file**, which is a widely recognized standard for antivirus testing.

You can download the **EICAR test file** from the official **EICAR website**: 🔗 [Download Anti Malware Testfile - EICAR](https://www.eicar.org/download-anti-malware-testfile/)

⚠️ **Disclaimer:** The use of third-party test files is **at your own discretion**. Please ensure compliance with your organization’s security policies before downloading and using test files.
