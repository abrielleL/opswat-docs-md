# CIS Level 2 - Windows Guidelines

### [Setup](/docs/mdcore/v5.21.0/installation/cis-level-2---windows-guidelines#setup)

Windows version has been tested: Windows Server 2022

We use the image available on AWS: [CIS Hardened Image Level 2 on Microsoft Windows Server 2022](https://aws.amazon.com/marketplace/pp/prodview-lhbxwzmvsawbw#:~:text=This%20product%20has%20charges%20associated,best%20practice%20for%20secure%20configuration.)

This image has been hardened CIS Level 2

When using the image above, we can find the CIS report already available at `C:\CIS_Hardening_Reports\`

`Base_CIS-CAT_Report.html` - Base report, the report before applying CIS - meet 21% CIS points

`CIS-CAT_Report.html` - CIS report, the report after applying CIS - meets 97% CIS points
