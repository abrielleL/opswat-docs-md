# Overview

View as Markdown Ask ChatGPT about this page Ask Claude about this page Info

Proactive DLP requires separate licensing for MetaDefender to enable this module.

With Proactive DLP module, MetaDefender can detect and then block or prevent and then allow data transferring between networks. Here are the details functions for each approach you have chosen.

## [Detect and then block approach](/docs/mdcore/v5.22.1/proactive-dlp/user-guide#detect-and-then-block-approach)

- [Detect Sensitive Information](/docs/mdcore/v5.22.1/proactive-dlp/detect-sensitive-information)

## [Prevent and then allow approach](/docs/mdcore/v5.22.1/proactive-dlp/user-guide#prevent-and-then-allow-approach)

- [Redact Sensitive Information](/docs/mdcore/v5.22.1/proactive-dlp/redact-sensitive-information)
- [Watermark Files](/docs/mdcore/v5.22.1/proactive-dlp/watermark-files)
- [Remove Metadata](/docs/mdcore/v5.22.1/proactive-dlp/remove-metadata)

## [General configuration](/docs/mdcore/v5.22.1/proactive-dlp/user-guide#general-configuration)

**System requirement:**

- Windows version

  - Microsoft Visual C++ 2017 Redistributable Package
  - [.NET 8 dependencies](/docs/mdcore/v5.22.1/knowledge-base/how-to-install-net-8-runtime-dependencies-on-Linux-Distribu)
  - CPU must support [AVX2](https://en.wikipedia.org/wiki/Advanced_Vector_Extensions) and [SSE4.1](https://en.wikipedia.org/wiki/SSE4) instruction set to use OCR feature
- Linux version:

  - mscorefonts
  - [.NET 8 dependencies](/docs/mdcore/v5.22.1/knowledge-base/how-to-install-net-8-runtime-dependencies-on-Linux-Distribu)
  - CPU must support [AVX2](https://en.wikipedia.org/wiki/Advanced_Vector_Extensions) and [SSE4.1](https://en.wikipedia.org/wiki/SSE4) instruction set to use OCR feature
