# Does Deep CDR support sanitizing split archives?

This article applies to all MetaDefender Core V4 and V5 releases deployed on Windows and Linux systems.

Currently Deep CDR only supports sanitizing split CAB archives fully. While other split archives are supported for extraction and AV engine scanning (ZIP, RAR and TAR), Deep CDR does not have the capability to sanitize any files contained in these types of split archives at this time.
