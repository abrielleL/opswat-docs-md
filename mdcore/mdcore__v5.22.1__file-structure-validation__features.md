# Features

View as Markdown Ask ChatGPT about this page Ask Claude about this page

File Structure Validation performs the following functions in a MetaDefender Core™ workflow. Each one is configured on the File Structure Validation tab of the workflow, and each can be scoped per file type.

- Structure validation: Checks the file against its format specification and marks the structure valid or invalid

- Object extraction and routing: Extracts the objects in the file and sends them to downstream engines in a workflow

- Rule-based blocking: Blocks on a built-in object class, or on a custom JSON condition matched against object attributes

- Polyglot detection: Reports files that carry the signatures of more than one format

- Format-specific validation: XSD schema for XML.
