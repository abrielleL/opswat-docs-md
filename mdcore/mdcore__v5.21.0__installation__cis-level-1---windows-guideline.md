# CIS Level 1 - Windows Guidelines

### [Setup](/docs/mdcore/v5.21.0/installation/cis-level-1---windows-guideline#setup)

Windows version has been tested: Windows Server 2022 and 2025

We use the image available on AWS: [CIS Hardened Image Level 1 on Microsoft Windows Server 2025](https://aws.amazon.com/marketplace/pp/prodview-okv4xiseyoaj4?sr=0-1&ref_=beagle&applicationId=AWSMPContessa)

This image has been hardened CIS Level 1

When using the image above, we can find the CIS report already available at `C:\CIS_Hardening_Reports\`

`Base_CIS-CAT_Report.html` - Base report, the report before apply CIS - meet 22% CIS points

`CIS-CAT_Report.html` - CIS report, the report after apply CIS - meet 97% CIS points
