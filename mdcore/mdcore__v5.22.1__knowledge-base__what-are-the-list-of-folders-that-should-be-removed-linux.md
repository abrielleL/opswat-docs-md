# What are the List of folders that should be removed after MetaDefender Core uninstallation on Linux?

View as Markdown Ask ChatGPT about this page Ask Claude about this page Check Your Version:

This article applies to all MetaDefender Core V4 and V5 releases deployed on Linux systems.

Please find below the list of folders that should be removed after performing a clean uninstallation of MetaDefender Core on Linux

List of foldersCopy/var/lib/ometascan
/var/log/ometascan
/var/tmp/ometascan
/var/run/ometascan
/usr/lib/ometascan
/run/ometascan
/etc/ometascanSupport
