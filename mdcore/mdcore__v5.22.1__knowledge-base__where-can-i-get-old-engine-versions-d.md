# Where can I get old engine versions?

View as Markdown Ask ChatGPT about this page Ask Claude about this page Check Your Version:

This article applies to all MetaDefender Core V4 and V5 releases deployed on Windows or Linux systems.

Using older engine versions is **not recommended**, as they lack the latest features, detection capabilities, and security patches for third-party dependencies.

**Exceptions:**

- **Legacy OS compatibility**: If MD Core runs on an unsupported OS, an older engine version may be required and pinned to prevent auto-updates until an upgrade is possible.
- **Known issues in latest version**: If the latest engine has a confirmed issue with no available fix, a temporary rollback to an older version is acceptable.

Older versions should only be used temporarily. Upgrade to the latest supported version as soon as possible. If you need to **download previous versions** of the following engines:

- **File Type Engine**
- **Archive Engine**
- **Deep CDR Engine**
- **DLP Engine**
- **SBOM Engine**
- **COO Engine**

Please [**contact the OPSWAT Support Team**](https://my.opswat.com/support) for access to the installation files and further instructions.
