# Settings for My OPSWAT Central Management

## [Synchronized configuration interval](/docs/mdcore/configuration/my-opswat-configuration#synchronized-configuration-interval)

Administrator can adjust the synchronization interval between MetaDefender Core (MD Core) and My OPSWAT Central Management (MOCM) in order to reduce aggressive traffic to MOCM and lower resource usage on MD Core.

## [Enrollment URL Allowlist](/docs/mdcore/configuration/my-opswat-configuration#enrollment-url-allowlist)

To enhance security, the system administrator can configure an allowlist of enrollment URLs. Once configured, MD Core will allow enrollment in MOCM only through URLs that are included in the allowlist.
