# Processing history - search by user

View as Markdown Ask ChatGPT about this page Ask Claude about this page

Processing history supported for search by user.

Please select Search box -> User

After that, please type user-name in the search box and hit Enter

For searching the scan request that has been scanned by "Anonymous" user, please type "@" for searching them
