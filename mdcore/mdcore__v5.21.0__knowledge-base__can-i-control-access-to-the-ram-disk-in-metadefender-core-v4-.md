# Can I control access to the RAM disk in MetaDefender Core v5?

This article applies to all MetaDefender Core V4 and V5 releases deployed on Windows systems.

Yes.

You can set security permissions for the RAM disk just like a regular hard disk.

To do so, right-click on the **RAM Drive**, select **Properties**, and then navigate to the **Security** tab to access security permissions for that drive.

Support:

If you have followed all of the steps above but are still unable to set the desired **RAM Drive** security permissions, please follow these instructions on [How to Create Support Package With Bundle Tools?](/docs/mdcore/v5.21.0/troubleshooting/how-to-create-support-package-), before [creating a support case or chatting with our support engineer](https://my.opswat.com/portal/support).
