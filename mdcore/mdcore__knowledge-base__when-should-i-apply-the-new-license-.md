# When should I apply the new license?

View as Markdown Ask ChatGPT about this page Ask Claude about this page

**Check Your Version:**

This article applies to all OPSWAT Metadefender products with a License key on Windows and Linux systems.

## [**Overview**](/docs/mdcore/knowledge-base/when-should-i-apply-the-new-license-#overview)

You may activate your new renewal license (activation key) **before the current license expires**, once provided by OPSWAT.

In many cases, you will be provided the renewal license key **several weeks prior to the expiration of the existing license**. Activating the new license key in advance helps to ensure **continuous operation and prevents any potential service disruption**.

## [**Applying the new license**](/docs/mdcore/knowledge-base/when-should-i-apply-the-new-license-#applying-the-new-license)

Please find the license documentation for the product at <https://www.opswat.com/docs>

For online activation, please hit activate license and paste the key.

For offline activation, please follow the steps provided on the screen.

## [**When to Use “Deactivate”**](/docs/mdcore/knowledge-base/when-should-i-apply-the-new-license-#when-to-use-deactivate)

In most cases, you do not need to deactivate the existing license before applying the new one.

However, if the system’s network configuration has changed such as the MAC address, there will be a new deployment ID, you may need to select Deactivate before activating the new license.

If you encounter an activation error:

1. Click Deactivate.
2. Repeat the activation process using the new license key.
3. If you continue to encounter an error, please contact OPSWAT support.
