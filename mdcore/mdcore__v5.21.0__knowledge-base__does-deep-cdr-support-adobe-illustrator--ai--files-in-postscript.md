# Does Deep CDR support Adobe Illustrator (AI) files in PostScript format?

This article applies to all MetaDefender Core releases deployed on Windows and Linux systems.

### [Answer:](/docs/mdcore/v5.21.0/knowledge-base/does-deep-cdr-support-adobe-illustrator--ai--files-in-postscript#answer)

No, Deep CDR does not support AI files in PostScript format.

Adobe Illustrator (AI) files can be saved or exported in two formats:

✅ **AI file in PDF format**: This file format is essentially a PDF that contains vector graphics and design elements created using Adobe Illustrator. It is widely used for sharing and viewing vector designs while retaining high quality.

❌ **AI file in PostScript format**: This file format contains vector data and design elements described in the PostScript language, which is primarily intended for high-quality printing.

In Deep CDR, only **AI files in PDF format** are supported. Due to the nature of the PostScript format, AI files in PostScript format are not compatible with the Deep CDR engine.

For the complete list of supported file types for DeepCDR, please refer to the following article: [Supported File Types](/docs/mdcore/v5.21.0/deep-cdr/supported-file-types)
