# Supported file types

The File Type Verification engine enables organizations to evaluate and process files based on their true file type rather than relying on file extensions, which can be easily spoofed. This capability allows security teams to enforce granular policies for high-risk formats, such as executables (EXEs), and take proactive measures to block potentially malicious content. For example, files with mismatched types and extensions (e.g., an EXE file masquerading as a TXT) can be automatically flagged or blocked.

The engine supports accurate identification of thousands of known file formats. When a file’s type cannot be conclusively determined, it is classified as binary or text and scanned accordingly to maintain inspection depth and reduce blind spots. This approach strengthens defenses against file-based threats and ensures consistent enforcement of security policies.
