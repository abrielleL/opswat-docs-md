# What operating system patches should be applied to the system hosting MetaDefender Core?

This article applies to all MetaDefender Core V4 and V5 releases deployed on Windows or Linux systems.

The operating systems in OPSWAT's labs are kept updated with the latest patches. As a result, MetaDefender Core is tested for use with only optimized (patch-updated) operating systems.

Pro Tip:

MetaDefender Core does not require specific Windows patches to be operational, but it is best practice to patch the system as soon as possible to avoid security vulnerabilities.

OPSWAT highly recommends that you keep the operating system hosting MetaDefender Core completely updated with the latest OS version updates, patches and bug fixes.

Support:

If your **Operating System** is fully updated but MetaDefender Core is not run optimally, please follow these instructions on [How to Create Support Package With Bundle Tools?](/docs/mdcore/v5.21.0/troubleshooting/how-to-create-support-package-), before logging a [Support Case](https://my.opswat.com/portal/support) with the OPSWAT team.
