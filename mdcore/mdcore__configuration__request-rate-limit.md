# Request Rate Limit

Since version 5.13.0, MetaDefender Core supports rate limiting for more API calls. This feature is not enabled by default.

To enable Request Rate Limit,

1. Go to **Settings** -> **Security** page

2. Hit **Details** to setup

3. Hit **Save** to complete. It takes MetaDefender Core a few seconds to apply the new settings.

Warning

It may take MetaDefender Core up to 30 seconds to apply the settings. During this time, MetaDefender Core may not respond.
