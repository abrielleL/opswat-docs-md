# Change user password

The current user can change their own password, the option could be found under their username on the top right

Important notes

Warning

As long as TLS is not configured for the Web Management Console, passwords are sent clear-text over the network. To set up TLS see [Enabling HTTPS](/docs/mdcore/configuration/enabling-https).

Warning

If enhanced password policy is enabled for the user directory this user belongs to, then the new password must fulfill the password complexity requirements listed on the [User directories](/docs/mdcore/configuration/user-directories)) page.
