# How do I remove an engine from my MetaDefender instance?

This article applies to all MetaDefender Core V4 and V5 releases deployed on Windows or Linux systems.

Please Note:

MetaDefender Core downloads engines based on the license key activated on the system. If an engine is manually removed, MetaDefender Core will automatically download the engine again the next time it updates.

In order to completely remove an engine (so that it disappears from the engine list, with no engine files left on the system or to be downloaded again), you will need to get a new license key that does not include the engine.

To do this, you will need to contact the OPSWAT support team.

Support:

If you have need help removing an engine from your MetaDefender instance, please log a [support case or chat with our support engineer](https://my.opswat.com/portal/support).
