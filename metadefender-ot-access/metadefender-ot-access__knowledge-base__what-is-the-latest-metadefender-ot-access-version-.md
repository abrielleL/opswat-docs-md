# What is the latest MetaDefender OT Access version?

**Check Your Version:**

This article applies to all MetaDefender OT Access releases deployed on Linux systems.

Browse MetaDefender OT Access [Release Notes](https://www.opswat.com/docs/metadefender-ot-access/release-notes)for details on the latest version,version history, version comparisons and release notes. 

Alternatively, go directly through the [My OPSWAT](https://my.opswat.com/portal) for a list of available downloads.:

1. Login to My OPSWAT portal

2. Click on “MetaDefender OT Access On-premises”

3. Click on “Download” button

4. In the new window opened, always the version from the top is the latest version

**Pro Tip:**

OPSWAT highly recommends that users upgrade to the latest version of MetaDefender OT Access. Current versions incorporate state-of-the-art features and necessary bug fixes, and are freely available for all license holders to download.
