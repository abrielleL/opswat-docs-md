# System Requirements for Secure OT Access

## [Secure OT Access On premise](/docs/metadefender-ot-access/2.3.0/knowledge-base/system-requirements-for-secure-ot-access#secure-ot-access-on-premise)

Your server must meet the following requirements before installing MetaDefender Endpoint Secure OT Access.

### [Minimum Hardware Requirement](/docs/metadefender-ot-access/2.3.0/knowledge-base/system-requirements-for-secure-ot-access#minimum-hardware-requirement)

| RAM | 8 GB |
| --- | --- |
| CPU | 1 CPU (4 cores) |
| Hard disk | 60 GB |

### [Software Requirement](/docs/metadefender-ot-access/2.3.0/knowledge-base/system-requirements-for-secure-ot-access#software-requirement)

The server software includes the OS, installed from an ISO either onto a VM or bare metal (VM strongly recommended). Because of this, it has no external software requirements. The ISO includes all the software it needs

### [Hardware sizing](/docs/metadefender-ot-access/2.3.0/knowledge-base/system-requirements-for-secure-ot-access#hardware-sizing)

The following table provides recommendations on how to scale hardware specs for a Secure OT Access on-premise deployment based on the number of concurrent connected devices needing to be serviced.

| Number of devices | 1,000 | 1,000 to 5,000 |
| --- | --- | --- |
| CPU | 1 CPU ( 4 cores) | 1 CPU ( 8 cores) |
| RAM | 8 GB | 16 GB |
| Hard disk capacity | 60 GB | 120 GB |

### [Ports used](/docs/metadefender-ot-access/2.3.0/knowledge-base/system-requirements-for-secure-ot-access#ports-used)

The table below shows the default port configuration of Secure OT Access. The ports listed under **External** should be opened for external access.

| OPSWAT Product | Port |
| --- | --- |
| Management Console | 443 and 8443 |

### [Browser Requirement](/docs/metadefender-ot-access/2.3.0/knowledge-base/system-requirements-for-secure-ot-access#browser-requirement)

One of the following desktop browsers is required to use the web management console:

- Latest two Chrome versions
- Latest two Firefox versions
- Latest two Microsoft Edge versions

Mobile layouts are not supported yet.
