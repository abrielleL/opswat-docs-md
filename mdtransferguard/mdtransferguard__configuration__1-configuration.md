# Configuration

In this page you will learn how to configure several aspects of MetaDefender Diode X.

You will learn:

- [Initial Configuration](https://docs.opswat.com/netwalldiode/v1.6.1/configuration/diode-initial-config): How to configure your management IP, DNS and NTP servers
- [Transfer Guard dongles](https://docs.opswat.com/netwalldiode/v1.6.1/configuration/diode-dongles): How the dongles work and how you can register them
- [File Transfer](https://docs.opswat.com/netwalldiode/v1.6.1/configuration/diode-filetransfer): How to configure FTP and Windows File Share to transfer files from BLUE to RED
- [TCP/UDP Streams](https://docs.opswat.com/netwalldiode/v1.6.1/configuration/diode-tcpupd-config): How to configure TCP/UDP Streaming from BLUE to RED
- [Software Updates](https://docs.opswat.com/netwalldiode/v1.6.1/configuration/diode-updates): How to update Transfer Guard
- [Backups](https://docs.opswat.com/netwalldiode/v1.6.1/configuration/diode-backup): How to take snapshots of Transfer Guard configuration and restore them if needed
- [System Log](https://docs.opswat.com/netwalldiode/v1.6.1/configuration/syslog-config): How Syslog feature works
- [Advanced Menu](https://docs.opswat.com/netwalldiode/v1.6.1/configuration/advanced-config): How to configure advanced settings
- [User Accounts](https://docs.opswat.com/netwalldiode/v1.6.1/configuration/user-config): How to create new management Accounts
- [Managed File Transfer Streams](https://docs.opswat.com/netwalldiode/v1.6.1/configuration/vault-streams): How to configure Transfer Guard to work with MetaDefender Managed File Transfer (MFT)
- [Port Scan Detect](/docs/mdtransferguard/configuration/7-port-scan-detect). How to configure Port Scan detect in Transfer Guard
