# Can I deploy MD Kiosk Linux on another computer hardware?

This article applies to all MD Kiosk L-Series.

**MetaDefender Kiosk Linux** is one of our most advanced products, designed with **strict hardware requirements** to ensure optimal security and system durability.

To maintain these standards, MetaDefender Kiosk Linux can **only be deployed on verified hardware** included in the official MetaDefender Kiosk Linux package.

Deployment on **unverified hardware is strictly prohibited**. The system includes a hardware validation mechanism that will block installation attempts on unsupported devices.
