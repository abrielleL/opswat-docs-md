# Product Overview

MetaDefender Kiosk Linux is the latest version of MetaDefender Kiosk, designed to be a self-contained, stateless appliance running on the Linux operating system. The configuration and management of MetaDefender Kiosk Linux appliances is done through My OPSWAT / OPSWAT Central Management.

## [Key Features](/docs/mdkiosk-linux/setup/product-overview#key-features)

- All-in-one hardware appliance
- Simple setup - start scanning removable media within minutes of unboxing in Evaluation Mode
- Scan portable media
- Copy scanned files to USB media or a MetaDefender Managed File Transfer server
- Auto upgrade from a connected management server

---

## [Removable media](/docs/mdkiosk-linux/setup/product-overview#removable-media)

Kiosk supports scanning:

- USB 2.0 / 3.0
- SD Cards
- Discs

Kiosk can process files on devices with:

- NTFS
- FAT32/16
- exFAT
- ext2/3/4

The following encrypted USB devices are supported:

- Bitlocker encrypted devices
- Kingston DTVP
- Kingston DTVP 3.0
- Kingston IronKey D300

Encrypted media as a destination

Encrypted devices are not supported as destination media.

Info

If support for a specific encrypted device is needed, please contact OPSWAT Support.
